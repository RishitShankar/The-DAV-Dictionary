• **Chapter Overview**: Welcome to the DAV Dictionary Academic Notes for Class 6 Hands On in Computer, Chapter 6, titled "Introduction to Coding & Scratch Programming," designed to build foundational computational thinking skills.
• **Definition of Computer Science**: Computer science at the Class 6 level introduces students to how digital devices process information through structured, logical instructions rather than random user inputs.
• **What is Coding?**: Coding is defined as the process of giving step-by-step instructions to a computer in a language that it can interpret and execute to perform specific tasks.
• **Evolution of Communication with Machines**: In the early days of computing, humans communicated with machines using complex binary code consisting of 1s and 0s, which was exceptionally difficult to read and write.
• **Rise of High-Level Languages**: Over time, programming languages evolved from machine code into high-level, human-readable languages that use English-like words to simplify software creation.
• **Concept of a Program**: A program is formally defined as a set of sequential instructions written for a computer to solve a problem, perform a calculation, or control hardware behavior.
• **Role of a Programmer**: A programmer is a human problem solver who breaks down complex real-world challenges into smaller, manageable logical steps that a computer can understand.
• **Real-World Applications of Coding**: Coding powers almost every modern digital technology, including traffic lights, mobile applications, video games, microwave ovens, and automated manufacturing systems.
• **Introduction to Computational Thinking**: Computational thinking is a core problem-solving process that involves breaking problems down, recognizing patterns, abstracting details, and designing algorithms.
• **Decomposition**: Decomposition is the mental process of breaking down a large, complex project or problem into smaller, simpler, and more manageable sub-problems.
• **Pattern Recognition**: Pattern recognition involves finding similarities, trends, and shared characteristics among different problems or data sets to apply previously successful solutions.
• **Abstraction**: Abstraction is the process of filtering out unnecessary details and focusing only on the core, relevant information needed to solve a problem effectively.
• **Algorithm Design**: An algorithm is a finite, ordered sequence of unambiguous instructions designed to solve a specific problem or complete a specific computational task.
• **Difference Between Natural Language and Code**: While natural human languages contain ambiguity and contextual nuances, programming languages require absolute precision, strict syntax, and logical consistency.
• **Importance of Logical Sequencing**: In coding, the exact order in which instructions are given is critical, as changing the sequence can lead to unexpected program behavior or complete failure.
• **Introduction to Block-Based Coding**: Block-based coding environments are designed for beginners, allowing users to snap graphical programming blocks together like puzzle pieces to build applications.
• **Advantages of Block-Based Languages**: Block-based languages eliminate syntax errors caused by missing commas or semicolons, allowing students to focus purely on logic and creativity.

• **Introduction to Scratch**: Scratch is a popular, free, block-based visual programming language and online community developed by the Lifelong Kindergarten Group at the Massachusetts Institute of Technology (MIT).
• **Target Audience of Scratch**: Scratch is specifically designed for children and beginners aged 8 to 16 to help them learn programming concepts while creating interactive stories, games, and animations.
• **Philosophy of Scratch**: The core philosophy of Scratch is "Imagine, Program, Share," emphasizing personal expression, creative exploration, and collaborative learning in a digital environment.
• **Visual Nature of Scratch**: Instead of typing complex text commands on a keyboard, Scratch users drag and drop colorful graphical blocks that represent programming instructions.
• **Platform Availability**: Scratch is versatile and can be accessed either online via a web browser or offline by downloading the Scratch Desktop application for Windows, macOS, or Linux.
• **Scratch Online Community**: The official Scratch website allows millions of creators worldwide to share their projects, remix others' work, and provide constructive feedback in a safe community.
• **Concept of Media Computation**: Scratch integrates multiple media types, allowing users to combine graphics, photographs, recorded sounds, and text into their interactive digital projects.
• **The Scratch Cat Mascot**: The default mascot of Scratch is an orange cat named Scratch Cat, which appears automatically in a new project to represent the primary character or sprite.
• **Understanding the Scratch Interface**: The Scratch interface is divided into multiple well-organized sections, including the Stage, Sprite List, Block Palette, and Script Area, for efficient workflow.
• **The Stage Area**: The Stage is the primary viewing window located in the upper-right corner of the Scratch screen where animations, games, and stories come to life during execution.
• **Stage Dimensions**: The standard Scratch Stage is a Cartesian coordinate plane that measures 480 pixels wide horizontally and 360 pixels high vertically.
• **Center Point of the Stage**: The exact center of the Scratch Stage corresponds to the coordinate position X: 0 and Y: 0, which serves as the origin point for movement.
• **X-Coordinate in Scratch**: The X-coordinate determines the horizontal position of an object on the Stage, with negative values moving left and positive values moving right.
• **Y-Coordinate in Scratch**: The Y-coordinate determines the vertical position of an object on the Stage, with negative values moving down and positive values moving up.
• **FullScreen Mode Button**: A dedicated button near the Stage allows users to expand the viewing window to full screen for a better presentation of completed projects and games.
• **Green Flag and Stop Sign**: Positioned above the Stage, the Green Flag acts as the universal start button for programs, while the Red Stop Sign halts all running scripts instantly.
• **Sprite Definition**: In Scratch, a sprite is defined as any graphical object, character, or item that can be placed on the Stage and programmed to perform various actions.

• **Sprite Pane**: Located beneath the Stage, the Sprite Pane displays thumbnails of all active sprites in the current project, allowing users to select, inspect, and manage them.
• **Adding a New Sprite**: Users can add new sprites to their project by clicking the "Choose a Sprite" button, which opens an extensive library categorized by themes and topics.
• **Sprite Library Categories**: The Scratch Sprite Library organizes characters and objects into categories such as Animals, People, Fantasy, Dance, Music, Sports, Food, Fashion, and Letters.
• **Painting a New Sprite**: The "Paint" option opens the built-in vector and raster graphics editor, allowing users to draw custom characters and objects from scratch.
• **Surprise Sprite Feature**: The "Surprise" button automatically selects and adds a random sprite from the built-in library, adding an element of fun and unexpected discovery.
• **Uploading a Sprite**: Users can import custom images, photographs, or graphics saved on their local computer to use as personalized sprites within their Scratch projects.
• **Deleting a Sprite**: Unwanted sprites can be removed from a project by clicking the trash can icon on the sprite thumbnail or by right-clicking and selecting "delete."
• **Duplicating a Sprite**: Duplicating a sprite creates an exact copy of the selected character along with all its associated costumes, sounds, and programming scripts.
• **Sprite Information Panel**: Each sprite has an information panel displaying its name, X and Y coordinates, direction, size, and visibility status (shown or hidden).
• **Renaming Sprites**: Good programming practice involves giving descriptive names to sprites (e.g., "Player1," "Enemy," "Goal") instead of default names like "Sprite1" or "Sprite2."
• **Adjusting Sprite Size**: The size property in the sprite information panel allows users to scale characters up or down by percentage values relative to their original dimension.
• **Sprite Direction and Rotation**: The direction property determines the angle at which a sprite faces, measured in degrees from -180 to 180, affecting its movement orientation.
• **Backdrop Definition**: A backdrop is the background image or scene displayed on the Stage behind all active sprites, helping to establish the setting of the project.
• **Stage Backdrop Pane**: Situated next to the Sprite Pane, the Backdrop Pane allows users to view, select, and manage backgrounds associated with the Stage.
• **Backdrop Library**: Similar to the sprite library, the Backdrop Library offers a vast collection of pre-designed scenes ranging from outdoor landscapes and indoor rooms to abstract patterns.
• **Painting Custom Backdrops**: Users can utilize the built-in paint editor to design custom backdrops, create color gradients, add text elements, and set specific moods for their games.
• **Managing Multiple Backdrops**: Projects can contain multiple backdrops, allowing programmers to switch backgrounds dynamically during a story or transition between different game levels.

• **Introduction to Costumes**: Every sprite in Scratch can have one or more costumes, which are alternative graphical appearances or poses that the character can wear.
• **Costume Tab**: Clicking on the Costumes tab reveals the graphics editor, allowing users to modify existing sprite appearances, flip images horizontally, or create new frames for animation.
• **Animating with Costumes**: By rapidly switching between different costumes in a sequence, programmers can create smooth walking, running, or talking animations for their characters.
• **Vector vs. Raster Graphics**: The Scratch paint editor supports both vector graphics (which scale without losing quality) and bitmap/raster graphics (composed of pixels) for versatile editing.
• **Selection Tool**: The arrow selection tool in the costume editor lets users click, drag, resize, rotate, and group different graphical components of a sprite.
• **Brush and Eraser Tools**: The brush tool allows freehand drawing with adjustable thickness and color, while the eraser tool removes unwanted pixels or vector lines.
• **Fill Bucket Tool**: The paint bucket tool fills enclosed areas with solid colors, gradients, or patterns, making it easy to colorize characters and background shapes.
• **Text Tool**: The text tool enables users to add captions, speech bubbles, or UI elements directly onto costumes and backdrops using various fonts and styles.
• **Sound Library in Scratch**: Scratch includes a built-in Sound Library containing musical instrument notes, sound effects, and voice clips that can be added to any project.
• **Sound Tab**: The Sound tab allows users to play, edit, trim, reverse, and apply audio effects like louder, softer, robot, or echo to imported or library sounds.
• **Recording Custom Audio**: Using a microphone connected to the computer, users can record their own voice, narration, or musical sounds directly into the Scratch environment.
• **Sound Categories**: Sounds in Scratch are categorized into effects, human sounds, loops, notes, percussions, and specific instrumental themes to match project requirements.
• **Introduction to the Block Palette**: The Block Palette is the central color-coded repository located in the middle-left section of the screen that contains all available programming blocks.
• **Categorization of Blocks**: Scratch organizes programming blocks into nine distinct, color-coded categories to make finding specific instructions intuitive and efficient for young learners.
• **Motion Category**: Dark blue blocks in the Motion category control sprite movement, position, sliding, rotation, and coordinate tracking on the Stage.
• **Looks Category**: Purple blocks in the Looks category manage sprite appearance, costume changes, speech bubbles, thinking bubbles, size adjustments, and visual effects.
• **Sound Category**: Magenta-pink blocks in the Sound category control audio playback, musical instrument notes, volume levels, and audio effects within a project.

----PAGE-BREAK---

• **Events Category**: Yellow-orange blocks in the Events category act as triggers that start scripts when specific actions occur, such as clicking the Green Flag or pressing a key.
• **Control Category**: Gold-yellow blocks in the Control category manage program flow through looping structures, conditional statements, and time delays.
• **Sensing Category**: Light blue blocks in the Sensing category allow sprites to detect interactions, such as touching another sprite, touching a color, or asking user input.
• **Operators Category**: Light green blocks in the Operators category perform mathematical calculations, string manipulations, and logical comparisons (greater than, less than, equals).
• **Variables Category**: Orange blocks in the Variables category allow programmers to create, store, update, and display numerical or textual data values during runtime.
• **My Blocks Category**: Red-pink blocks in the My Blocks category allow advanced users to define their own custom blocks and procedures for modular programming.
• **Understanding Block Shapes**: The geometric shape of a Scratch block indicates its function, syntax rules, and how it can connect with other blocks in the Script Area.
• **Hat Blocks**: Hat blocks feature a rounded top and a flat bottom with a connector notch, acting exclusively as event triggers placed at the very top of any script.
• **Stack Blocks**: Stack blocks have a notch on top and a bump on the bottom, allowing them to stack vertically like puzzle pieces to form sequential instruction lists.
• **Reporter Blocks**: Reporter blocks have rounded or pill-like shapes designed to hold values, numbers, or text, and fit inside the oval input slots of other blocks.
• **Boolean Blocks**: Boolean blocks feature hexagonal shapes and evaluate strictly to a truth value of either "true" or "false" when used in conditional test statements.
• **C-Blocks**: C-blocks are shaped like the letter 'C' and are used to wrap around other instruction blocks to control how many times or under what conditions they run.
• **Cap Blocks**: Cap blocks have a flat top and no bottom connector, marking the definitive end point or termination of a script or custom procedure.
• **Script Area Definition**: The Script Area is the large workspace on the right side of the screen where users drag, drop, and snap blocks together to form functional programs.
• **Snapping Blocks Together**: When dragging a block close to another compatible block in the Script Area, a white glowing highlight indicates where the connection will be made.
• **Disassembling Blocks**: To separate connected blocks, users can simply click and drag any lower block downward to pull the instruction stack apart.
• **Deleting Blocks**: Unwanted blocks can be removed from the Script Area by dragging them backward and dropping them back into the Block Palette.

• **Concept of Event-Driven Programming**: Scratch relies heavily on event-driven programming, meaning that code execution is triggered by specific user actions or environmental occurrences.
• **The "When Green Flag Clicked" Block**: The most fundamental event block in Scratch starts the attached script sequence the exact moment the user clicks the green flag.
• **The "When [Key] Pressed" Block**: This event block allows a sprite to respond to keyboard inputs, such as the spacebar, arrow keys, or any alphabet letter.
• **The "When This Sprite Clicked" Block**: This event block triggers code when the user clicks directly on a specific sprite with the mouse pointer on the Stage.
• **Sequential Execution Mechanics**: Once an event triggers a script, Scratch executes the stacked blocks strictly in order from top to bottom, one instruction after another.
• **Introduction to Motion Blocks**: Motion blocks dictate how a sprite moves across the coordinate plane of the Stage, changing its X and Y values dynamically.
• **The "Move [Steps] Steps" Block**: This block moves a sprite forward in the direction it is currently facing by a specified number of pixels.
• **The "Turn Right/Left [Degrees]" Blocks**: These rotation blocks tilt a sprite clockwise or counterclockwise by a specified number of degrees without changing its position.
• **The "Go To [X: Y]" Block**: This teleportation block instantly moves a sprite to exact coordinates on the Stage without showing any intermediate animation.
• **The "Glide [Seconds] To [X: Y]" Block**: This block moves a sprite smoothly across the Stage to target coordinates over a specified time duration.
• **The "Point in Direction [Degrees]" Block**: This block sets the absolute orientation of a sprite, where 90 is right, -90 is left, 0 is up, and 180 is down.
• **The "Point Towards [Sprite]" Block**: This block automatically calculates the angle required to face another sprite and rotates the current character to look directly at it.
• **The "Change X/Y by [Value]" Blocks**: These blocks adjust only the horizontal or vertical position of a sprite relative to its current coordinate location.
• **The "Set X/Y to [Value]" Blocks**: These blocks lock a sprite's horizontal or vertical position to an absolute coordinate value regardless of where it currently is.
• **The "If on edge, bounce" Block**: This convenient block prevents sprites from disappearing off the Stage by reversing their direction when they touch the window border.
• **Understanding Rotation Styles**: Scratch provides three rotation styles (All Around, Left-Right, and Don't Rotate) to control how sprites behave when pointing in different directions.
• **Role of Looks Blocks in Storytelling**: Looks blocks transform static sprites into dynamic storytellers by adding visual dialog, costume switching, color changes, and visibility controls.

• **The "Say [Text] for [Seconds]" Block**: This block displays a speech bubble above a sprite containing specified text for an exact duration before disappearing automatically.
• **The "Say [Text]" Block**: This block displays a speech bubble with text indefinitely until another display block replaces it or clears the message.
• **The "Think [Text] for [Seconds]" Block**: Similar to speech, this block displays a thought bubble with cloud-like circles to represent internal monologues or character thoughts.
• **The "Switch Costume To [Costume]" Block**: This block instantly changes the visual appearance of a sprite to a specific named costume from its costume list.
• **The "Next Costume" Block**: This block cycles a sprite forward to the subsequent costume in its list, wrapping around to the first costume after the last one.
• **The "Switch Backdrop To [Backdrop]" Block**: This Stage-specific block changes the background image of the entire Stage to a designated scene.
• **The "Change Size By [Value]" Block**: This block increases or decreases the physical dimensions of a sprite by a specific percentage relative to its current size.
• **The "Set Size To [Value] %" Block**: This block sets a sprite's size to an exact percentage of its original imported dimensions.
• **The "Change [Color] Effect By [Value]" Block**: This block applies visual distortions, such as color tints, fish-eye warping, pixelation, mosaics, or brightness adjustments, to a sprite.
• **The "Clear Graphic Effects" Block**: This instruction resets all visual distortions applied to a sprite, returning it to its original normal appearance instantly.
• **The "Show" and "Hide" Blocks**: These complementary blocks control sprite visibility, allowing characters to vanish from the Stage and reappear magically during a game.
• **Going to Front or Back Layers**: When multiple sprites overlap on the Stage, these blocks control layering, determining which sprite appears on top of others.
• **Introduction to Sound Integration**: Sound blocks enrich interactive projects by adding background music, sound effects, and character vocalizations at precise moments.
• **The "Play Sound [Sound] Until Done" Block**: This block pauses script execution until the selected audio clip finishes playing completely before moving to the next block.
• **The "Start Sound [Sound]" Block**: This block triggers an audio clip to play in the background while immediately executing the subsequent blocks in the script stack.
• **The "Stop All Sounds" Block**: This instruction halts all audio playback across the entire project immediately, useful for transitioning scenes or ending games.
• **Controlling Audio Volume**: Programmers can adjust audio output levels dynamically using blocks that change or set the volume property of a sprite or stage.

• **Introduction to Control Structures**: Control blocks dictate the flow, timing, and logical execution order of instructions within a computer program.
• **The "Wait [Seconds]" Block**: This essential timing block pauses script execution for a specified duration, allowing programmers to pace animations and events.
• **The Concept of Loops**: Loops are programming structures that allow a specific block of instructions to be repeated multiple times without duplicating code manually.
• **The "Repeat [Number]" Loop**: This C-block executes all enclosed instruction blocks a precise, predetermined number of times before moving on to the rest of the script.
• **The "Forever" Loop**: This infinite C-block continues executing its enclosed instructions endlessly until the user clicks the Stop Sign or the program is terminated.
• **The "Repeat Until [Condition]" Loop**: This conditional loop keeps running the inner instruction blocks continuously until a specific Boolean sensing condition becomes true.
• **Introduction to Conditional Statements**: Conditionals allow programs to make decisions and execute different instructions based on whether specific circumstances are met.
• **The "If [Condition] Then" Block**: This conditional structure checks a Boolean condition, and if true, executes the enclosed blocks; if false, it skips them entirely.
• **The "If [Condition] Then, Else" Block**: This expanded conditional structure provides two alternate pathways, executing one set of blocks if the condition is true and a different set if false.
• **Introduction to Sensing Blocks**: Sensing blocks allow sprites to interact with their environment, detect mouse pointers, measure distances, and respond to user inputs.
• **The "Touching [Sprite/Mouse-Pointer]?" Block**: This Boolean sensing block checks whether a sprite is colliding with another object or the mouse cursor on the Stage.
• **The "Touching Color [Color]?" Block**: This block checks if any part of a sprite is currently touching a specific color chosen from the Stage.
• **The "Key [Key] Pressed?" Block**: This Boolean block checks if a specific keyboard key is being held down at that exact moment during program execution.
• **The "Mouse Down?" Block**: This block detects whether the left mouse button is currently being clicked or held down anywhere on the screen.
• **The "Mouse X" and "Mouse Y" Reporter Blocks**: These blocks track the real-time horizontal and vertical pixel coordinates of the mouse cursor on the Stage.
• **The "Ask [Question] and Wait" Block**: This interactive block prompts the user by displaying a question in a box at the bottom of the Stage and waits for text keyboard input.
• **The "Answer" Reporter Block**: This system variable stores the most recent text string typed by the user in response to an "Ask and Wait" prompt block.

• **Introduction to Operators**: Operator blocks serve as the mathematical and logical engine of Scratch, performing calculations and comparisons.
• **Basic Arithmetic Operators**: Scratch provides four primary mathematical operator blocks for addition (+), subtraction (-), multiplication (*), and division (/).
• **The "Pick Random [Min] to [Max]" Block**: This reporter block generates a random integer between two specified numbers, crucial for adding unpredictability to games.
• **Comparison Operators**: Scratch includes three relational comparison blocks: "Greater Than (>)", "Less Than (<)", and "EqualTo (=)" to compare numbers or text.
• **Logical Operators (AND, OR, NOT)**: These boolean operator blocks allow programmers to combine multiple conditions to create complex decision-making logic.
• **The "Join [Apple] [Banana]" Block**: This string manipulation operator combines two separate text words or phrases into a single continuous text string.
• **String Character Extraction**: Operators allow programmers to find the letter at a specific position in a word or determine the total character length of a text string.
• **Mathematical Functions**: Advanced mathematical operators include finding modulo (remainders), rounding numbers up or down, and calculating absolute values or square roots.
• **Introduction to Variables**: A variable is a named storage container in the computer's memory used to hold dynamic data that can change while the program runs.
• **Creating a Variable**: To create a variable in Scratch, users click "Make a Variable" in the Orange category and choose whether it applies to all sprites or only one.
• **Variable Scope**: "For all sprites" variables are global and can be accessed or modified by any character, while "For this sprite only" variables are local.
• **Stage Monitor Display**: When a variable is created, a monitor box appears on the Stage displaying its current name and value, which can be shown, hidden, or formatted.
• **The "Set [Variable] To [Value]" Block**: This block assigns a specific initial numerical or textual value to a variable, resetting its contents.
• **The "Change [Variable] By [Value]" Block**: This block increments or decrements a variable's current value by a specified amount (e.g., adding points to a score).
• **The "Show/Hide Variable [Variable]" Blocks**: These instructions control whether the variable monitor box is visible on the Stage during gameplay.
• **Introduction to Lists**: A list is an advanced data structure in Scratch that stores an ordered collection of multiple items or values under a single variable name.
• **List Operations**: Scratch allows programmers to add items to lists, delete specific entries, insert items at given positions, replace items, and check list lengths.

• **Debugging in Coding**: Debugging is the systematic process of identifying, analyzing, and removing errors or bugs from a computer program to ensure correct execution.
• **Types of Errors in Programming**: Errors in coding typically fall into logical errors (where the program runs but produces incorrect results) and syntax issues (avoided in Scratch).
• **Using Step-by-Step Tracing**: Programmers debug scripts by manually following the execution path instruction by instruction to find where expected logic deviates from reality.
• **Adding Sound and Visual Cues for Debugging**: Inserting temporary "Say" blocks or sound effects helps developers track which code branches are executing during runtime.
• **Best Practices in Scratch Project Organization**: Clean coding practices include keeping scripts organized, using comments, naming sprites logically, and avoiding redundant blocks.
• **Using Project Comments**: Scratch allows developers to right-click in the Script Area and add sticky notes as comments to explain complex logic to themselves and others.
• **Importance of Saving Work**: Regularly saving Scratch projects (both locally and in the online cloud account) prevents accidental data loss during development.
• **Exporting and Importing Projects**: Users can save their Scratch projects as `.sb3` files on their local hard drives to back up work or share via USB drives.
• **Remixing Projects**: The Scratch community encourages remixing, which involves taking an existing shared project, modifying its code, and adding personal creative touches.
• **Designing Interactive Games**: Combining events, loops, conditionals, variables, and clones enables Class 6 students to build fully playable arcade games in Scratch.
• **Creating Digital Stories**: Students can use backdrops, dialogue blocks, and costume changes to program animated storybooks, book reports, and historical reenactments.
• **Art and Animation Projects**: Scratch empowers students to program geometric patterns, musical visualizers, and interactive digital art pieces using pen and motion blocks.
• **Collaboration and Sharing**: Sharing finished projects on the Scratch website fosters a global community of young creators who learn from one another's code architecture.
• **Ethical Considerations in Digital Creation**: Young programmers learn the importance of giving credit when remixing projects and maintaining a respectful, positive online community environment.
