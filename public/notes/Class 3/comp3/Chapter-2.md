• **Computer**: An electronic machine that processes data and converts it into meaningful information.
• **Data**: Raw facts, figures, numbers, and symbols that are fed into the computer for processing.
• **Information**: The meaningful and organized output obtained after processing the raw data.
• **Input**: The process of entering data and instructions into the computer system.
• **Processing**: The internal operation performed by the computer to convert data into information.
• **Output**: The final result displayed or produced by the computer after processing.
• **IPO Cycle**: The fundamental working principle of a computer consisting of Input, Processing, and Output.
• **Hardware**: The physical parts of a computer that we can see and touch.
• **Software**: The set of instructions or programs that tell the computer what to do.
• **CPU**: Central Processing Unit, often called the "brain" of the computer.
• **Input Devices**: Hardware components used to provide data and control signals to the computer.
• **Keyboard**: The primary input device used for typing text, numbers, and commands.
• **Mouse**: A pointing device used to select items and navigate the graphical user interface.
• **Scanner**: An input device that converts physical documents or images into digital format.
• **Microphone**: An input device used to record sound or voice into the computer.
• **Webcam**: A camera used to capture live images or video for digital communication.
• **Joystick**: A device primarily used for controlling movements in computer games.
• **Light Pen**: A light-sensitive pointing device used to draw directly on the screen.

• **Processing Unit**: The core component that performs calculations and logical operations.
• **System Unit**: The main cabinet or box that houses the motherboard, CPU, and memory.
• **CPU Components**: The CPU is divided into three main parts: ALU, CU, and MU.
• **ALU (Arithmetic Logic Unit)**: The part of the CPU that performs all mathematical calculations and logical comparisons.
• **CU (Control Unit)**: The part of the CPU that directs and coordinates all operations within the computer.
• **MU (Memory Unit)**: The part of the CPU that stores data and instructions temporarily during processing.
• **Motherboard**: The main circuit board that connects all the internal components of the computer.
• **Microprocessor**: A single chip that contains the entire CPU, responsible for executing instructions.
• **Clock Speed**: The speed at which the CPU processes instructions, measured in Gigahertz (GHz).
• **Data Flow**: The path data takes from input devices, through the CPU, to the output devices.
• **Binary Language**: The machine language consisting of 0s and 1s that the computer understands.
• **Instruction Set**: A predefined group of commands that the CPU is designed to execute.
• **Processing Speed**: The efficiency with which a computer handles complex tasks and calculations.
• **Internal Memory**: The storage space located directly on the motherboard for immediate access.
• **Registers**: Small, high-speed storage locations within the CPU used to hold data currently being processed.
• **Cache Memory**: A small, ultra-fast memory that stores frequently used data to speed up CPU operations.
• **System Bus**: The communication system that transfers data between the components of the computer.

---PAGE-BREAK---

• **Output Devices**: Hardware components that display or present the results of processing.
• **Monitor**: The primary output device that displays text, images, and videos on a screen.
• **Visual Display Unit (VDU)**: Another name for the monitor, representing the visual output interface.
• **Printer**: An output device that produces a permanent copy of information on paper.
• **Hard Copy**: The physical paper output produced by a printer.
• **Soft Copy**: The digital output displayed on the computer screen.
• **Impact Printers**: Printers that strike an ink ribbon against paper (e.g., Dot Matrix).
• **Non-Impact Printers**: Printers that use ink droplets or toner without striking the paper (e.g., Inkjet, Laser).
• **Inkjet Printer**: A printer that sprays tiny droplets of ink onto paper to create high-quality images.
• **Laser Printer**: A fast, high-quality printer that uses laser technology and toner powder.
• **Speakers**: Output devices that produce sound, music, and voice from the computer.
• **Headphones**: Personal output devices that allow users to listen to audio privately.
• **Projector**: An output device used to display computer output on a large screen or wall.
• **Plotter**: A specialized output device used for printing high-quality vector graphics and architectural designs.
• **Resolution**: The clarity and sharpness of the image on the monitor, measured in pixels.
• **Pixel**: The smallest unit of an image on a screen; short for "picture element."
• **Refresh Rate**: The number of times per second the screen image is updated.

---PAGE-BREAK---

• **Storage Devices**: Hardware used to store data and information permanently for future use.
• **Primary Memory**: The main memory of the computer, which is volatile and directly accessible by the CPU.
• **Secondary Memory**: Non-volatile storage used for long-term data retention.
• **RAM (Random Access Memory)**: The temporary workspace of the computer where active programs are stored.
• **Volatile Memory**: Memory that loses its data when the power supply is turned off (e.g., RAM).
• **ROM (Read-Only Memory)**: Permanent memory that contains essential startup instructions for the computer.
• **Non-Volatile Memory**: Memory that retains data even when the power is switched off (e.g., ROM, Hard Disk).
• **Hard Disk Drive (HDD)**: The main secondary storage device inside the computer with a large capacity.
• **Magnetic Storage**: Technology used by HDDs to store data on spinning magnetic platters.
• **Solid State Drive (SSD)**: A faster, more durable storage device that uses flash memory instead of moving parts.
• **Optical Storage**: Devices that use laser light to read and write data on discs.
• **CD (Compact Disc)**: An optical storage medium typically used for music or small software files.
• **DVD (Digital Versatile Disc)**: An optical storage medium with higher capacity than a CD, used for movies and large data.
• **Blu-ray Disc**: A high-capacity optical disc used for storing high-definition video and large amounts of data.
• **Flash Drive (Pen Drive)**: A portable, compact storage device that connects via a USB port.
• **Memory Card**: A small, removable storage device used in cameras, phones, and tablets.
• **Storage Capacity**: The amount of data a storage device can hold, measured in Bytes, KB, MB, GB, and TB.

• **Software**: The collection of programs that enable the hardware to perform specific tasks.
• **System Software**: Essential software that manages the computer's hardware and provides a platform for other programs.
• **Operating System (OS)**: The most important system software that acts as an interface between the user and the hardware.
• **Examples of OS**: Windows, macOS, Linux, Android, and iOS.
• **Application Software**: Programs designed to help users perform specific tasks, such as writing or drawing.
• **General Purpose Software**: Software used for common tasks like word processing or browsing the internet.
• **Word Processor**: Application software used for creating, editing, and formatting text documents (e.g., MS Word).
• **Spreadsheet Software**: Software used for calculations, data analysis, and creating charts (e.g., MS Excel).
• **Presentation Software**: Software used to create visual slideshows for presentations (e.g., MS PowerPoint).
• **Graphics Software**: Programs used for creating and editing images, drawings, and designs (e.g., MS Paint).
• **Multimedia Software**: Software used to play, create, or edit audio and video files.
• **Utility Software**: Programs that help maintain and optimize the computer's performance (e.g., Antivirus).
• **User Interface (UI)**: The visual part of the software that allows the user to interact with the computer.
• **GUI (Graphical User Interface)**: An interface that uses icons, menus, and windows to make interaction easy.
• **Command Line Interface (CLI)**: An older interface where users type text commands to interact with the system.
• **Software Installation**: The process of setting up a program on the computer so it can be used.
• **Software Update**: The process of improving or fixing existing software to keep it current and secure.

• **Computer Characteristics**: Computers are known for their speed, accuracy, diligence, versatility, and storage.
• **Speed**: Computers can perform millions of calculations in a single second.
• **Accuracy**: Computers provide error-free results, provided the input data and instructions are correct.
• **Diligence**: Computers can work for long hours without getting tired, bored, or losing concentration.
• **Versatility**: Computers can perform a wide variety of tasks, from simple calculations to complex simulations.
• **Storage Capacity**: Computers can store vast amounts of data in a small physical space for a long time.
• **Reliability**: Computers are highly dependable machines that perform tasks consistently.
• **Automation**: Computers can perform tasks automatically once the instructions are provided.
• **No Intelligence**: Computers do not have their own brain or feelings; they follow human instructions.
• **Dependence**: Computers are entirely dependent on humans for input and programming.
• **Limitations**: Computers cannot make decisions on their own or learn from experience like humans.
• **GIGO Principle**: "Garbage In, Garbage Out" – if the input is incorrect, the output will also be incorrect.
• **Human-Computer Interaction**: The relationship where humans provide the logic and computers provide the processing power.
• **Efficiency**: The ability of a computer to complete tasks with minimal waste of time and resources.
• **Consistency**: The ability to produce the same result every time the same process is repeated.
• **Multitasking**: The ability of a computer to perform multiple tasks simultaneously.
• **Scalability**: The ability of a computer system to handle an increasing amount of work.

• **Types of Computers**: Computers are categorized based on their size, power, and purpose.
• **Supercomputers**: The most powerful and fastest computers, used for complex scientific research and weather forecasting.
• **Mainframe Computers**: Large, powerful computers used by big organizations for bulk data processing and transactions.
• **Minicomputers**: Mid-sized computers that are smaller than mainframes but more powerful than personal computers.
• **Microcomputers**: Small, affordable computers designed for individual use, also known as Personal Computers (PCs).
• **Desktop Computer**: A microcomputer designed to be placed on a desk and connected to a power source.
• **Laptop**: A portable microcomputer that runs on a battery and can be carried easily.
• **Tablet**: A handheld, touch-screen computer that is highly portable and used for media consumption.
• **Smartphone**: A mobile phone with advanced computing capabilities and internet access.
• **Workstation**: A high-performance computer designed for technical or scientific applications.
• **Embedded System**: A computer system built into a larger device to perform specific tasks (e.g., in washing machines).
• **Server**: A powerful computer that provides services or data to other computers on a network.
• **Client**: A computer that requests services or data from a server.
• **Personal Digital Assistant (PDA)**: An early form of handheld computer used for organizing personal information.
• **Wearable Computers**: Computing devices worn on the body, such as smartwatches.
• **Game Consoles**: Specialized computers designed primarily for playing video games.
• **Networked Computers**: Computers connected together to share resources and information.

• **Computer Ethics**: The set of moral principles that govern the use of computers and technology.
• **Cybersecurity**: The practice of protecting computer systems and networks from digital attacks.
• **Password Protection**: The use of secret codes to prevent unauthorized access to computer accounts.
• **Data Privacy**: The right of individuals to control how their personal information is collected and used.
• **Copyright**: The legal right that protects the creator of software or digital content from unauthorized copying.
• **Piracy**: The illegal copying, distribution, or use of software without proper licensing.
• **Malware**: Malicious software designed to harm or gain unauthorized access to a computer system.
• **Virus**: A type of malware that replicates itself and spreads to other files, causing damage.
• **Antivirus Software**: A program used to detect, prevent, and remove malware from the computer.
• **Digital Citizenship**: The responsible and ethical use of technology in society.
• **Netiquette**: The rules of polite and respectful behavior when communicating online.
• **Cyberbullying**: The use of digital technology to harass, threaten, or intimidate others.
• **Phishing**: A fraudulent attempt to obtain sensitive information by disguising as a trustworthy entity.
• **Spam**: Unsolicited and unwanted emails sent in bulk to many users.
• **Firewall**: A security system that monitors and controls incoming and outgoing network traffic.
• **Backup**: The process of creating copies of data to prevent loss in case of system failure.
• **Cloud Storage**: Storing data on remote servers accessed via the internet rather than on a local drive.

• **Computer Maintenance**: The practice of keeping the computer hardware and software in good working condition.
• **Cleaning**: Regularly dusting the monitor, keyboard, and mouse to prevent dirt buildup.
• **Cable Management**: Organizing wires to prevent tripping hazards and damage to connections.
• **Ventilation**: Ensuring the computer has enough airflow to prevent overheating.
• **Surge Protector**: A device that protects the computer from sudden spikes in electrical voltage.
• **UPS (Uninterruptible Power Supply)**: A device that provides battery backup during power outages.
• **Disk Cleanup**: A utility that removes unnecessary files to free up space on the hard drive.
• **Defragmentation**: A process that organizes data on the hard drive to improve access speed.
• **Software Updates**: Regularly installing patches to fix bugs and improve security.
• **Safe Shutdown**: Always turning off the computer using the proper "Shut Down" command.
• **Physical Safety**: Keeping food and drinks away from the computer to avoid spills.
• **Ergonomics**: Designing the workspace to ensure comfort and prevent strain while using the computer.
• **Posture**: Sitting correctly with back support and keeping the screen at eye level.
• **Eye Care**: Taking regular breaks from the screen to prevent eye strain (20-20-20 rule).
• **Keyboard Care**: Avoiding pressing keys too hard and keeping the keyboard clean.
• **Mouse Care**: Using a mouse pad for smooth movement and accurate tracking.
• **System Restore**: A feature that allows the user to revert the computer to a previous working state.

• **Future of Computing**: The evolution of technology towards faster, smaller, and more intelligent systems.
• **Artificial Intelligence (AI)**: The simulation of human intelligence by machines to perform tasks like learning and problem-solving.
• **Internet of Things (IoT)**: The network of physical objects embedded with sensors and software to exchange data.
• **Virtual Reality (VR)**: A computer-generated simulation of an environment that users can interact with.
• **Augmented Reality (AR)**: The integration of digital information with the user's environment in real-time.
• **Quantum Computing**: A new type of computing that uses quantum mechanics to solve complex problems faster than classical computers.
• **Robotics**: The branch of technology that deals with the design, construction, and operation of robots.
• **Cloud Computing**: The delivery of computing services over the internet, including storage and processing.
• **Big Data**: Extremely large data sets that are analyzed to reveal patterns and trends.
• **Biometrics**: The use of physical characteristics (like fingerprints) for security and identification.
• **Smart Homes**: Homes equipped with internet-connected devices for automation and control.
• **Wearable Tech**: Devices that track health, fitness, and communication from the wrist or body.
• **3D Printing**: The process of creating three-dimensional objects from a digital file.
• **Automation**: The use of technology to perform tasks with minimal human intervention.
• **Connectivity**: The ability of computers to link together globally via the internet.
• **Innovation**: The continuous development of new technologies to improve human life.
• **Digital Transformation**: The integration of digital technology into all areas of business and daily life.
