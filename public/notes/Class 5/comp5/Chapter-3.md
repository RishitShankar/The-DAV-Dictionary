• **Operating System (OS):** The fundamental software that manages computer hardware, software resources, and provides common services for computer programs.
• **Windows OS:** A graphical user interface (GUI) based operating system developed by Microsoft that allows users to interact with the computer using icons, menus, and windows.
• **Desktop:** The primary workspace that appears on the screen after the computer boots up and the user logs in.
• **Icons:** Small graphical representations of files, folders, applications, or shortcuts located on the desktop.
• **Taskbar:** The long horizontal bar usually located at the bottom of the screen that displays currently running programs and system notifications.
• **Start Button:** The gateway to the computer, providing access to all installed applications, settings, and power options.
• **System Tray:** Located on the right side of the taskbar, it displays icons for background processes like volume, network status, and the clock.
• **GUI (Graphical User Interface):** A type of user interface that allows users to interact with electronic devices through visual indicators rather than text-based commands.
• **Windows Environment:** The workspace where all applications run, characterized by rectangular frames known as 'windows'.
• **File:** A collection of related information or data stored on a storage device, such as a document, image, or program.
• **Folder:** A digital container used to organize and store files, other folders, and shortcuts, similar to a physical file cabinet.
• **Directory:** Another term for a folder, representing the hierarchical structure of the file system.
• **File Extension:** A suffix at the end of a filename (e.g., .docx, .jpg) that indicates the file type and the program used to open it.
• **Path:** The specific location of a file or folder within the computer’s storage hierarchy.
• **Drive:** A storage device (like C: or D:) that acts as the root container for all files and folders on a computer.

---PAGE-BREAK---

• **File Explorer:** The primary file management application in Windows used to navigate, view, and manage files and folders.
• **Navigation Pane:** The left-hand column in File Explorer that provides quick access to frequently used folders, drives, and network locations.
• **Address Bar:** Displays the current path of the folder being viewed, allowing users to navigate back to parent folders.
• **Ribbon:** The toolbar at the top of File Explorer containing various commands and tools for managing files and folders.
• **Search Box:** Located at the top right of File Explorer, it allows users to quickly find specific files or folders by typing their names.
• **Status Bar:** Located at the bottom of the window, it displays information about the number of items in a folder and their total size.
• **Details Pane:** A section that shows specific metadata about a selected file, such as date modified, size, and author.
• **View Tab:** A section in the Ribbon that allows users to change how files and folders are displayed (e.g., Large Icons, List, Details).
• **Large Icons View:** Displays files and folders as large thumbnails, which is useful for previewing images.
• **Details View:** Displays files and folders in a list format with columns showing name, date modified, type, and size.
• **Sorting:** The process of arranging files and folders by specific criteria such as Name, Date, or Size.
• **Grouping:** A feature that organizes files into categories based on specific attributes within the current view.
• **Refresh:** A command used to update the contents of a folder if changes are not immediately visible.
• **Quick Access:** A feature in the Navigation Pane that provides shortcuts to folders you use frequently.
• **This PC:** A view in File Explorer that shows all drives connected to the computer, including hard disks, USB drives, and network locations.

• **Creating a Folder:** The process of organizing data by generating a new container within a drive or another folder.
• **Right-Click Method:** The most common way to create a folder by right-clicking on an empty space, selecting 'New', and then 'Folder'.
• **Naming a Folder:** Assigning a descriptive name to a folder to make it easier to identify its contents later.
• **Renaming:** The action of changing the name of an existing file or folder to better reflect its current content.
• **F2 Key:** The shortcut key on the keyboard used to quickly rename a selected file or folder.
• **Context Menu:** The menu that appears when you right-click on an object, providing a list of actions you can perform.
• **Selecting Files:** The act of highlighting one or more files to perform operations like moving, copying, or deleting.
• **Single Selection:** Clicking on a file once to select it.
• **Contiguous Selection:** Selecting a group of files that are next to each other by holding the 'Shift' key and clicking the first and last file.
• **Non-Contiguous Selection:** Selecting multiple files that are not next to each other by holding the 'Ctrl' key and clicking each file individually.
• **Select All:** A command (Ctrl + A) that selects every item within the current folder window.
• **Invert Selection:** A command that selects all unselected items and deselects all currently selected items.
• **Drag and Drop:** A mouse action used to move or copy files by clicking and holding an item, then releasing it in a new location.
• **Moving Files:** The process of changing the location of a file from one folder or drive to another.
• **Copying Files:** The process of creating a duplicate of a file in a different location while keeping the original intact.

---PAGE-BREAK---

• **Cut Command:** Removes the selected file or folder from its original location and places it in the clipboard for moving.
• **Copy Command:** Creates a duplicate of the selected file or folder and places it in the clipboard.
• **Paste Command:** Places the file or folder currently held in the clipboard into the destination folder.
• **Clipboard:** A temporary storage area in the computer's memory used to hold data during cut, copy, and paste operations.
• **Ctrl + X:** The keyboard shortcut for the 'Cut' command.
• **Ctrl + C:** The keyboard shortcut for the 'Copy' command.
• **Ctrl + V:** The keyboard shortcut for the 'Paste' command.
• **Destination Folder:** The folder where you intend to move or copy your files.
• **Source Folder:** The folder where the file is currently located before moving or copying.
• **Overwriting:** A warning that appears if you try to copy a file into a folder that already contains a file with the same name.
• **Deleting Files:** The process of removing unwanted files or folders from the computer's storage.
• **Delete Key:** The keyboard button used to send a selected file to the Recycle Bin.
• **Recycle Bin:** A temporary storage area for deleted files, allowing users to restore them if they were deleted by mistake.
• **Permanent Deletion:** The process of deleting a file without sending it to the Recycle Bin, usually done by pressing 'Shift + Delete'.
• **Confirmation Dialog:** A pop-up window that asks the user to confirm if they really want to delete a file or folder.

---PAGE-BREAK---

• **Restoring Files:** The process of moving a file from the Recycle Bin back to its original location.
• **Emptying the Recycle Bin:** The action of permanently removing all files stored in the Recycle Bin to free up disk space.
• **File Properties:** Information about a file, including its size on disk, creation date, and security permissions.
• **Right-Click Properties:** Accessing the 'Properties' option from the context menu to view detailed file information.
• **Read-Only Attribute:** A file property that prevents the file from being modified or overwritten.
• **Hidden Attribute:** A file property that makes a file invisible in standard folder views to prevent accidental deletion or modification.
• **System Attribute:** A file property assigned to critical OS files to protect them from user interference.
• **File Size Units:** Files are measured in Bytes (B), Kilobytes (KB), Megabytes (MB), Gigabytes (GB), and Terabytes (TB).
• **Search Filters:** Tools in the search box that allow users to narrow down results by date, size, or file type.
• **Wildcards:** Special characters like '*' (asterisk) used in searches to represent unknown parts of a filename.
• **File Association:** The relationship between a file type and the application that opens it by default.
• **Default Program:** The specific application that Windows automatically launches when you double-click a file of a certain type.
• **Open With:** A context menu option that allows you to choose a different program to open a file instead of the default one.
• **Shortcut:** An icon that acts as a pointer to a file or program, allowing quick access without moving the original file.
• **Shortcut Icon:** Distinguished by a small arrow in the bottom-left corner of the icon.

---PAGE-BREAK---

• **Windows Settings:** The central hub for configuring system preferences, user accounts, and hardware settings.
• **Control Panel:** A legacy component of Windows that provides advanced settings and system management tools.
• **Personalization:** Settings that allow users to change the desktop background, colors, lock screen, and themes.
• **Taskbar Settings:** Options to lock the taskbar, hide it automatically, or change its location on the screen.
• **Date and Time Settings:** Allows users to synchronize the system clock with internet time servers and change time zones.
• **Display Settings:** Used to adjust screen resolution, brightness, and text size for better readability.
• **User Accounts:** Settings that allow for the creation and management of different users on a single computer.
• **Administrator Account:** A user account with full control over the computer, including installing software and changing system settings.
• **Standard User Account:** A restricted account intended for daily use to prevent unauthorized system changes.
• **Power Options:** Settings that control how the computer uses energy, such as sleep mode, hibernate, and shutdown.
• **Sleep Mode:** A power-saving state that keeps documents and programs open in memory while the computer consumes very little power.
• **Hibernate:** A power-saving state that saves open documents to the hard disk and turns off the computer completely.
• **Shut Down:** Completely turns off the computer and closes all running programs.
• **Restart:** Closes all programs and reboots the operating system, often required after updates.
• **Sign Out:** Closes the current user's session, allowing another user to log in without turning off the computer.

• **File Management:** The systematic process of creating, organizing, naming, and maintaining files and folders.
• **Hierarchical Structure:** The tree-like arrangement of folders within folders, starting from a root drive.
• **Tree View:** A visual representation of the folder hierarchy, often seen in the Navigation Pane of File Explorer.
• **Parent Folder:** A folder that contains other folders (subfolders).
• **Subfolder:** A folder located inside another folder.
• **Root Directory:** The top-level directory of a drive (e.g., C:\), which contains all other files and folders.
• **Naming Conventions:** Best practices for naming files, such as using descriptive names and avoiding special characters like / \ : * ? " < > |.
• **Backup:** The process of creating copies of important files on an external drive or cloud storage to prevent data loss.
• **Cloud Storage:** Online storage services (like OneDrive) that sync files across multiple devices.
• **OneDrive:** A Microsoft service integrated into Windows for storing files in the cloud and accessing them from anywhere.
• **Syncing:** The process of ensuring that files on your computer match the files stored in the cloud.
• **File Compression:** Reducing the size of files to save space or make them easier to send via email.
• **Zip Folder:** A compressed folder that contains one or more files, often used for archiving or transferring data.
• **Extracting:** The process of decompressing files from a Zip folder to their original state.
• **Archive:** A collection of files stored in a single compressed file for long-term storage.

• **Task Manager:** A system utility used to monitor running processes, performance, and to force-close unresponsive applications.
• **Ctrl + Shift + Esc:** The direct keyboard shortcut to open the Task Manager.
• **End Task:** A command in Task Manager used to terminate a program that has stopped responding (frozen).
• **Performance Tab:** Shows real-time data about CPU, Memory, Disk, and Network usage.
• **System Tray Icons:** Small icons in the bottom right that provide quick access to system settings like Wi-Fi, Volume, and Battery.
• **Action Center:** A notification area in Windows that displays system alerts and provides quick access to common settings like Bluetooth and Night Light.
• **Windows Update:** A service that automatically downloads and installs security patches and feature updates for the OS.
• **Device Manager:** A tool used to view and manage hardware devices connected to the computer, such as printers or webcams.
• **Disk Cleanup:** A utility that helps free up space on the hard drive by deleting temporary files and system junk.
• **System Restore:** A feature that allows the user to revert the computer's state to a previous point in time if a problem occurs.
• **Safe Mode:** A diagnostic mode of Windows that starts the system with minimal drivers and services to troubleshoot issues.
• **Screen Resolution:** The number of pixels displayed on the screen, which determines the clarity and size of images and text.
• **Wallpaper:** The image or color used as the background of the desktop.
• **Screen Saver:** An animation or image that appears on the screen after a period of inactivity to prevent screen burn-in.
• **Theme:** A combination of desktop background, window colors, and sounds that changes the look and feel of Windows.

• **Keyboard Shortcuts:** Essential combinations that increase efficiency when navigating Windows.
• **Windows Key:** Opens the Start Menu.
• **Win + E:** Opens File Explorer directly.
• **Win + D:** Minimizes all open windows to show the Desktop.
• **Win + L:** Locks the computer screen.
• **Win + I:** Opens the Windows Settings app.
• **Win + R:** Opens the 'Run' dialog box for executing commands.
• **Alt + Tab:** Switches between currently open applications.
• **Alt + F4:** Closes the active window or shuts down the computer.
• **Print Screen (PrtSc):** Captures an image of the entire screen to the clipboard.
• **Win + Shift + S:** Opens the Snipping Tool to capture a specific part of the screen.
• **Esc Key:** Cancels the current operation or closes a menu.
• **Enter Key:** Opens a selected file or folder or executes a command.
• **Backspace Key:** Moves up one level in the folder hierarchy in File Explorer.
• **Arrow Keys:** Used to navigate through files and folders without using the mouse.

• **Maintenance:** Regular care of the computer system to ensure optimal performance and longevity.
• **Disk Defragmentation:** A process that reorganizes fragmented data on a hard drive to improve read/write speeds.
• **Antivirus Software:** Programs designed to detect, prevent, and remove malicious software (malware) from the computer.
• **Firewall:** A security system that monitors and controls incoming and outgoing network traffic to protect the computer.
• **User Account Control (UAC):** A security feature that notifies the user before changes are made to the computer that require administrator-level permissions.
• **Updates:** Keeping software and the OS updated is crucial for security and compatibility.
• **Data Security:** Protecting files from unauthorized access by using passwords or encryption.
• **File Permissions:** Settings that control who can read, write, or execute a specific file or folder.
• **Hidden Files:** Files that are not shown by default to prevent accidental modification of system files.
• **System Files:** Essential files required for the Windows OS to function correctly; these should never be deleted or moved.
• **Desktop Cleanup:** Keeping the desktop organized by moving files into appropriate folders to maintain a clean workspace.
• **Naming Consistency:** Using a standard naming format (e.g., Date_ProjectName) helps in quickly locating files.
• **Folder Structure:** A well-planned folder hierarchy makes it easier to manage large amounts of data.
• **Digital Citizenship:** Practicing responsible and ethical use of computer resources and respecting others' data.
• **Conclusion:** Mastering Windows and folder management is the foundation for all further computer learning and effective digital productivity.
