• **Computer System:** A computer is an electronic device that processes data according to a set of instructions called a program.
• **Hardware:** The physical, tangible parts of a computer system that you can touch and feel are known as hardware.
• **Software:** The set of instructions or programs that tell the computer hardware what to do is called software.
• **Interdependence:** Hardware and software are interdependent; hardware cannot function without software, and software cannot execute without hardware.
• **Input Devices:** These are hardware components used to enter data and instructions into the computer system.
• **Output Devices:** These are hardware components used to display or provide the results of processed data.
• **Processing Unit:** The Central Processing Unit (CPU) is the brain of the computer that performs all calculations and logical operations.
• **Storage Devices:** Hardware components used to store data and programs permanently or temporarily.
• **System Software:** A type of software that manages the computer hardware and provides a platform for other software to run.
• **Application Software:** Software designed to perform specific tasks for the user, such as word processing or gaming.
• **Data:** Raw facts and figures that are input into the computer for processing.
• **Information:** The meaningful output generated after the computer processes the raw data.
• **Peripheral Devices:** External hardware devices connected to the computer, such as printers, scanners, and webcams.
• **Motherboard:** The main circuit board inside the computer that connects all hardware components together.
• **Binary Language:** The machine-level language consisting of 0s and 1s that the hardware understands.

• **Keyboard:** The primary input device used to type text, numbers, and commands into the computer.
• **Mouse:** A pointing device used to interact with graphical user interfaces by clicking, dragging, and scrolling.
• **Scanner:** An input device that converts physical documents or images into digital format.
• **Microphone:** An input device used to capture audio signals and convert them into digital data.
• **Webcam:** A digital camera connected to a computer used for video conferencing and capturing images.
• **Joystick:** An input device primarily used for controlling movement in computer games.
• **Light Pen:** A sensitive pointing device used to draw directly on a screen or select objects.
• **Barcode Reader:** An input device used to read information stored in barcodes, commonly found in retail stores.
• **Trackball:** A stationary pointing device with a ball on top that is rotated to move the cursor.
• **Touchpad:** A flat, touch-sensitive surface found on laptops used as a substitute for a mouse.
• **Graphic Tablet:** An input device that allows users to hand-draw images and graphics using a stylus.
• **Biometric Sensor:** An input device that identifies individuals based on physical traits like fingerprints or retina scans.
• **Input Mechanism:** The process of converting human-readable data into machine-readable signals.
• **Ergonomics:** The study of designing input devices to ensure user comfort and prevent physical strain.
• **Input Accuracy:** The quality of input depends on the precision of the device and the user's interaction.

---PAGE-BREAK---

• **Monitor:** The primary output device that displays visual information, text, and graphics.
• **Printer:** An output device that produces a hard copy of digital documents on paper.
• **Speaker:** An output device that converts electrical signals into audible sound.
• **Headphones:** Personal output devices that allow users to listen to audio privately.
• **Projector:** An output device used to display computer output on a large screen or wall for an audience.
• **Plotter:** A specialized printer used for printing high-quality vector graphics, blueprints, and architectural designs.
• **LCD Monitor:** Liquid Crystal Display monitors that are thin, lightweight, and energy-efficient.
• **LED Monitor:** Light Emitting Diode monitors that offer better contrast and color accuracy than LCDs.
• **Impact Printer:** A type of printer that works by striking an ink ribbon against paper, such as dot-matrix printers.
• **Non-Impact Printer:** A type of printer that uses heat, laser, or ink droplets without physical impact, such as inkjet or laser printers.
• **Laser Printer:** A high-speed printer that uses laser technology to produce high-quality text and images.
• **Inkjet Printer:** A printer that sprays tiny droplets of ink onto paper to form characters and images.
• **Resolution:** The clarity of an image on a monitor or printout, measured in pixels or dots per inch (DPI).
• **Hard Copy:** The physical, printed version of a document.
• **Soft Copy:** The digital, electronic version of a document displayed on a screen.

• **CPU (Central Processing Unit):** The core component that executes instructions and processes data.
• **ALU (Arithmetic Logic Unit):** A part of the CPU that performs mathematical calculations and logical comparisons.
• **CU (Control Unit):** The part of the CPU that directs the flow of data and instructions between components.
• **MU (Memory Unit):** The part of the CPU that stores data and instructions temporarily during processing.
• **Microprocessor:** A single integrated circuit that contains the entire CPU on a small chip.
• **Clock Speed:** The speed at which a CPU executes instructions, measured in Gigahertz (GHz).
• **Cores:** Independent processing units within a single CPU that allow for multitasking.
• **Cache Memory:** A small, high-speed memory located inside or near the CPU for quick data access.
• **Processing Cycle:** The sequence of Fetch, Decode, Execute, and Store operations performed by the CPU.
• **Fetch:** The process of retrieving an instruction from the memory.
• **Decode:** The process of translating the instruction into a format the CPU can understand.
• **Execute:** The process of performing the operation specified by the instruction.
• **Store:** The process of writing the result of the operation back into the memory.
• **Heat Sink:** A metal component attached to the CPU to dissipate heat and prevent overheating.
• **Fan:** A cooling device used to circulate air around the CPU and other internal components.

---PAGE-BREAK---

• **Primary Memory:** The main memory of the computer, directly accessible by the CPU.
• **RAM (Random Access Memory):** Volatile memory that stores data currently in use; it is erased when power is turned off.
• **ROM (Read-Only Memory):** Non-volatile memory that stores essential startup instructions (BIOS) that cannot be changed.
• **Secondary Memory:** Non-volatile storage used for long-term data retention, such as hard drives and USB drives.
• **Hard Disk Drive (HDD):** A magnetic storage device with high capacity used for storing the operating system and files.
• **Solid State Drive (SSD):** A faster, more durable storage device that uses flash memory instead of spinning disks.
• **Optical Discs:** Storage media like CDs, DVDs, and Blu-ray discs that use laser technology to read and write data.
• **Flash Drive:** A portable, compact storage device that connects via a USB port.
• **Memory Card:** A small storage medium used in cameras, phones, and tablets.
• **Volatile Memory:** Memory that requires electricity to maintain the stored information.
• **Non-Volatile Memory:** Memory that retains data even when the power is switched off.
• **Bit:** The smallest unit of data, representing a single 0 or 1.
• **Byte:** A unit of digital information consisting of 8 bits.
• **Storage Capacity:** The amount of data a device can hold, measured in Kilobytes, Megabytes, Gigabytes, or Terabytes.
• **Data Retrieval:** The process of accessing and reading stored data from a storage medium.

• **System Software:** The foundation software that manages the computer's resources and provides a user interface.
• **Operating System (OS):** The most important system software that acts as an interface between the user and the hardware.
• **Examples of OS:** Windows, macOS, Linux, Android, and iOS.
• **Functions of OS:** Managing memory, processing, file systems, and hardware devices.
• **Booting:** The process of starting the computer and loading the operating system into RAM.
• **Utility Software:** Programs designed to help maintain, analyze, and optimize the computer system.
• **Antivirus:** Utility software that protects the computer from malicious programs and viruses.
• **Disk Defragmenter:** A utility that reorganizes fragmented data on a hard drive to improve performance.
• **Device Drivers:** Small programs that allow the operating system to communicate with specific hardware devices.
• **Language Translators:** Software that converts high-level programming languages into machine-level code.
• **Compiler:** A translator that converts the entire source code into machine code at once.
• **Interpreter:** A translator that converts source code line-by-line into machine code.
• **User Interface (UI):** The visual part of the software that allows the user to interact with the computer.
• **GUI (Graphical User Interface):** An interface that uses icons, windows, and menus to make interaction easy.
• **CLI (Command Line Interface):** An interface where users type text commands to interact with the system.

---PAGE-BREAK---

• **Application Software:** Software created to help users perform specific tasks or solve problems.
• **General Purpose Software:** Software designed for a broad range of tasks, such as word processing or spreadsheets.
• **Specific Purpose Software:** Software designed for a particular industry or task, such as payroll or accounting software.
• **Word Processor:** Software used for creating, editing, and formatting text documents (e.g., MS Word).
• **Spreadsheet Software:** Software used for organizing data in rows and columns and performing calculations (e.g., MS Excel).
• **Presentation Software:** Software used to create visual slideshows for presentations (e.g., MS PowerPoint).
• **Database Management System (DBMS):** Software used to store, manage, and retrieve large amounts of data (e.g., MS Access).
• **Graphic Design Software:** Software used for creating and editing images and illustrations (e.g., Adobe Photoshop).
• **Web Browser:** Application software used to access and view websites on the internet (e.g., Chrome, Edge).
• **Media Player:** Software used for playing audio and video files.
• **Communication Software:** Software used for sending emails, instant messaging, and video conferencing.
• **Educational Software:** Software designed to teach specific subjects or skills to students.
• **Gaming Software:** Application software designed for entertainment and interactive play.
• **Customized Software:** Software developed specifically for a particular client or organization's needs.
• **Freeware:** Software that is available for use at no cost.

• **System Unit:** The main cabinet or chassis that houses the internal hardware components of a computer.
• **Power Supply Unit (PSU):** The component that converts AC electricity from a wall outlet into DC power for the computer.
• **Expansion Slots:** Slots on the motherboard used to add extra functionality, such as graphics cards or sound cards.
• **Ports:** External connection points on the system unit used to connect peripheral devices.
• **USB Port:** Universal Serial Bus port, the most common interface for connecting various peripherals.
• **HDMI Port:** High-Definition Multimedia Interface used for transmitting high-quality audio and video signals.
• **Ethernet Port:** A port used for connecting the computer to a wired network or internet.
• **Audio Jack:** A port used for connecting speakers, microphones, or headphones.
• **VGA Port:** Video Graphics Array port used for connecting older monitors and projectors.
• **BIOS (Basic Input/Output System):** Firmware used to perform hardware initialization during the booting process.
• **Firmware:** A specific class of computer software that provides low-level control for a device's specific hardware.
• **Bus:** A communication system that transfers data between components inside a computer.
• **System Bus:** The main pathway that connects the CPU, memory, and other components.
• **Data Bus:** A bus that carries the actual data being processed.
• **Address Bus:** A bus that carries information about where the data should be sent or retrieved.

• **Software Lifecycle:** The process of developing, testing, and maintaining software.
• **Proprietary Software:** Software that is owned by an individual or company, and users must purchase a license to use it.
• **Open Source Software:** Software whose source code is available for anyone to inspect, modify, and enhance.
• **Shareware:** Software that is distributed for free on a trial basis, often with limited features.
• **Malware:** Malicious software designed to harm, disrupt, or gain unauthorized access to a computer system.
• **Updates:** Improvements or patches released by software developers to fix bugs or add new features.
• **Upgrades:** New versions of software that offer significant changes or improvements over the previous version.
• **Software License:** A legal instrument governing the use or redistribution of software.
• **End User License Agreement (EULA):** A contract between the software developer and the user.
• **Compatibility:** The ability of software to run on a specific operating system or hardware configuration.
• **System Requirements:** The minimum hardware and software specifications needed to run a particular program.
• **Installation:** The process of setting up software on a computer so it can be executed.
• **Uninstallation:** The process of removing software from a computer system.
• **File Extension:** A suffix at the end of a filename that indicates the file type (e.g., .docx, .jpg).
• **Directory/Folder:** A container used to organize files on a storage device.

---PAGE-BREAK---

• **Hardware Maintenance:** Keeping physical components clean and cool to ensure longevity.
• **Software Maintenance:** Regularly updating software and running security scans to keep the system healthy.
• **Data Backup:** The process of creating copies of data to protect against loss or corruption.
• **Cloud Storage:** Storing data on remote servers accessed via the internet instead of local hardware.
• **Computer Ethics:** The moral principles that govern the use of computers and software.
• **Piracy:** The unauthorized copying, distribution, or use of software, which is illegal.
• **Copyright:** Legal protection for software developers, preventing others from stealing their work.
• **Cybersecurity:** The practice of protecting systems, networks, and programs from digital attacks.
• **Firewall:** A security system that monitors and controls incoming and outgoing network traffic.
• **Encryption:** The process of encoding information so that only authorized parties can access it.
• **Password Protection:** A security measure to restrict access to a computer or specific files.
• **System Restore:** A feature that allows users to revert the computer's state to a previous point in time.
• **Troubleshooting:** The process of identifying and fixing problems with hardware or software.
• **Safe Mode:** A diagnostic mode of an operating system that runs with minimal drivers and services.
• **Future Trends:** The evolution of hardware towards smaller, faster components and software towards AI-driven automation.
