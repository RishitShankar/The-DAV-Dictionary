• **DAV Introduction to GIMP Overview**: This chapter introduces Class 7 students to GIMP (GNU Image Manipulation Program), a powerful, open-source, and free raster graphics editor used for image retouching, image composition, and image authoring.
• **Open Source Software Definition**: GIMP is classified as Free and Open Source Software (FOSS), meaning its source code is publicly available for anyone to view, modify, distribute, and enhance without purchasing any expensive commercial licenses.
• **Cross-Platform Compatibility**: GIMP is a highly versatile cross-platform application that operates seamlessly across multiple operating systems, including various distributions of Linux, Microsoft Windows, and macOS.
• **Primary Purpose in ICT**: In the Class 7 Hands-on Computer curriculum, GIMP serves as an essential tool for understanding digital image processing, raster graphics, color management, layers, and visual communication principles.
• **Raster Graphics Core Concept**: Unlike vector graphics (which use mathematical formulas), GIMP deals exclusively with raster graphics, meaning images are composed of a grid of tiny colored squares known as pixels.
• **Pixel Definition**: A pixel (picture element) is the fundamental smallest individual unit of a digital image displayed on a computer screen, containing specific color and brightness data.
• **Image Resolution Concept**: Resolution refers to the level of detail visible in a digital image, typically measured in Pixels Per Inch (PPI) or dots per inch, which directly dictates image clarity when printed or zoomed.
• **GIMP Mascot Feature**: The official mascot of GIMP is a friendly cartoon raccoon named Wilber, who frequently appears in loading screens, splash art, and community documentation to welcome users.
• **Historical Development Origin**: GIMP was originally created in 1995 by Spencer Kimball and Peter Mattis as a semester project at the University of California, Berkeley, before evolving into a global community project.
• **GNU Project Integration**: GIMP is an official part of the GNU Project, supporting the philosophy of user freedom and collaborative software development promoted by the Free Software Foundation.
• **File Format Associations**: GIMP supports a vast array of standard and specialized image file formats, allowing students to open, edit, convert, and save digital media effortlessly.
• **Native GIMP File Extension**: The native working file format of GIMP is `.xcf`, which stands for Experimental Computing Facility, preserving all layers, channels, transparency, and paths.
• **Common Export Formats**: While `.xcf` is used for working projects, completed GIMP creations are typically exported to universal formats like `.jpg`, `.png`, `.gif`, or `.bmp` for viewing on the web.
• **Installation and Accessibility**: GIMP can be safely downloaded from its official website (`gimp.org`) or accessed via school laboratory computer management systems as directed by the computer instructor.
• **Educational Utility**: Mastering GIMP at the middle school level builds foundational visual literacy, creative confidence, and technical competence required for advanced digital design in higher classes.

• **Launching GIMP**: To start GIMP on a Windows operating system, a student must navigate through the Start menu, locate the GNU Image Manipulation Program shortcut, and click it to initiate the software.
• **Splash Screen Appearance**: Upon launching, GIMP displays an artistic loading splash screen featuring Wilber the raccoon alongside a progress bar that loads various fonts, brushes, and modules into system memory.
• **Default Single-Window Interface**: Modern versions of GIMP utilize a streamlined single-window user interface by default, keeping all toolboxes, docks, and image canvases organized within one cohesive application window.
• **Multi-Window Mode Option**: For users who prefer legacy setups, GIMP allows switching to a multi-window mode via the Windows menu, separating the toolbox, dockable dialogs, and image window into floating entities.
• **Image Canvas Area**: The central workspace in GIMP is the image canvas, which represents the digital drawing board where the active image file is displayed, edited, and manipulated.
• **Main Menu Bar Location**: Positioned at the very top of the GIMP window, the Menu Bar contains comprehensive category dropdowns including File, Edit, Select, View, Image, Layer, Colors, Tools, Filters, Windows, and Help.
• **Toolbox Panel Purpose**: The Toolbox is a compact vertical panel housing quick-access icons for selection tools, painting tools, transformation tools, color pickers, and zoom utilities.
• **Tool Options Dock**: Located directly beneath or attached to the Toolbox, the Tool Options dialog dynamically changes to display specific settings and parameters for whichever tool is currently selected.
• **Layers Dialog Dock**: Positioned usually on the right side of the default workspace, the Layers dialog manages the stacking order, transparency, visibility, and blending modes of individual image layers.
• **Brushes and Patterns Dock**: Adjacent to the Layers dialog, the Brushes, Patterns, and Gradients docks allow users to select various artistic textures and stamp styles for painting applications.
• **Status Bar Information**: Situated at the bottom of the image window, the Status Bar provides real-time contextual information such as cursor coordinates, current zoom percentage, and image dimensions.
• **Zoom Controls in GIMP**: Users can adjust their canvas magnification using the Zoom tool, the view menu, or the shortcut percentage dropdown located at the bottom-left corner of the image window.
• **Workspace Customization**: GIMP allows students and teachers to customize their workspace by dragging and docking dialog tabs, saving custom layouts, or resetting default preferences if needed.
• **Full Screen Mode Toggle**: Pressing the `F11` key on the keyboard toggles Full Screen mode in GIMP, hiding operating system window borders to provide an immersive editing environment.
• **Exiting the Application**: To close GIMP safely, users can click the standard close button (`X`), select `Quit` from the File menu, or press the keyboard shortcut `Ctrl + Q`.

• **Creating a New Image**: To start a fresh digital drawing or composition in GIMP, the user selects `File > New` from the menu bar or uses the keyboard shortcut `Ctrl + N`.
• **Create a New Image Dialog**: The New Image dialog box appears, allowing users to configure precise initial parameters such as image width, height, resolution, and background fill color.
• **Image Dimensions Configuration**: Width and height can be measured in various units within GIMP, with pixels (`px`) being the standard unit for screen-based digital graphics.
• **Advanced Template Options**: The New Image dialog provides pre-set templates for standard paper sizes (like A4, Letter), web banners, and video resolutions to simplify project setup.
• **Advanced Options Expansion**: Clicking the Advanced Options dropdown in the New Image dialog reveals settings for X/Y resolution, precise color spaces (RGB vs. Grayscale), and precision depths.
• **Background Fill Choices**: When creating a new image, users can choose whether the background canvas is filled with the current Foreground color, Background color, White, or Transparency.
• **Opening Existing Images**: To edit a previously saved image file, students select `File > Open` (`Ctrl + O`), browse through the computer directory, and select the desired file.
• **Recent Files Access**: GIMP maintains a quick-access list under `File > Open Recent`, allowing users to reopen projects they worked on previously without navigating through folder paths.
• **Saving Projects (`.xcf`)**: To preserve all editing layers and modifications for future work, users must save their project using `File > Save` or `File > Save As` with the `.xcf` extension.
• **Exporting Final Images**: Because standard image viewers cannot read `.xcf` files, finished creations must be exported using `File > Export As` to convert them into `.jpg` or `.png` formats.
• **JPEG Format Characteristics**: JPEG (Joint Photographic Experts Group) is a lossy compression format ideal for photographs and continuous-tone images, supporting millions of colors but not transparency.
• **PNG Format Characteristics**: PNG (Portable Network Graphics) is a lossless compression format that supports full alpha channel transparency, making it superior for logos, icons, and web graphics.
• **Unsaved Changes Warning**: If a user attempts to close GIMP or an image tab with unsaved modifications, GIMP displays a warning dialog prompting them to save, discard, or cancel.
• **Reverting to Saved State**: If an editing session goes wrong, users can revert their entire canvas back to the last saved state by navigating to `File > Revert`.
• **Document History Management**: GIMP keeps track of open document metadata, helping students manage multiple digital assets simultaneously within a single software session.

• **Selection Tools Category**: Selection tools in GIMP are fundamental utilities used to isolate specific areas of an image, allowing edits, color changes, or transformations to apply only to the selected region.
• **Rectangle Select Tool**: The Rectangle Select tool (shortcut `R`) allows users to draw rectangular or square selection boundaries on the canvas by clicking and dragging diagonally.
• **Ellipse Select Tool**: The Ellipse Select tool (shortcut `E`) enables users to create circular or elliptical selections, perfect for isolating round objects or creating glowing light effects.
• **Free Select (Lasso) Tool**: The Free Select tool (shortcut `F`) lets users draw freehand custom boundary outlines around irregular shapes by clicking and dragging the mouse cursor.
• **Fuzzy Select (Magic Wand) Tool**: The Fuzzy Select tool (shortcut `U`) selects contiguous areas of similar color based on a tolerance threshold when clicked on a specific pixel.
• **Select by Color Tool**: The Select by Color tool selects all pixels matching a chosen color value across the entire image canvas, regardless of whether they are physically connected or adjacent.
• **Scissors (Intelligent Scissors) Tool**: The Intelligent Scissors tool creates selections by snapping boundary curves automatically to high-contrast edges detected within the image.
• **Foreground Select Tool**: The Foreground Select tool allows users to coarsely paint over an object to isolate it from its background using advanced algorithmic background subtraction.
• **Paths Tool for Selection**: The Paths tool (Pen tool) uses vector control points and bezier curves to create extremely precise, professional-grade selections and clipping masks.
• **Selection Modification Operations**: Once a selection is made, it can be modified using commands under the Select menu, such as `Grow`, `Shrink`, `Feather`, `Invert`, and `Border`.
• **Inverting a Selection**: Inverting a selection (shortcut `Ctrl + I`) reverses the active area, turning an unselected background into the active selection and vice versa.
• **Feathering Selection Edges**: Feathering softens the hard outer boundary of a selection by a specified pixel radius, blending pasted or edited elements smoothly into their surroundings.
• **Clearing and Deleting Selections**: Pressing the `Delete` key while a selection is active erases the pixels inside it (revealing the background or transparency layer underneath).
• **Floating Selection State**: Pasting an image element into a selection often creates a temporary Floating Selection that must be anchored to a layer before proceeding with other actions.
• **Deselecting Active Areas**: To remove all active selection marching ants from the canvas, the user presses the keyboard shortcut `Shift + Ctrl + A` or selects `Select > None`.

• **Paint Tools Overview**: GIMP provides a comprehensive suite of digital painting and retouching tools that allow users to draw freehand, apply textures, and modify existing pixel colors dynamically.
• **Paintbrush Tool Function**: The Paintbrush tool (shortcut `P`) applies brush strokes with smooth anti-aliased edges, making it the primary tool for digital illustration and freehand painting.
• **Pencil Tool Characteristics**: Unlike the Paintbrush, the Pencil tool (shortcut `N`) creates hard-edged, aliased pixel strokes without any smoothing or soft blending along the edges.
• **Eraser Tool Purpose**: The Eraser tool (shortcut `Shift + E`) removes pixels from the active layer, exposing underlying layers or background transparency depending on the layer's alpha channel.
• **Bucket Fill Tool Operation**: The Bucket Fill tool (shortcut `Shift + B`) fills bounded regions or entire selections with the current foreground color, a selected pattern, or a smooth gradient.
• **Gradient Tool Mechanics**: The Gradient tool (shortcut `G`) draws smooth, multicolored transitions between two or more colors across the canvas or within an active selection area.
• **Ink Tool Simulation**: The Ink tool simulates a calligraphy pen, drawing vector-based brush strokes that dynamically change thickness based on the speed of the mouse movement.
• **Airbrush Tool Dynamics**: The Airbrush tool applies paint with a pressure-dependent rate, building up color intensity continuously the longer the mouse button is held down in one spot.
• **Clone Tool Retouching**: The Clone tool (shortcut `C`) copies pixel samples from a source point defined by the user (using `Ctrl + click`) and paints them onto a destination area to repair blemishes.
• **Heal Tool Advanced Retouching**: Similar to the Clone tool, the Heal tool seamlessly repairs image imperfections by blending the texture of the source sample with the lighting of the target area.
• **Blur and Sharpen Tool**: The Blur/Sharpen tool softens or hardens the local contrast of image details when brushed over specific areas, useful for softening backgrounds or enhancing eye details.
• **Smudge Tool Effect**: The Smudge tool smears and blends colors together on the active layer, mimicking the physical effect of dragging a finger across wet paint or charcoal.
• **Dodge and Burn Tools**: The Dodge tool lightens specific areas of an image, while the Burn tool darkens them, emulating traditional darkroom photographic manipulation techniques.
• **Foreground and Background Colors**: The Toolbox displays two overlapping color swatches representing the active Foreground (drawing) color and Background (filling) color, which can be swapped easily.
• **Color Picker Tool Function**: The Color Picker tool (shortcut `O`) samples any color from the image canvas instantly, making it the active foreground color for subsequent painting tasks.

• **Transform Tools Definition**: Transform tools in GIMP are geometric utilities used to alter the size, shape, angle, perspective, or alignment of images, selections, paths, or individual layers.
• **Move Tool Operation**: The Move tool (shortcut `M`) repositions active layers, guides, or selection masks across the canvas by clicking and dragging them to a new spatial location.
• **Align Tool Precision**: The Align tool provides automated alignment and distribution options for multiple selected layers or objects relative to each other or to the image canvas.
• **Crop Tool Functionality**: The Crop tool (shortcut `Shift + C`) trims unwanted outer portions of an image canvas, reducing overall file dimensions and focusing attention on the subject.
• **Unified Transform Tool**: The Unified Transform tool combines scaling, rotating, shearing, and perspective manipulation into a single interactive on-canvas control widget.
• **Scale Tool Resizing**: The Scale tool (shortcut `Shift + T`) alters the pixel dimensions of a layer or selection, expanding or shrinking it while optionally maintaining its aspect ratio.
• **Rotate Tool Mechanics**: The Rotate tool (shortcut `Shift + R`) spins an image or layer around a central pivot point by a specific angle or freehand rotation.
• **Shear Tool Slanting**: The Shear tool skews an image layer horizontally or vertically along an axis, creating geometric parallelogram distortions and slanting effects.
• **Perspective Tool Depth**: The Perspective tool alters the spatial depth of an image layer by adjusting its four corner handles independently to simulate three-dimensional angles.
• **Flip Tool Mirroring**: The Flip tool (shortcut `Shift + F`) mirrors an image layer or selection horizontally or vertically along its axis to create reflection symmetry.
• **Aspect Ratio Locking**: When scaling or transforming objects, clicking the chain icon in tool options locks the aspect ratio to prevent unnatural stretching or squishing of the image.
• **Interpolation Methods**: When transforming raster graphics, GIMP uses mathematical interpolation methods (like Cubic or Sinc) to calculate new pixel values smoothly without excessive blurring.
• **Transform Layer vs. Selection**: Users can choose whether the transform tool affects the entire active layer, only the floating selection, or just a linked path.
• **Resetting Transform Parameters**: If a transformation goes awry, clicking the Reset button in the Tool Options dialog instantly reverts the object back to its original untransformed state.
• **Executing Transformations**: Once transformation handles are adjusted, clicking the `Transform` button or pressing `Enter` confirms and applies the geometric changes permanently to the layer.

• **Layers Concept Foundation**: Layers are transparent, independent sheets stacked on top of one another in GIMP, allowing complex digital artworks to be built and edited without damaging other elements.
• **Analogous Stack Metaphor**: Layers function like sheets of clear acetate stacked in a vertical column; what is drawn on upper layers obscures what lies beneath, except where transparent areas exist.
• **Layers Dialog Management**: The Layers Dialog is the central hub for managing all layer-based operations, located typically on the right side of the default single-window interface.
• **Adding a New Layer**: Clicking the "Create a New Layer" button at the bottom of the Layers dialog opens a setup window to name the layer, set its dimensions, and choose its fill type.
• **Layer Transparency (`Alpha Channel`)**: Most standard layers include an alpha channel, which stores transparency information, allowing portions of underlying layers to show through.
• **Layer Stacking Order**: Users can change the visual depth of elements by clicking and dragging layers up or down within the Layers dialog list.
• **Layer Visibility Toggle**: Each layer in the dialog features an eye icon; clicking this icon toggles the visibility of that specific layer on or off without deleting its contents.
• **Locking Layer Attributes**: Users can lock a layer's pixels, alpha channel, or position to prevent accidental edits or unwanted brush strokes while working on complex projects.
• **Duplicate Layer Feature**: Right-clicking a layer and selecting `Duplicate Layer` creates an exact copy of the layer, useful for experimenting with special effects or backup preservation.
• **Merging Layers**: Layers can be merged downward or combined into a single flat image (`Merge Visible Layers` or `Flatten Image`) to reduce file size when project editing is finished.
• **Layer Opacity Slider**: The Opacity slider at the top of the Layers dialog controls the transparency level of the active layer, ranging from 0% (fully invisible) to 100% (fully opaque).
• **Layer Blend Modes**: Blend modes determine how the pixels of the active layer mathematically interact with the pixels of the layers directly beneath it (e.g., Multiply, Screen, Overlay).
• **Deleting a Layer**: Selecting an unwanted layer in the dialog and clicking the trash can icon permanently removes that layer and its contents from the project canvas.
• **Floating Layer Anchoring**: When pasting external images into GIMP, they appear as floating layers that must be anchored to the active background or converted to a normal layer.
• **Layer Masks Introduction**: Layer masks allow students to hide or reveal parts of a layer using black and white paint without permanently erasing the actual image pixels.

• **Color Adjustment Tools**: GIMP features a dedicated `Colors` menu containing professional tools designed to modify image tones, contrast, saturation, and overall color balance.
• **Brightness and Contrast**: The Brightness-Contrast tool provides simple slider controls to make an entire image lighter or darker while adjusting the distinction between light and dark areas.
• **Hue and Saturation**: The Hue-Saturation tool allows users to shift overall color tones (Hue), adjust color intensity (Saturation), and modify brightness (Lightness) for specific color channels.
• **Color Balance Adjustment**: The Color Balance tool modifies the mix of colors in an image across shadows, midtones, and highlights, helping to correct lighting casts or create cinematic moods.
• **Desaturate (Grayscale Conversion)**: The Desaturate command strips all color data from an active layer or image, converting full-color photographs into classic black-and-white grayscale pictures.
• **Levels Tool Histogram**: The Levels tool displays a graphical histogram representing shadow, midtone, and highlight distribution, allowing precise tonal range correction via input and output sliders.
• **Curves Tool Mastery**: The Curves tool provides an interactive diagonal graph line that users can click and bend to reshape tonal values and contrast curves with extreme surgical precision.
• **Invert Colors Effect**: The Invert command reverses every color on the active layer to its exact photographic negative (e.g., black becomes white, blue becomes orange), creating striking surreal effects.
• **Threshold Tool Bi-leveling**: The Threshold tool converts a grayscale image into high-contrast black-and-white pixels based on a chosen luminance cutoff point, resembling a photocopied silhouette.
• **Posterize Tool Effect**: The Posterize tool reduces the number of distinct color tones in an image to a specified level, giving photographs a flat, retro comic-book or printed poster aesthetic.
• **Color Temperature Adjustment**: Users can warm up or cool down the color temperature of photographs to simulate different times of day or environmental lighting conditions.
• **Sepia Tone Effect**: By adjusting color balance and saturation, students can apply a vintage brownish sepia tone to modern images, mimicking 19th-century photographic prints.
• **Poster Printing Preparation**: Color adjustment tools ensure that digital creations look vibrant and correctly balanced before exporting them for digital display or classroom printing.
• **Non-Destructive Adjustments via New Layers**: Advanced students often duplicate layers before applying heavy color adjustments to preserve original pixel data if the result is unsatisfactory.
• **Preview Checkbox Utility**: Almost all color adjustment dialogue boxes in GIMP feature a `Preview` checkbox, allowing users to view changes on the canvas in real-time before confirming.

• **Filters and Special Effects**: The `Filters` menu in GIMP offers an extensive library of automated algorithmic effects that can instantly transform ordinary images into artistic masterpieces.
• **Blur Filters Category**: Blur filters (such as Gaussian Blur, Motion Blur, and Pixelize) soften image details or simulate camera motion, depth-of-field, and digital censoring.
• **Distorts Filters Category**: Distortion filters (such as Page Curl, Emboss, Whirl and Pinch, and Wind) warp and bend image pixels into creative physical shapes and textures.
• **Light and Shadow Filters**: These filters add artificial lighting effects, lens flares, sparkles, or drop shadows to make flat elements appear dimensional and realistic on the canvas.
• **Artistic Filters Category**: Artistic filters transform photographic images to resemble physical media, such as Cartoon style, Cubism, Canvas textures, or Ink splatters.
• **Decor Filters Category**: Decor filters add borders, frames, rounded corners, or watermarks automatically around image selections to give projects a polished presentation look.
• **Map Filters Category**: Map filters can wrap flat 2D images around 3D geometric shapes like spheres, cylinders, or boxes, or tile patterns seamlessly across a canvas.
• **Noise Filters Category**: Noise filters add random pixel variations to simulate film grain, dust, or digital interference, or conversely, remove speckles from scanned photographs.
• **Render Filters Category**: Render filters generate computer-drawn graphical elements from scratch, including fractal patterns, grid lines, checkerboards, clouds, and flame designs.
• **Web Filters Category**: Web-specific filters help create image maps, slice images for website loading, or optimize graphics for online publication formats.
• **Repeat Last Filter Shortcut**: Pressing `Ctrl + F` immediately re-applies the most recently used filter with its previous settings, saving time during iterative creative experimentation.
• **Alpha to Logo Effect**: GIMP includes script-fu plugins under File/Filters that automatically generate professional 3D text titles with bevels, shadows, and textures instantly.
• **Customizing Filter Parameters**: Every filter opens a configuration dialog with sliders and input boxes, allowing students to fine-tune effect intensity, radius, and behavior.
• **Processing Time Warning**: Heavy filters applied to high-resolution images require significant computer processing power, occasionally displaying a temporary progress bar during rendering.
• **Creative Expression in ICT**: Filters encourage Class 7 students to explore digital aesthetics, combining multiple filter layers with blend modes to invent unique graphic compositions.

• **Text Tool Functionality**: The Text tool (shortcut `T`) allows users to type, format, and place editable typographic characters directly onto the image canvas or onto a dedicated text layer.
• **Text Tool Interaction**: Clicking the canvas with the Text tool creates a bounding text box where students can type titles, captions, or watermarks using the system's installed fonts.
• **Font Family Selection**: Through the Tool Options or Text Editor panel, users can browse and select from hundreds of font styles, ranging from classic serif types to playful display fonts.
• **Font Size and Units**: Font size can be adjusted easily in pixels or points, allowing precise scaling of headings and subheadings within digital posters and greeting cards.
• **Text Styling Options**: Standard formatting buttons within the text tool options enable bold, italic, underlined, and strikethrough styling for selected blocks of text.
• **Text Alignment Controls**: Typographic alignment options permit left-aligned, right-aligned, centered, or justified text formatting within the active text bounding box.
• **Line and Letter Spacing**: Advanced text settings allow students to adjust baseline spacing (leading) and character tracking (kerning) to achieve professional typographic layout results.
• **Coloring Text Elements**: Text color is determined by the active foreground color swatch in the toolbox, but individual letters can be re-colored by highlighting them within the text editor.
• **Automatic Text Layer Creation**: Typing text in GIMP automatically generates a special editable Text Layer in the Layers dialog, denoted by a capital 'T' icon on the layer thumbnail.
• **Editing Existing Text**: To modify text content after creation, students simply select the Text tool, click inside the existing text box on the canvas, and make necessary edits.
• **Path to Text Conversion**: GIMP allows users to convert text outlines into vector paths (`Path from Text`), enabling advanced artistic distortions along curved geometrical lines.
• **Drop Shadow on Text**: Adding a Drop Shadow filter to a text layer lifts the lettering visually off the background, enhancing legibility against complex or photographic backgrounds.
• **Stroking Text Outlines**: Users can outline text characters with a colored border using `Path` or selection methods, creating bold comic-book style heading effects.
• **Saving Text Projects (.xcf)**: Maintaining text layers as editable `.xcf` files is crucial because exporting to `.jpg` flattens text into uneditable raster pixels.
• **Classroom Project Applications**: Mastery of the Text Tool empowers students to design professional school banners, event invitations, book covers, and digital infomercials efficiently.
