• **Introduction to Computer Parts**: A computer is a machine made up of several different parts that work together to perform tasks.
• **The Four Main Parts**: The primary components of a desktop computer system are the Monitor, CPU, Keyboard, and Mouse.
• **System Interdependence**: Each part of the computer has a specific role, and the system cannot function effectively if one of these core parts is missing.
• **The Monitor**: Often referred to as the **VDU (Visual Display Unit)**, it acts as the primary output device for visual information.
• **Screen Functionality**: The monitor displays everything we type, draw, or process on the computer screen.
• **Appearance of a Monitor**: A monitor looks very similar to a television screen and comes in various sizes and types, such as LCD or LED.
• **Visual Output**: The monitor allows the user to see the results of the work performed by the computer in real-time.
• **The CPU**: The **Central Processing Unit** is known as the "Brain of the Computer" because it controls all other parts.
• **CPU Cabinet**: The CPU is housed inside a metal box called the **System Unit** or CPU Cabinet.
• **Processing Power**: The CPU performs all the calculations, logic operations, and data processing required by the user.
• **Data Handling**: It receives instructions from the input devices and sends the processed information to the output devices.
• **Storage Role**: The CPU cabinet also contains internal storage components that hold the computer's memory and programs.
• **The Keyboard**: The keyboard is the primary **Input Device** used to enter data into the computer.
• **Typing Mechanism**: It consists of a set of buttons called **Keys** that are pressed to type letters, numbers, and symbols.
• **Standard Layout**: Most keyboards follow the **QWERTY** layout, named after the first six letters on the top row of the letter keys.
• **Functionality**: When a key is pressed, an electrical signal is sent to the CPU, which then displays the corresponding character on the monitor.
• **Special Keys**: Keyboards include special keys like the **Spacebar**, **Enter key**, and **Backspace key** to perform specific formatting tasks.
• **The Mouse**: The computer mouse is a **Pointing Device** used to interact with items on the computer screen.
• **Physical Structure**: A standard mouse usually has two buttons (left and right) and a scroll wheel in the middle.
• **Mouse Movement**: Moving the mouse on a flat surface moves the **Pointer** (or cursor) on the monitor screen.

• **Clicking Action**: Pressing the left mouse button once is called a **Single Click**, which is used to select an item on the screen.
• **Double-Clicking**: Pressing the left mouse button twice quickly is called a **Double-Click**, used to open files or programs.
• **Right-Clicking**: Pressing the right mouse button once opens a **Context Menu** that shows a list of options for the selected item.
• **Scrolling**: The **Scroll Wheel** located between the buttons allows the user to move up and down through long documents or web pages.
• **Mouse Pad**: A mouse should always be kept on a **Mouse Pad** to ensure smooth movement and prevent dust from entering the sensor.
• **Input vs. Output**: A computer system is categorized into input devices, processing units, and output devices.
• **Input Devices**: These are tools used to provide data and instructions to the computer, such as the keyboard and mouse.
• **Output Devices**: These are tools that display or provide the results of the processing, such as the monitor and printer.
• **The Printer**: A printer is an **Output Device** used to take information from the computer and put it on paper.
• **Hard Copy**: The paper output produced by a printer is known as a **Hard Copy**, while the digital version on the screen is a **Soft Copy**.
• **Types of Printers**: Common types include **Inkjet Printers** (using liquid ink) and **Laser Printers** (using toner powder).
• **Speakers**: Speakers are output devices used to listen to music, sounds, and voice recordings from the computer.
• **Sound Quality**: Speakers convert electrical signals from the computer into sound waves that we can hear.
• **Headphones**: Headphones are a personal type of speaker that allows a user to listen to audio without disturbing others.
• **Microphone**: A microphone is an **Input Device** used to record sound, voice, or music into the computer.
• **Voice Input**: Microphones are essential for voice commands, online chatting, and recording audio files.
• **UPS**: The **Uninterruptible Power Supply** is a device that keeps the computer running for a short time during a power cut.
• **Surge Protection**: The UPS also protects the computer from sudden voltage fluctuations that could damage internal components.
• **Battery Backup**: It provides a temporary power source, allowing the user to save their work and shut down the computer safely.
• **Peripheral Devices**: Any device connected to the computer that is not part of the core system is called a **Peripheral**.

• **Computer Cables**: All parts of the computer are connected to the CPU cabinet using various **Wires and Cables**.
• **Power Cables**: These cables supply electricity from the wall socket to the computer parts to make them work.
• **Data Cables**: These cables carry information between the CPU and the input/output devices.
• **Port Connections**: The back of the CPU cabinet has several **Ports** (slots) where the cables for the monitor, keyboard, and mouse are plugged in.
• **Safety First**: Never touch electrical wires or plugs with wet hands to avoid the risk of an electric shock.
• **Proper Shutdown**: Always shut down the computer using the software menu before turning off the power button on the CPU.
• **Computer Maintenance**: Keep the computer parts clean by using a soft, dry cloth to wipe away dust.
• **Dust Prevention**: Covering the computer with a dust cover when not in use helps keep the internal components clean and functional.
• **Handling Hardware**: Always handle computer parts with care; do not drop or hit them, as they contain delicate electronic parts.
• **Keyboard Care**: Do not eat or drink near the keyboard, as crumbs or liquid spills can damage the keys and internal circuits.
• **Mouse Maintenance**: Clean the bottom of the mouse regularly to ensure the sensor can track movement accurately.
• **Monitor Care**: Avoid touching the monitor screen with fingers, as oils from the skin can leave smudges and attract dust.
• **Cable Management**: Keep cables organized and untangled to prevent tripping hazards and damage to the wire connections.
• **Ventilation**: Ensure the CPU cabinet has enough space around it for air to circulate, preventing the system from overheating.
• **Computer Desk**: Place the computer on a sturdy, flat table to ensure all parts are stable and safe from falling.
• **Posture**: Sit straight in front of the computer to avoid back and neck strain while using the keyboard and mouse.
• **Eye Health**: Maintain a comfortable distance from the monitor screen to protect your eyes from strain.
• **Volume Control**: Keep the volume of speakers or headphones at a moderate level to protect your hearing.
• **Software vs. Hardware**: Hardware refers to the physical parts you can touch, while software refers to the programs that run on the computer.
• **The Complete System**: A functional computer requires both hardware (the parts) and software (the instructions) to work together.

• **The Monitor Screen**: The screen is made of millions of tiny dots called **Pixels** that light up to form images.
• **Resolution**: The clarity of the image on the monitor depends on the number of pixels; more pixels mean a sharper image.
• **Brightness Control**: Most monitors have buttons on the side or bottom to adjust the brightness and contrast of the display.
• **Power Button**: Every monitor has a dedicated power button to turn the display on or off independently of the CPU.
• **Monitor Stand**: The stand supports the monitor and allows for slight tilting to adjust the viewing angle for the user.
• **CPU Processing Speed**: The CPU processes millions of instructions every second, making it incredibly fast.
• **Internal Components**: Inside the CPU cabinet, there is a **Motherboard**, which is the main circuit board connecting all components.
• **Memory (RAM)**: The CPU uses **RAM (Random Access Memory)** to store information temporarily while the computer is running.
• **Storage (Hard Drive)**: The **Hard Disk Drive** is the permanent storage area where files, photos, and programs are saved even when the power is off.
• **Keyboard Keys**: The keyboard is divided into different sections, including the **Alphabet Keys** (A-Z) and **Number Keys** (0-9).
• **Navigation Keys**: These include the **Arrow Keys** (Up, Down, Left, Right) used to move the cursor around the screen.
• **Function Keys**: These are the keys labeled F1 through F12, which perform special tasks depending on the program being used.
• **Control Keys**: Keys like **Ctrl**, **Alt**, and **Shift** are used in combination with other keys to perform specific commands.
• **Spacebar**: The longest key on the keyboard, used to add a blank space between words or characters.
• **Enter Key**: Used to move the cursor to the next line or to confirm a command given to the computer.
• **Backspace Key**: Used to delete characters typed to the left of the cursor.
• **Delete Key**: Used to remove characters or items selected to the right of the cursor.
• **Caps Lock**: A key that, when activated, allows the user to type all letters in uppercase (Capital letters).
• **Num Lock**: A key that enables or disables the numeric keypad on the right side of the keyboard.
• **Keyboard Lights**: Small indicator lights on the keyboard show the status of Caps Lock, Num Lock, and Scroll Lock.

• **Mouse Sensors**: Modern mice use an **Optical Sensor** (a red light) on the bottom to track movement instead of a mechanical ball.
• **Wireless Mouse**: Some mice do not have a cord and use **Bluetooth** or a USB receiver to connect to the computer.
• **Mouse Surface**: An optical mouse works best on a flat, opaque surface; it may not work well on glass or highly reflective surfaces.
• **Drag and Drop**: This is a technique where you click and hold an item with the mouse, move it to a new location, and then release the button.
• **Right-Click Menu**: The menu that appears after a right-click is often called a **Pop-up Menu** or **Context Menu**.
• **Printer Types**: **Inkjet printers** are common for home use, while **Laser printers** are often used in offices for high-speed printing.
• **Printer Cartridges**: Inkjet printers use ink cartridges, while laser printers use a powder called **Toner**.
• **Paper Tray**: Printers have a tray where blank paper is loaded before the printing process begins.
• **Print Command**: To print, the user selects the "Print" option from the software menu on the computer screen.
• **Speaker Placement**: Speakers should be placed on either side of the monitor for the best stereo sound experience.
• **Headphone Jack**: Most computers have a dedicated port (usually green) to plug in headphones or external speakers.
• **Microphone Sensitivity**: The microphone captures sound waves and converts them into digital data that the computer can process.
• **UPS Capacity**: The capacity of a UPS is measured in **VA (Volt-Ampere)**; a higher rating means it can support the computer for longer.
• **UPS Maintenance**: The battery inside a UPS needs to be replaced every few years to ensure it holds a charge during power outages.
• **Webcam**: A webcam is an **Input Device** used to capture live video and images, often used for video calls.
• **Scanner**: A scanner is an **Input Device** that converts physical documents or photographs into a digital format on the computer.
• **Joystick**: A joystick is an **Input Device** primarily used for playing games on the computer to control movement.
• **Game Controller**: Similar to a joystick, a game controller provides buttons and sticks for a better gaming experience.
• **External Storage**: Devices like **Pen Drives** (USB Flash Drives) are used to store and transfer data between different computers.
• **Data Transfer**: Pen drives are plugged into the **USB Port** of the CPU cabinet to read or write data.

• **The Computer System**: A computer is not just one box; it is a collection of hardware components working in harmony.
• **Hardware Definition**: Hardware refers to all the physical parts of a computer that you can see and touch.
• **Software Definition**: Software refers to the set of instructions or programs that tell the hardware what to do.
• **Input Process**: The process of giving data or instructions to the computer is called **Input**.
• **Processing Phase**: The CPU performs the **Processing** phase, where it analyzes the input data.
• **Output Phase**: The result of the processing is displayed or provided to the user during the **Output** phase.
• **Storage Phase**: The computer saves data for future use in the **Storage** phase, using devices like the hard drive.
• **IPO Cycle**: Computers follow the **IPO Cycle** (Input-Process-Output) to complete every task.
• **Example of IPO**: Typing a letter (Input) -> CPU processes the text (Process) -> Letter appears on the monitor (Output).
• **Monitor Resolution**: High-resolution monitors provide clearer images, which is important for graphic design and gaming.
• **CPU Speed**: The speed of a CPU is measured in **Gigahertz (GHz)**; higher GHz means faster processing.
• **Keyboard Ergonomics**: Ergonomic keyboards are designed to reduce strain on the wrists and hands during long typing sessions.
• **Mouse Precision**: The precision of a mouse is measured in **DPI (Dots Per Inch)**; higher DPI means the mouse is more sensitive.
• **Printer Speed**: Printer speed is measured in **PPM (Pages Per Minute)**, indicating how many pages it can print in one minute.
• **Speaker Channels**: Speakers can be 2.0 (stereo), 2.1 (stereo + subwoofer), or 5.1 (surround sound) for different audio experiences.
• **Microphone Noise Cancellation**: Advanced microphones can filter out background noise to make the voice recording clearer.
• **Webcam Resolution**: Webcam quality is measured in megapixels; higher megapixels result in sharper video calls.
• **Scanner DPI**: The quality of a scan is determined by its DPI; higher DPI results in a more detailed digital image.
• **Joystick Calibration**: Joysticks often need to be calibrated in the computer settings to ensure accurate movement in games.
• **USB Standards**: USB ports come in different versions (e.g., USB 2.0, USB 3.0), with newer versions offering faster data transfer speeds.

• **The Motherboard**: This is the main board inside the CPU cabinet that connects the processor, memory, and other components.
• **Processor (CPU Chip)**: The actual CPU is a small silicon chip that sits on the motherboard and performs all the calculations.
• **Cooling Fan**: A fan is mounted on top of the CPU chip to keep it cool, as it generates a lot of heat while working.
• **Power Supply Unit (PSU)**: This component converts electricity from the wall outlet into a form that the computer parts can use.
• **Expansion Slots**: These are slots on the motherboard that allow users to add extra features like better graphics cards or sound cards.
• **BIOS**: The **Basic Input/Output System** is a small program that starts the computer when you press the power button.
• **Operating System**: This is the main software that manages all the hardware and allows the user to interact with the computer.
• **Desktop Environment**: The screen you see after the computer starts is called the **Desktop**, which contains icons and a taskbar.
• **Icons**: Small pictures on the desktop that represent files, folders, or programs.
• **Taskbar**: The bar usually located at the bottom of the screen that shows open programs and the Start menu.
• **Start Menu**: A menu that provides access to all installed programs, settings, and files on the computer.
• **File Explorer**: A tool used to browse, organize, and manage files and folders stored on the computer.
• **Window**: A rectangular area on the screen where a program or folder is displayed.
• **Minimize Button**: A button that hides a window and moves it to the taskbar without closing the program.
• **Maximize Button**: A button that makes the window fill the entire screen.
• **Close Button**: A button (usually marked with an 'X') that shuts down the program or window.
• **Cursor**: A small blinking line or arrow on the screen that shows where the next character will appear or where the mouse is pointing.
• **Scroll Bar**: A bar on the side or bottom of a window that allows the user to move through content that doesn't fit on the screen.
• **Menu Bar**: A bar at the top of a window that contains various commands and options for the program.
• **Toolbar**: A row of buttons or icons that provide quick access to frequently used commands.
