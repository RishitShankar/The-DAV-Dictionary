• **Tux Paint**: An award-winning, free, and open-source drawing program designed specifically for children to explore their creativity.
• **Educational Tool**: It is widely used in schools to teach basic computer skills, mouse handling, and artistic expression.
• **Mascot**: The program features a friendly penguin named **Tux**, who acts as a guide and helper throughout the drawing process.
• **User Interface**: The interface is designed to be simple, intuitive, and fun, avoiding complex menus found in professional software.
• **Toolbar**: Located on the left side of the screen, it contains all the primary drawing and editing tools.
• **Canvas**: The large central area where the actual drawing and painting take place.
• **Selector**: Located on the right side, it displays various options, brushes, or sub-tools depending on the tool selected from the toolbar.
• **Colors Palette**: Situated at the bottom of the screen, it provides a wide range of colors to choose from for drawing.
• **Help Area**: Located at the very bottom, this area displays tips, hints, and instructions from Tux the penguin.
• **Starting Tux Paint**: To open the program, one must double-click the Tux Paint icon on the desktop or select it from the Start menu.
• **Closing Tux Paint**: The program can be exited by clicking the 'Quit' button on the toolbar or using the 'Escape' key.
• **Saving Work**: Tux Paint allows users to save their drawings easily by clicking the 'Save' button.
• **File Management**: When saving, Tux Paint does not ask for a filename; it saves as a thumbnail, making it easy for children to identify their work.
• **Opening Files**: Previously saved drawings can be opened by clicking the 'Open' button, which displays a gallery of saved images.
• **Printing**: The 'Print' button allows users to print their artwork directly to a connected printer.

• **Paint Tool**: The primary tool used for freehand drawing, similar to a paintbrush or marker.
• **Brush Selection**: When the Paint tool is selected, the Selector on the right shows various brush shapes and sizes.
• **Drawing Mechanism**: To draw, click and hold the left mouse button while dragging the cursor across the canvas.
• **Lines Tool**: Used to draw straight lines by clicking and dragging from a starting point to an ending point.
• **Rubber Band Effect**: While drawing a line, a thin line appears to show where the final line will be placed before releasing the mouse button.
• **Shapes Tool**: Allows the user to draw various geometric shapes like circles, squares, rectangles, and polygons.
• **Filled vs. Unfilled**: The Shapes tool provides options to draw either an outline of a shape or a solid, filled-in shape.
• **Rotation**: Many shapes in Tux Paint can be rotated before they are finalized on the canvas.
• **Text Tool**: Enables users to type text onto the canvas using different fonts and styles.
• **Text Placement**: Click anywhere on the canvas to place a cursor and begin typing the desired text.
• **Font Selection**: The Selector provides a list of available fonts, which can be previewed before typing.
• **Text Color**: Users can change the color of the text by selecting a color from the color palette before typing.
• **Editing Text**: Text can be moved or deleted before it is "stamped" onto the canvas by pressing the Enter key.
• **Label Tool**: Similar to the Text tool, but labels can be moved or edited even after they have been placed.
• **Keyboard Usage**: The Text and Label tools require the use of the keyboard to input characters and symbols.

• **Magic Tool**: A collection of special effects and filters that add unique artistic elements to the drawing.
• **Magic Tool Variety**: Includes effects like Rainbow, Blur, Bricks, Grass, Chalk, and many others.
• **Rainbow Effect**: Allows the user to draw a trail of colors that cycle through the rainbow spectrum.
• **Blur Effect**: Softens the edges of the drawing or image, creating a dreamy or out-of-focus appearance.
• **Bricks Effect**: Fills an area with a brick-like pattern, useful for drawing walls or buildings.
• **Grass Effect**: Creates a realistic grass texture by clicking and dragging on the canvas.
• **Chalk Effect**: Gives the drawing the appearance of being created with chalk on a blackboard.
• **Drip Effect**: Makes the colors appear as if they are melting or dripping down the screen.
• **Flower Effect**: Automatically draws flowers wherever the mouse cursor is moved.
• **Sparkles Effect**: Adds a glittering, magical star-like effect to the drawing.
• **Fill Tool**: Used to fill a closed area with a solid color or a pattern.
• **Flood Fill**: The Fill tool works by flooding a bounded area with the selected color until it hits an outline.
• **Eraser Tool**: Used to remove parts of the drawing that are no longer wanted.
• **Eraser Sizes**: The Selector provides various sizes and shapes for the eraser, from small squares to large circles.
• **Eraser Functionality**: Click and drag the eraser over the area to be cleared, revealing the background color.

• **Stamp Tool**: Acts like a rubber stamp, allowing users to place pre-drawn images onto the canvas.
• **Stamp Categories**: Stamps are organized into categories such as animals, plants, space, and people.
• **Flipping Stamps**: Many stamps can be flipped horizontally or vertically using the buttons in the Selector.
• **Resizing Stamps**: A slider in the Selector allows the user to change the size of the stamp before placing it.
• **Stamp Preview**: When selecting a stamp, a preview is shown in the Selector area to help the user choose.
• **Mirroring**: Some stamps support mirroring, which creates a reflected version of the image.
• **Stamp Placement**: Simply click on the canvas to place the selected stamp at the desired location.
• **Undo Feature**: The 'Undo' button is one of the most important tools, allowing the user to reverse the last action.
• **Redo Feature**: The 'Redo' button allows the user to restore an action that was previously undone.
• **Multiple Undos**: Tux Paint supports multiple levels of undo, meaning you can step back through several previous actions.
• **New Tool**: Used to start a fresh drawing by clearing the current canvas.
• **Canvas Backgrounds**: When starting a new drawing, the user can choose a blank color or a pre-drawn template to color in.
• **Template Usage**: Templates are helpful for beginners who want to practice coloring within lines.
• **Confirmation**: When clicking 'New', the program asks for confirmation to ensure the current work is saved or intentionally discarded.
• **Safety**: The confirmation dialog prevents accidental loss of progress when starting a new project.

• **Color Palette**: Located at the bottom of the screen, it contains a variety of colors for drawing and filling.
• **Primary Colors**: The palette includes basic colors like Red, Blue, Green, Yellow, and Black.
• **Secondary Colors**: Includes shades like Orange, Purple, Pink, and Brown.
• **Custom Colors**: The last few slots in the palette can sometimes be used to pick custom colors or shades.
• **Color Selection**: Clicking on a color in the palette changes the active color for all drawing tools.
• **Background Color**: When starting a new drawing, the background color can be selected from the palette.
• **Text Color**: The color of the text is determined by the currently selected color in the palette.
• **Shape Color**: Shapes are drawn using the currently selected color from the palette.
• **Magic Tool Interaction**: Some Magic tools, like the 'Fill' tool, rely entirely on the selected color.
• **Visual Feedback**: The selected color is usually highlighted or indicated in the palette area.
• **Eraser Color**: The eraser typically removes the drawing to reveal the background color.
• **Color Mixing**: While Tux Paint doesn't have a traditional color mixer, some Magic tools create color blends.
• **Palette Navigation**: If there are many colors, arrows on the side of the palette allow scrolling through the full selection.
• **Color Consistency**: Maintaining a consistent color scheme helps in creating professional-looking digital art.
• **Educational Value**: The palette helps children learn the names of colors and how they interact.

• **Clicking**: The act of pressing and releasing the mouse button to select tools or place stamps.
• **Dragging**: The act of holding the mouse button while moving the cursor, essential for drawing lines and painting.
• **Precision**: Using the mouse to draw helps children improve their hand-eye coordination.
• **Cursor Icons**: The mouse cursor changes shape depending on the tool selected (e.g., a brush, a stamp, or a crosshair).
• **Tool Selection**: Navigating the toolbar requires accurate clicking on specific icons.
• **Selector Interaction**: Choosing brushes or stamps requires clicking on the desired item in the right-hand panel.
• **Canvas Navigation**: Moving the mouse across the canvas is the primary way to interact with the drawing space.
• **Right-Clicking**: In some versions of Tux Paint, right-clicking may have specific functions, though left-clicking is the standard.
• **Double-Clicking**: Used primarily to launch the application from the desktop icon.
• **Steady Hands**: Drawing straight lines or detailed shapes requires a steady hand and controlled mouse movement.
• **Ergonomics**: Proper posture while using the mouse is important for long drawing sessions.
• **Mouse Speed**: Adjusting mouse sensitivity in system settings can make drawing in Tux Paint easier.
• **Click-and-Drag Technique**: Mastering this technique is the foundation for using almost all tools in the program.
• **Practice**: Consistent use of the mouse in Tux Paint builds confidence for using other computer applications.
