• **Introduction to Computer:** A computer is an advanced electronic device designed to accept data, process it according to specific instructions, and produce meaningful information.
• **Definition of Data:** Data refers to raw, unorganized facts, figures, symbols, or characters that are fed into the computer for processing.
• **Definition of Information:** Information is the processed, organized, and meaningful output that results from the computer’s manipulation of raw data.
• **The IPO Cycle:** The fundamental working mechanism of a computer is based on the Input-Process-Output (IPO) cycle.
• **Input Phase:** This is the stage where raw data and instructions are entered into the computer system using input devices like keyboards or mice.
• **Process Phase:** This is the stage where the Central Processing Unit (CPU) performs calculations, comparisons, and logical operations on the input data.
• **Output Phase:** This is the final stage where the processed data is presented to the user in a readable format via output devices like monitors or printers.
• **Storage Phase:** A crucial fourth component where data and instructions are saved for future retrieval and use within memory units.
• **Speed:** Computers are incredibly fast, capable of performing millions of complex calculations in a fraction of a second.
• **Accuracy:** Computers provide highly accurate results, provided the input data and the instructions given are correct.
• **Diligence:** Unlike humans, computers do not get tired, bored, or lose concentration, allowing them to perform repetitive tasks for hours without error.
• **Versatility:** Computers are versatile machines capable of performing a wide variety of tasks, from word processing to complex scientific simulations.
• **Storage Capacity:** Computers possess the ability to store vast amounts of data in a compact space, which can be accessed instantly when needed.
• **Reliability:** The electronic components of a computer are designed to be highly reliable, ensuring consistent performance over long periods.
• **Automation:** Computers can perform tasks automatically once the initial instructions are provided, reducing the need for constant human intervention.

• **Hardware:** Hardware refers to the physical, tangible components of a computer system that you can touch and feel.
• **Software:** Software refers to the set of programs, instructions, and data that tell the hardware how to perform specific tasks.
• **Input Devices:** These are hardware components used to provide data and control signals to the computer.
• **Keyboard:** The primary input device used for typing text, numbers, and commands into the computer.
• **Mouse:** A pointing device used to interact with graphical user interfaces by clicking, dragging, and scrolling.
• **Scanner:** An input device that captures images, printed text, or handwriting and converts them into digital format.
• **Microphone:** An input device used to record audio, voice commands, or sound into the computer system.
• **Webcam:** A video capture device that records live video or takes still images for transmission over the internet.
• **Joystick:** An input device primarily used for controlling movement in computer games and simulations.
• **Light Pen:** A light-sensitive pointing device used in conjunction with a computer's CRT monitor to draw or select objects.
• **Touchscreen:** A display screen that acts as both an input and output device, allowing users to interact by touching the screen directly.
• **Trackball:** A stationary pointing device consisting of a ball held by a socket, used as an alternative to a mouse.
• **Graphics Tablet:** An input device that allows users to hand-draw images and graphics, similar to drawing with a pencil on paper.
• **Barcode Reader:** An optical scanner that reads printed barcodes, commonly used in retail stores for inventory and pricing.
• **Biometric Sensor:** An input device that identifies individuals based on physical characteristics like fingerprints or iris scans.

• **Central Processing Unit (CPU):** Often referred to as the "Brain of the Computer," it is responsible for executing instructions and processing data.
• **Control Unit (CU):** A component of the CPU that directs and coordinates the operations of all other parts of the computer.
• **Arithmetic Logic Unit (ALU):** The part of the CPU that performs all mathematical calculations (addition, subtraction) and logical operations (comparisons).
• **Memory Unit (MU):** The section of the CPU that stores data, instructions, and intermediate results temporarily during processing.
• **Motherboard:** The main circuit board of the computer that connects the CPU, memory, hard drives, and other hardware components.
• **System Clock:** A tiny quartz crystal that regulates the speed at which the CPU processes instructions, measured in Gigahertz (GHz).
• **Registers:** Small, high-speed storage locations within the CPU used to hold data that is currently being processed.
• **Bus System:** A communication system that transfers data between components inside the computer or between computers.
• **Microprocessor:** A single integrated circuit that contains all the functions of a CPU, commonly found in modern personal computers.
• **Instruction Cycle:** The process by which a computer retrieves a program instruction from its memory, determines what actions the instruction requires, and carries out those actions.
• **Fetch:** The first step of the instruction cycle where the CPU retrieves an instruction from the main memory.
• **Decode:** The second step where the CPU interprets the instruction to determine which operation needs to be performed.
• **Execute:** The final step where the CPU performs the actual operation specified by the instruction.
• **Cache Memory:** A small, extremely fast memory type located close to the CPU to speed up data access.
• **Multi-core Processor:** A CPU with two or more independent processing units (cores) that can execute multiple instructions simultaneously.

---PAGE-BREAK---

• **Output Devices:** Hardware components that receive data from the computer and convert it into a human-readable form.
• **Monitor:** The primary output device that displays visual information, text, and graphics generated by the computer.
• **Printer:** An output device that produces a hard copy (physical printout) of documents or images on paper.
• **Impact Printers:** Printers that work by striking an ink ribbon against paper, such as Dot Matrix printers.
• **Non-Impact Printers:** Printers that do not physically strike the paper, such as Inkjet and Laser printers.
• **Inkjet Printer:** A printer that creates images by spraying tiny droplets of ink onto the paper.
• **Laser Printer:** A high-speed printer that uses a laser beam and toner to produce high-quality text and graphics.
• **Speakers:** Output devices that convert electrical signals from the computer into audible sound.
• **Headphones:** Personal audio output devices that allow users to listen to sound privately without disturbing others.
• **Projector:** An output device that projects computer-generated images onto a large screen or wall for group viewing.
• **Plotter:** A specialized output device used for printing high-quality vector graphics, such as architectural blueprints and engineering designs.
• **Braille Embosser:** An output device that translates computer text into Braille for visually impaired users.
• **Resolution:** A measure of the clarity of an image, usually defined by the number of pixels on a monitor or dots per inch (DPI) on a printer.
• **Refresh Rate:** The number of times per second a monitor updates the image on the screen, measured in Hertz (Hz).
• **Hard Copy:** A physical, printed version of a digital document.

---PAGE-BREAK---

• **Primary Memory:** Also known as Main Memory, it is the internal memory of the computer that the CPU accesses directly.
• **RAM (Random Access Memory):** A volatile type of memory that stores data and programs currently in use by the CPU.
• **Volatile Memory:** Memory that loses its stored information when the power supply to the computer is turned off.
• **ROM (Read-Only Memory):** A non-volatile type of memory that contains permanent instructions for booting the computer.
• **Non-Volatile Memory:** Memory that retains its stored information even after the power is switched off.
• **Secondary Storage:** External or auxiliary storage used to save data permanently for long-term use.
• **Hard Disk Drive (HDD):** A magnetic storage device that serves as the primary storage for the operating system and user files.
• **Solid State Drive (SSD):** A faster, more durable storage device that uses flash memory instead of spinning magnetic platters.
• **Optical Discs:** Storage media that use laser technology to read and write data, such as CDs, DVDs, and Blu-ray discs.
• **USB Flash Drive:** A portable, compact storage device that connects to a computer via a USB port.
• **Memory Card:** A small, removable storage device used in cameras, smartphones, and tablets.
• **Cloud Storage:** A service where data is stored on remote servers accessed via the internet, rather than on a local device.
• **Bit:** The smallest unit of data in a computer, representing either a 0 or a 1.
• **Byte:** A unit of digital information consisting of 8 bits, typically representing a single character.
• **Storage Hierarchy:** The ranking of memory types based on speed, cost, and capacity, with CPU registers at the top and secondary storage at the bottom.

• **System Software:** A type of software that manages and controls the computer hardware and provides a platform for application software.
• **Operating System (OS):** The most critical system software that acts as an interface between the user and the computer hardware.
• **Functions of OS:** Managing files, controlling hardware devices, running applications, and providing a user interface.
• **Examples of OS:** Windows, macOS, Linux, Android, and iOS.
• **Application Software:** Programs designed to help users perform specific tasks, such as writing documents or browsing the internet.
• **Word Processors:** Application software used for creating, editing, and formatting text documents (e.g., MS Word).
• **Spreadsheet Software:** Software used for organizing data in rows and columns and performing mathematical calculations (e.g., MS Excel).
• **Presentation Software:** Tools used to create visual slideshows for presentations (e.g., MS PowerPoint).
• **Web Browsers:** Software used to access and view websites on the internet (e.g., Google Chrome, Firefox).
• **Multimedia Software:** Programs used to create, edit, or play audio, video, and image files.
• **Utility Software:** Programs that help maintain and optimize the computer's performance, such as antivirus or disk cleanup tools.
• **Programming Languages:** Tools used by developers to write instructions that the computer can understand and execute.
• **Compiler:** A program that translates high-level programming code into machine-readable code.
• **User Interface (UI):** The part of the software that allows the user to interact with the computer, such as a Graphical User Interface (GUI).
• **GUI:** A type of interface that uses icons, windows, and menus to make the computer easy to use.

• **Computer Network:** A collection of interconnected computers and devices that share resources and information.
• **Internet:** A global network of networks that connects millions of computers worldwide.
• **World Wide Web (WWW):** A system of interlinked hypertext documents accessed via the internet.
• **Email:** A method of exchanging digital messages between people using electronic devices.
• **E-Commerce:** The buying and selling of goods and services over the internet.
• **Online Education:** The use of computer technology to provide learning materials and instruction remotely.
• **Social Media:** Platforms that allow users to create and share content or participate in social networking.
• **Cybersecurity:** The practice of protecting computer systems and networks from digital attacks and unauthorized access.
• **Password:** A secret string of characters used to authenticate a user and protect their account.
• **Firewall:** A security system that monitors and controls incoming and outgoing network traffic based on security rules.
• **Antivirus Software:** A program designed to detect, prevent, and remove malicious software (malware) from a computer.
• **Malware:** A broad term for malicious software, including viruses, worms, and spyware.
• **Phishing:** A fraudulent attempt to obtain sensitive information by disguising as a trustworthy entity in electronic communication.
• **Data Privacy:** The right of individuals to control how their personal information is collected and used.
• **Digital Citizenship:** The responsible and ethical use of technology and the internet.

---PAGE-BREAK---

• **Computer Ethics:** The set of moral principles that govern the behavior of individuals when using computers and the internet.
• **Plagiarism:** The act of using someone else's work or ideas and passing them off as one's own.
• **Copyright:** A legal right that protects the creators of original works, such as software, music, and literature.
• **Software Piracy:** The unauthorized copying, distribution, or use of software.
• **Open Source Software:** Software whose source code is available for anyone to inspect, modify, and enhance.
• **Proprietary Software:** Software that is owned by an individual or company and has restrictions on its use and modification.
• **Ergonomics:** The study of designing equipment and devices to fit the human body, reducing strain and injury.
• **Posture:** Maintaining a correct sitting position while using a computer to prevent back and neck pain.
• **Screen Time:** The amount of time spent using a device with a screen; it is important to take regular breaks.
• **Eye Strain:** A condition caused by prolonged screen use; the 20-20-20 rule is recommended to prevent it.
• **20-20-20 Rule:** Every 20 minutes, look at something 20 feet away for at least 20 seconds.
• **Computer Literacy:** The knowledge and ability to use computers and related technology efficiently.
• **Technological Advancement:** The continuous improvement of computer hardware and software over time.
• **Artificial Intelligence (AI):** The simulation of human intelligence processes by computer systems.
• **Future of Computing:** Trends like quantum computing, edge computing, and advanced robotics shaping the future.

• **Booting:** The process of starting up a computer and loading the operating system into memory.
• **Cold Boot:** Starting the computer when it is completely turned off.
• **Warm Boot:** Restarting the computer without turning off the power.
• **Desktop:** The main screen area that appears after the computer has finished booting up.
• **Icons:** Small graphical symbols on the desktop that represent programs, files, or folders.
• **Taskbar:** A bar usually located at the bottom of the screen that shows open programs and system status.
• **Start Menu:** A central hub for accessing installed applications, settings, and files.
• **File:** A digital container for storing information, such as a document, image, or program.
• **Folder:** A container used to organize files and other folders on a storage drive.
• **Directory:** Another term for a folder, often used in technical contexts.
• **Path:** The specific location of a file or folder within the computer's file system.
• **File Extension:** A suffix at the end of a filename (e.g., .docx, .jpg) that indicates the file type.
• **Control Panel:** A section of the operating system that allows users to change system settings and configurations.
• **Settings:** A menu used to customize the computer's behavior, appearance, and hardware preferences.
• **Search Bar:** A tool used to quickly find files, folders, or applications on the computer.

• **Computer Limitations:** Despite their power, computers lack common sense, intuition, and the ability to feel emotions.
• **Dependency:** Over-reliance on computers can lead to a loss of traditional skills and critical thinking abilities.
• **Environmental Impact:** The production and disposal of electronic devices (e-waste) have significant environmental consequences.
• **Green Computing:** The practice of using computers in an environmentally sustainable and eco-friendly manner.
• **Energy Efficiency:** Modern computers are designed to consume less power and enter sleep modes when inactive.
• **Recycling:** Properly disposing of old computer parts to recover valuable materials and reduce pollution.
• **Human-Computer Interaction (HCI):** The study of how people interact with computers and how to design interfaces that are user-friendly.
• **Accessibility:** Features designed to make computers usable by people with disabilities, such as screen readers or voice control.
• **Virtual Reality (VR):** A computer-generated simulation that creates an immersive experience for the user.
• **Augmented Reality (AR):** Technology that overlays digital information onto the real-world environment.
• **Internet of Things (IoT):** The network of physical objects embedded with sensors and software to exchange data.
• **Big Data:** Extremely large datasets that may be analyzed computationally to reveal patterns and trends.
• **Cloud Computing:** Delivering computing services—including servers, storage, and databases—over the internet.
