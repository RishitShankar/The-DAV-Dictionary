• **Computer Definition**: A computer is an advanced electronic machine that processes data to perform various tasks with high speed and accuracy.
• **Electronic Nature**: Computers are called electronic machines because they run on electricity to function and perform operations.
• **Data Processing**: The primary function of a computer is to accept raw facts and figures, known as data, and convert them into meaningful information.
• **Speed**: Computers can perform millions of calculations in a single second, making them significantly faster than human beings.
• **Accuracy**: Computers are highly reliable and provide error-free results, provided the input data and instructions are correct.
• **Storage Capacity**: Computers possess a vast memory, allowing them to store large amounts of information, documents, images, and videos for future use.
• **Diligence**: Unlike humans, computers do not get tired or bored; they can work for long hours without losing their efficiency.
• **Versatility**: Computers are versatile machines capable of performing a wide variety of tasks, such as writing, calculating, playing games, and watching movies.
• **Decision Making**: Computers cannot make their own decisions; they strictly follow the instructions provided by the user.
• **Input**: The process of entering data and instructions into the computer is called input.
• **Processing**: The action of working on the input data according to the given instructions is known as processing.
• **Output**: The final result obtained after the processing of data is called output.
• **Hardware**: The physical parts of the computer that we can see and touch are collectively known as hardware.
• **Software**: The set of instructions or programs that tell the computer what to do is called software.
• **Human-Computer Interaction**: Computers act as a bridge between human intelligence and machine efficiency to simplify complex tasks.

• **Desktop Computer**: A computer designed to be kept on a desk or table, consisting of a monitor, CPU, keyboard, and mouse.
• **Portability**: Desktop computers are generally not portable and are meant for use in a fixed location like a home or office.
• **Laptop Computer**: A portable computer that is small enough to be placed on a person's lap and can be carried anywhere easily.
• **Battery Power**: Laptops are equipped with rechargeable batteries, allowing them to function without being plugged into a power outlet constantly.
• **Integrated Components**: In a laptop, the screen, keyboard, and pointing device are built into a single, foldable unit.
• **Tablet**: A thin, mobile computer with a touchscreen interface that is used primarily for media consumption and light tasks.
• **Touchscreen Technology**: Tablets rely on touch-sensitive screens, allowing users to interact with the device using fingers or a stylus.
• **Smartphone**: A handheld device that combines the features of a mobile phone with the computing power of a small computer.
• **Connectivity**: Modern computers are designed to connect to the internet, enabling global communication and information sharing.
• **Monitor**: An output device that displays the visual output, such as text, images, and videos, generated by the computer.
• **CPU (Central Processing Unit)**: Often called the 'Brain of the Computer,' it is responsible for processing all instructions and data.
• **Keyboard**: An input device consisting of various keys used to type text, numbers, and commands into the computer.
• **Mouse**: A pointing device used to move the cursor on the screen and select items by clicking.
• **Printer**: An output device used to produce a hard copy of the information displayed on the computer screen onto paper.
• **Speakers**: Output devices that allow the computer to produce sound, music, and voice output.
---PAGE-BREAK---
• **Input Devices**: These are hardware components used to provide data and control signals to an information processing system.
• **Keyboard Layout**: The standard keyboard follows the QWERTY layout, named after the first six letters on the top row.
• **Alphabet Keys**: These keys are used to type letters from A to Z, essential for writing words and sentences.
• **Number Keys**: These keys, labeled 0 to 9, are used for entering numerical data and performing mathematical calculations.
• **Space Bar**: The longest key on the keyboard, used to insert a blank space between words or characters.
• **Enter Key**: Used to move the cursor to the next line or to execute a command that has been typed.
• **Backspace Key**: Used to erase characters typed to the left of the current cursor position.
• **Delete Key**: Used to erase characters to the right of the cursor or to remove selected files and folders.
• **Caps Lock Key**: A toggle key that, when activated, allows the user to type all letters in uppercase (capital) format.
• **Shift Key**: Used in combination with other keys to type capital letters or the symbols located on the top half of certain keys.
• **Arrow Keys**: Four keys (Up, Down, Left, Right) used to move the cursor across the screen in the desired direction.
• **Function Keys**: Keys labeled F1 through F12 that perform specific tasks depending on the software being used.
• **Escape Key (Esc)**: Used to cancel or exit from the current operation or program.
• **Tab Key**: Used to move the cursor forward by several spaces at once, often used for indentation.
• **Control (Ctrl) and Alt Keys**: Modifier keys used in combination with other keys to perform special shortcuts and commands.
---PAGE-BREAK---
• **Mouse Functionality**: The mouse is a handheld pointing device that detects two-dimensional motion relative to a surface.
• **Cursor**: The small arrow or pointer on the screen that moves in sync with the physical movement of the mouse.
• **Left Click**: Pressing the left mouse button once to select an item or icon on the screen.
• **Double Click**: Pressing the left mouse button twice in quick succession to open a file, folder, or program.
• **Right Click**: Pressing the right mouse button to open a context menu containing options related to the selected item.
• **Drag and Drop**: A technique where an item is selected, held by the mouse button, moved to a new location, and then released.
• **Scroll Wheel**: A wheel located between the left and right buttons, used to move up and down through long documents or web pages.
• **Mouse Pad**: A flat surface used to support and guide the mouse, ensuring smooth movement and accurate tracking.
• **Optical Mouse**: A modern type of mouse that uses a light-emitting diode (LED) and a sensor to track movement.
• **Wireless Mouse**: A mouse that connects to the computer without a physical cable, usually via Bluetooth or a USB receiver.
• **Pointing**: The act of moving the mouse so that the cursor rests on a specific object on the screen.
• **Clicking**: The act of pressing and releasing a mouse button to perform an action.
• **Selection**: Highlighting an object on the screen to prepare it for a specific operation.
• **Context Menu**: A pop-up menu that appears when you right-click, showing commands relevant to the object you clicked on.
• **Ergonomics**: The design of the mouse to fit comfortably in the hand, reducing strain during prolonged use.

• **CPU Cabinet**: The box-like structure that houses the internal components of the computer, including the motherboard and processor.
• **Motherboard**: The main circuit board inside the CPU cabinet that connects all the different parts of the computer.
• **Processor (CPU Chip)**: The central component that performs all the calculations and logical operations.
• **Memory (RAM)**: Random Access Memory, which acts as the temporary workspace for the computer to store data currently in use.
• **Hard Disk Drive (HDD)**: The primary storage device where the operating system, software, and user files are permanently saved.
• **Power Supply Unit (PSU)**: The component that converts electricity from the wall outlet into the power required by the computer parts.
• **Cooling Fan**: A device inside the CPU cabinet that prevents the processor and other parts from overheating.
• **Ports**: Connection points on the back or front of the CPU cabinet where external devices like keyboards and mice are plugged in.
• **USB Port**: A universal port used to connect various devices like pen drives, printers, and cameras.
• **Audio Jacks**: Ports used to connect speakers, headphones, or microphones to the computer.
• **VGA/HDMI Port**: Ports used to connect the monitor to the CPU cabinet for video output.
• **Ethernet Port**: A port used to connect the computer to a network or the internet using a cable.
• **Internal Components**: Parts that are located inside the computer case and are not usually visible to the user.
• **External Devices**: Peripherals that are connected to the computer from the outside.
• **System Unit**: Another name for the CPU cabinet, representing the core processing hub of the computer system.
---PAGE-BREAK---
• **Monitor Types**: Monitors come in different technologies, such as LCD (Liquid Crystal Display) and LED (Light Emitting Diode).
• **Screen Size**: The size of a monitor is measured diagonally from one corner to the opposite corner in inches.
• **Resolution**: The number of pixels (tiny dots) that make up the image on the screen; higher resolution means a clearer picture.
• **Brightness and Contrast**: Settings that allow the user to adjust the light intensity and the difference between dark and light areas on the screen.
• **Power Button**: The button on the monitor used to turn it on or off independently of the CPU.
• **Desktop Screen**: The main screen that appears after the computer is turned on and the operating system loads.
• **Icons**: Small pictures on the desktop that represent files, folders, or programs.
• **Taskbar**: The long bar usually located at the bottom of the screen, showing open programs and system information.
• **Start Button**: A button on the taskbar that opens the main menu to access all installed programs and settings.
• **Wallpaper**: The background image displayed on the desktop, which can be customized by the user.
• **System Tray**: An area on the taskbar that displays icons for background processes like volume, time, and network status.
• **Window**: A rectangular area on the screen where a program or folder displays its contents.
• **Title Bar**: The bar at the top of a window that displays the name of the program or file currently open.
• **Minimize Button**: A button that hides the window and places it on the taskbar.
• **Maximize/Restore Button**: A button that makes the window fill the entire screen or returns it to its previous size.

• **Computer Care**: Computers are delicate machines and require proper handling to function efficiently for a long time.
• **Cleanliness**: Keep the computer and its surroundings clean and free from dust to prevent hardware damage.
• **Food and Drink**: Never eat or drink near the computer, as spills can cause short circuits and permanent damage.
• **Gentle Handling**: Press the keys on the keyboard gently and move the mouse smoothly to avoid wear and tear.
• **Cable Safety**: Do not pull or twist the wires connected to the computer, as this can cause loose connections.
• **Posture**: Sit straight and maintain a proper distance from the monitor to protect your eyes and back.
• **Shutdown Procedure**: Always shut down the computer properly using the software menu instead of just turning off the power button.
• **Covering**: Cover the computer with a dust cover when it is not in use to keep it clean.
• **No Magnets**: Keep magnets away from the computer, as they can interfere with the working of electronic components.
• **Software Updates**: Keep the computer's software and operating system updated to ensure security and performance.
• **Virus Protection**: Use antivirus software to protect the computer from harmful programs that can delete or corrupt data.
• **Rest**: Do not use the computer for very long hours; take breaks to rest your eyes and body.
• **Organization**: Keep your files and folders organized to find information quickly and keep the system tidy.
• **Professional Help**: If the computer shows an error or stops working, ask an adult or a professional for help instead of trying to fix it yourself.
• **Power Surge**: Use a UPS (Uninterruptible Power Supply) to protect the computer from sudden power cuts or voltage fluctuations.

• **Operating System (OS)**: A special software that manages all the hardware and software of the computer.
• **Windows**: The most popular operating system used in schools and homes, which provides a graphical user interface.
• **Graphical User Interface (GUI)**: A type of interface that allows users to interact with the computer using icons and menus instead of typing commands.
• **Booting**: The process of starting up the computer and loading the operating system into memory.
• **Shutting Down**: The process of closing all programs and turning off the power to the computer safely.
• **Restarting**: The process of turning the computer off and on again to fix minor errors or apply updates.
• **Login**: The process of entering a username and password to gain access to the computer system.
• **Desktop Icons**: Visual shortcuts that represent applications, files, or system tools.
• **Recycle Bin**: A special folder that stores deleted files temporarily before they are permanently removed from the computer.
• **File**: A collection of data or information stored on the computer, such as a document, photo, or song.
• **Folder**: A container used to organize and store files, similar to a physical file folder in a cabinet.
• **Taskbar Features**: The taskbar displays the Start button, pinned apps, and the system clock.
• **Search Bar**: A feature that allows users to quickly find files, folders, or programs on the computer.
• **Notification Area**: The part of the taskbar that shows alerts and status icons like battery and Wi-Fi.
• **User Profile**: A personalized environment on the computer that stores individual settings and files for a specific user.
