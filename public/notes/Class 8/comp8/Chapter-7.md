### PAGE 2: Fundamental Principles & Theory Deep-Dive

*   [BLUE] **Core Philosophy of QBasic**
    *   **Definition:** QBasic (Quick Beginners' All-purpose Symbolic Instruction Code) is a high-level, procedural programming language and interpreter developed by Microsoft based on older versions of BASIC.
    *   **Design Principle:** Intended to provide an easy-to-learn, English-like syntax environment for students to transition from manual problem-solving to algorithmic automation.
    *   **Interpreter Architecture:** Translates and executes high-level source code line-by-line, stopping immediately when a syntax error is encountered.

*   [GOLD] **The QBasic Integrated Development Environment (IDE)**
    *   **Interface Layout:** Features a distinct classic MS-DOS-style blue workspace background with a white text foreground.
    *   **Menu Bar Options:** 
        *   `File`: Manages program files (`New`, `Open`, `Save`, `Exit`).
        *   `Edit`: Text manipulation (`Cut`, `Copy`, `Paste`, `Clear`).
        *   `View`: Screen split options and subprograms.
        *   `Run`: Program execution commands (`Start`, `Restart`, `Continue`).
        *   `Debug`: Error tracing and breakpoints.
    *   **Immediate Window:** A lower utility pane used for testing individual commands and evaluating variable outputs instantaneously without running the entire program module.

*   [RED] **The Execution Lifecycle of a QBasic Program**
    *   **Step 1: Source Code Creation:** Typing raw program statements into the QBasic editor buffer.
    *   **Step 2: Lexical Analysis & Translation:** The built-in interpreter reads keywords, checking for typographical or grammar violations.
    *   **Step 3: Output Screen Rendering:** Temporarily switches from the blue IDE workspace to the black-and-white output terminal window (`F5` or `Shift + F5`).
    *   **Step 4: Terminal Pause:** Execution halts after the last instruction, requiring a key press to return to the editor.

### PAGE 3: Scientific Laws, Formulas, Equations & Principles

*   [BLUE] **Operator Precedence Hierarchy (PEMDAS/BODMAS in QBasic)**
    *   QBasic evaluates mathematical expressions following strict precedence rules. Operations of equal priority are evaluated from left to right.
    *   **Rank 1 (Highest):** Parentheses `( )` — Sub-expressions enclosed within brackets are always resolved first.
    *   **Rank 2:** Exponentiation `^` — Raising a base number to a power (e.g., `2 ^ 3` results in `8`).
    *   **Rank 3:** Unary Negation `-` — Denoting negative values (e.g., `-5`).
    *   **Rank 4:** Multiplication `*` and Real Division `/` — Evaluated left-to-right.
    *   **Rank 5:** Integer Division `\` — Divides numbers and truncates the fractional remainder to an integer.
    *   **Rank 6:** Modulus Arithmetic `MOD` — Divides two numbers and returns *only* the integer remainder.
    *   **Rank 7 (Lowest):** Addition `+` and Subtraction `-`.

*   [GOLD] **Fundamental Mathematical Formulas & QBasic Equivalents**
    *   *Area of a Circle:* $\text{Area} = \pi \times r^2$ 
        *   *QBasic Syntax:* `Area = 3.14159 * R ^ 2`
    *   *Simple Interest:* $\text{SI} = \frac{P \times R \times T}{100}$ 
        *   *QBasic Syntax:* `SI = (P * R * T) / 100`
    *   *Celsius to Fahrenheit Conversion:* $F = \left(C \times \frac{9}{5}\right) + 32$ 
        *   *QBasic Syntax:* `F = (C * 9 / 5) + 32`
    *   *Average of Three Numbers:* $\text{Avg} = \frac{N_1 + N_2 + N_3}{3}$ 
        *   *QBasic Syntax:* `Avg = (N1 + N2 + N3) / 3`

*   [GREEN] **Relational Operators & Logical Evaluation Rules**
    *   Used in conditional statements to compare values, always resulting in a Boolean output (True / False equivalent).
    *   `=` : Equal to
    *   `<` : Less than
    *   `>` : Greater than
    *   `<=` : Less than or equal to
    *   `>=` : Greater than or equal to
    *   `<>` : Not equal to

### PAGE 5: Detailed Page-by-Page Textbook Highlights & Core Factoids

*   [BLUE] **Introduction to Programming Concepts (Textbook Unit Core)**
    *   Computers are electronic machines devoid of independent intelligence; they require explicit, step-by-step instructions (programs) to perform operations.
    *   A **Program** is formally defined as a set of instructions organized in a logical sequence to direct the computer hardware to execute a specific task.
    *   Early programming languages required machine code (1s and 0s), which was highly error-prone. High-level languages like QBasic bridge human language and machine execution.

*   [GOLD] **Rules for Naming Variables in QBasic**
    *   Must always begin with an alphabetical letter (`A` through `Z`).
    *   Can contain letters, numbers, and decimal points, but **cannot** contain spaces or arithmetic symbols (`+`, `-`, `*`, `/`).
    *   Cannot be a reserved QBasic keyword (e.g., `CLS`, `PRINT`, `INPUT`, `IF`, `FOR`).
    *   Can include a type declaration suffix: `$` for String variables, `%` for Integer variables, and `!` for Single-precision floating-point numbers.

*   [RED] **Essential Command Breakdown**
    *   `CLS` (Clear Screen): Erases all previous text and outputs from the output display terminal, ensuring a clean slate before rendering new outputs.
    *   `PRINT`: Instructs the computer to display literal strings or evaluated variable values onto the output screen.
    *   `INPUT`: Halts program execution, displays an optional prompt string, and waits for the user to type a value from the keyboard, assigning it directly to a specified variable.

### PAGE 6: Conceptual Breakdown, Practical Examples & Applications

*   [BLUE] **Basic Input-Output Program Structure**
    *   *Concept:* Demonstrates how a program gathers user data, processes it mathematically, and presents the output.
    *   *Code Implementation:*
        ```qbasic
        CLS
        PRINT "=== DAV CALCULATOR PROGRAM ==="
        INPUT "Enter your marks in Maths: ", m
        INPUT "Enter your marks in Science: ", s
        INPUT "Enter your marks in English: ", e
        total = m + s + e
        avg = total / 3
        PRINT "Total Marks Obtained = "; total
        PRINT "Average Percentage = "; avg
        END
        ```

*   [GOLD] **Conditional Branching (`IF-THEN-ELSE`)**
    *   *Concept:* Allows the computer to make logical decisions based on comparative evaluations.
    *   *Code Implementation:*
        ```qbasic
        CLS
        INPUT "Enter student's age: ", age
        IF age >= 13 THEN
            PRINT "Category: Teenager"
        ELSE
            PRINT "Category: Child"
        END IF
        END
        ```

*   [GREEN] **Iterative Looping (`FOR...NEXT` Loop)**
    *   *Concept:* Automates repetitive tasks by running a specific block of code a set number of times using a counter.
    *   *Code Implementation:*
        ```qbasic
        CLS
        PRINT "Printing DAV School Motto 5 Times:"
        FOR i = 1 TO 5
            PRINT i; ". Knowledge is Power"
        NEXT i
        END
        ```

### PAGE 9: Crucial Distinctions, Conceptual Comparisons & Pitfalls

*   [BLUE] **Comparison 1: Variable vs. Constant**
    *   **Variable:** Can change its stored value multiple times during program execution (e.g., `score = score + 10`). Declared without strict initialization constraints.
    *   **Constant:** Value is locked down at declaration and cannot change (e.g., `CONST PI = 3.14159`). Attempts to modify a constant trigger a runtime error.

*   [GOLD] **Comparison 2: Division (`/`) vs. Integer Division (`\`) vs. Modulus (`MOD`)**
    *   `/` (Float Division): Returns the exact mathematical quotient including decimal fractions (e.g., `5 / 2 = 2.5`).
    *   `\` (Integer Division): Truncates the decimal component, returning only the whole number quotient (e.g., `5 \ 2 = 2`).
    *   `MOD` (Modulus): Discards the quotient entirely and returns only the leftover remainder (e.g., `5 MOD 2 = 1`).

*   [RED] **Comparison 3: `PRINT` vs. `INPUT` Commands**
    *   **`PRINT`**: One-way unidirectional communication stream. Pushes data from computer memory out to the visual terminal screen.
    *   **`INPUT`**: Interactive bidirectional communication stream. Halts execution, reads user typing from the physical keyboard, and pulls data into computer memory variables.
