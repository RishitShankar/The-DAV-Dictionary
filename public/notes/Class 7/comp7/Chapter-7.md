• **Definition of Internet**: The **Internet** (short for internetwork) is a massive, decentralized, global system of interconnected computer networks that link billions of devices worldwide.
• **Scale and Reach**: It spans every continent, connecting personal computers, smartphones, servers, smart appliances, satellites, and undersea fiber-optic cables.
• **Interoperability**: The Internet allows diverse hardware systems and operating systems to communicate seamlessly using a standardized suite of communication rules.
• **Global Infrastructure**: Unlike a local area network, the Internet has no single central owner, administrator, or physical control switch, making it truly distributed.
• **Etymology**: The term derives from "internetworking," which describes the process of connecting multiple independent computer networks into a unified communication grid.
• **Evolutionary Roots**: The Internet originated from a research project funded by the United States Department of Defense during the Cold War era.
• **ARPANET Genesis**: The foundational predecessor of the modern Internet was **ARPANET** (Advanced Research Projects Agency Network), established in the late 1960s.
• **First Connection**: ARPANET successfully established its first node-to-node communication on October 29, 1969, connecting University of California, Los Angeles (UCLA) and Stanford Research Institute.
• **Primary Purpose**: Initial networking designs aimed to create a robust, fault-tolerant communication system that could survive partial node destruction during military conflicts.
• **Packet Switching**: Early network engineers pioneered **packet switching**, a method where large messages are broken down into smaller data chunks called packets for independent transmission.
• **Academic Expansion**: During the 1970s and 1980s, the network expanded beyond military applications to connect university research centers, laboratories, and scientific institutions.
• **Protocol Standardization**: The introduction of **TCP/IP** (Transmission Control Protocol / Internet Protocol) in 1983 created a universal language for all connected machines.
• **Commercialization**: By the early 1990s, restrictions on commercial activity were lifted, paving the way for public internet service providers (ISPs) and everyday consumer access.

• **World Wide Web (WWW)**: Often confused with the Internet, the **World Wide Web** is not the physical network itself, but an information space operating *on top* of the Internet.
• **Web Invention**: The WWW was invented by British scientist **Tim Berners-Lee** in 1989 while working at CERN, fundamentally changing how humans share information.
• **Web Documents**: The Web consists of millions of interconnected multimedia documents, pages, and files accessible through specialized software applications called web browsers.
• **Hypertext Concept**: The Web relies on **Hypertext**, text containing links to other texts, allowing users to jump dynamically between related documents with a single click.
• **Web Browsers**: A **web browser** is a software application designed to retrieve, present, and traverse information resources on the World Wide Web.
• **Popular Browser Examples**: Standard web browsers include Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari, and Opera.
• **Web Servers**: A **web server** is a powerful computer system that stores website files (HTML, CSS, images, scripts) and delivers them to users over the Internet upon request.
• **Client-Server Architecture**: The web operates on a **client-server model**, where the user's browser acts as the client requesting data, and the remote computer acts as the server fulfilling the request.
• **Uniform Resource Locator (URL)**: A **URL** is the specific address of a unique resource on the Internet, dictating precisely where the browser must look.
• **URL Anatomy**: A standard URL comprises a protocol (e.g., `https://`), a domain name (e.g., `www.davboard.org`), and a specific file path or resource directory.
• **HTTP/HTTPS Protocols**: **HTTP** (HyperText Transfer Protocol) and its secure counterpart **HTTPS** govern how web messages are formatted and transmitted across the network.
• **SSL/TLS Encryption**: **HTTPS** uses Secure Sockets Layer / Transport Layer Security to encrypt data moving between browser and server, protecting sensitive user inputs.
• **Domain Name System (DNS)**: The **DNS** functions as the "phonebook" of the Internet, translating human-readable domain names into numerical IP addresses.
• **IP Addresses**: An **IP Address** (Internet Protocol address) is a unique numerical label assigned to every device connected to a computer network participating in IP.
• **IPv4 vs IPv6**: **IPv4** uses 32-bit addresses (e.g., `192.168.1.1`), while **IPv6** uses 128-bit addresses to accommodate the exponentially growing number of internet-connected gadgets.
• **Websites and Webpages**: A **website** is a collection of related web pages identified by a common domain name, while a **webpage** is a single document within that collection.

• **Internet Service Provider (ISP)**: An **ISP** is an organization or company that provides individuals, businesses, and institutions with access to the Internet and related services.
• **ISP Connection Types**: ISPs deliver connectivity through various physical mediums, including traditional telephone lines, television cables, cellular networks, and fiber optics.
• **Dial-Up Connection**: An early, slow internet connection method that used standard copper telephone lines and produced a distinctive audio handshake tone during connection.
• **Broadband Connection**: **Broadband** refers to high-speed internet transmission that transmits multiple signals simultaneously over high-bandwidth mediums.
• **DSL Technology**: **DSL** (Digital Subscriber Line) utilizes existing copper telephone lines to provide high-speed internet without interrupting normal telephone voice calls.
• **Cable Internet**: Leverages coaxial television cable infrastructure to deliver high-speed data services alongside television programming to residential areas.
• **Fiber-Optic Internet**: Uses strands of pure glass or plastic to transmit data as pulses of light, offering the fastest speeds and lowest latency currently available.
• **Wireless Internet (Wi-Fi)**: **Wi-Fi** is a wireless networking technology that allows devices to connect to the local network and internet via radio waves.
• **Mobile Data Networks**: Cellular networks (**3G, 4G LTE, and 5G**) enable smartphones and mobile devices to access high-speed internet while away from fixed routers.
• **Satellite Internet**: Connects remote or rural users to the Internet via orbiting communication satellites when terrestrial wired infrastructure is unavailable.
• **Modem Definition**: A **modem** (Modulator-Demodulator) is a hardware device that converts digital data from a computer into analog signals for transmission over lines, and vice versa.
• **Router Definition**: A **router** is a networking hardware device that forwards data packets between computer networks, directing traffic efficiently across multiple devices in a home or office.
• **Combined Gateway Devices**: Modern internet setups frequently combine modem and router functionalities into a single physical unit supplied by the ISP.
• **Network Interface Card (NIC)**: A **NIC** is a hardware component (wired or wireless) that provides a computer with a dedicated, full-time connection to a network.
• **Bandwidth Measurement**: **Bandwidth** measures the maximum rate of data transfer across a given path, typically quantified in megabits per second (Mbps) or gigabits per second (Gbps).
• **Latency Factor**: **Latency** refers to the delay before a transfer of data begins following an instruction for its transfer, heavily impacting online gaming and video calls.

• **Search Engine Fundamentals**: A **search engine** is a specialized software system designed to help users find information stored on the World Wide Web using keywords.
• **How Search Engines Work**: Search engines operate through three primary phases: **Crawling** (discovering pages), **Indexing** (storing and organizing text), and **Ranking** (sorting results by relevance).
• **Web Crawlers**: Automated software programs called **crawlers**, **spiders**, or **bots** systematically browse the web to discover new and updated pages.
• **Index Database**: Discovered webpage content and metadata are stored in a massive, searchable database index for lightning-fast retrieval.
• **Ranking Algorithms**: Complex mathematical algorithms analyze hundreds of factors (such as keyword presence, link quality, and page load speed) to rank search results.
• **Popular Search Engines**: Globally recognized search engines include Google, Microsoft Bing, Yahoo!, DuckDuckGo, and Baidu.
• **Search Query Syntax**: Users enter specific text strings called **search queries** containing keywords, phrases, or Boolean operators to narrow down information.
• **Boolean Search Operators**: Modifiers such as `AND`, `OR`, `NOT`, and quotation marks (`" "`) help refine search engine queries for precise academic results.
• **Email Communication**: **Electronic Mail (Email)** is a method of exchanging digital messages across the Internet from one author to one or more recipients.
• **Email Advantages**: Email provides asynchronous communication, message archiving, file attachment capabilities, and global reach at virtually no additional cost.
• **Email Address Structure**: Every email address consists of a unique username, the `@` (at) symbol, and the specific domain name (e.g., `student@davschool.edu`).
• **Core Email Folders**: Standard email interfaces include an **Inbox** (received mail), **Sent** (transmitted mail), **Drafts** (unfinished messages), and **Spam/Junk** (unsolicited commercial mail).
• **CC and BCC**: **CC** (Carbon Copy) sends visible copies to secondary recipients, while **BCC** (Blind Carbon Copy) hides recipient email addresses from other viewers.
• **Subject Line Importance**: The **subject line** acts as a concise summary of the email's content, guiding the recipient on the urgency and nature of the message.
• **Netiquette in Email**: **Email netiquette** dictates polite professional behavior, including clear greetings, concise paragraphs, proper spelling, and respectful closing remarks.
• **Chat and Instant Messaging**: **Instant Messaging (IM)** allows real-time text-based communication between two or more participants over the internet network.

• **Cloud Computing Basics**: **Cloud computing** is the delivery of computing services—including data storage, servers, databases, networking, and software—over the Internet ("the cloud").
• **Cloud Storage Providers**: Prominent cloud storage platforms include Google Drive, Microsoft OneDrive, Dropbox, and Apple iCloud.
• **Benefits of Cloud Storage**: Users can access files from any internet-connected device anywhere in the world, eliminating reliance on physical USB flash drives.
• **Automatic Backups**: Cloud systems automatically back up user data, protecting important academic documents against hardware crashes, theft, or accidental deletion.
• **Real-Time Collaboration**: Cloud platforms enable multiple students or teachers to edit the same document simultaneously, streamlining group projects and assignments.
• **E-Learning Platforms**: The Internet powers online education through **Learning Management Systems (LMS)**, virtual classrooms, digital textbooks, and instructional video repositories.
• **Video Conferencing Tools**: Applications like Zoom, Microsoft Teams, and Google Meet allow face-to-face virtual instruction, webinars, and parent-teacher meetings.
• **E-Commerce Definition**: **E-commerce** (Electronic Commerce) refers to the buying and selling of goods and services using the internet transmission medium.
• **B2C and C2C Models**: E-commerce operates in models such as **B2C** (Business-to-Consumer, e.g., Amazon) and **C2C** (Consumer-to-Consumer, e.g., OLX, eBay).
• **Digital Payment Methods**: Online transactions utilize digital wallets, credit/debit cards, Unified Payments Interface (UPI), and net banking for cashless purchases.
• **Online Banking Services**: **Net banking** allows customers to check account balances, transfer funds, pay utility bills, and manage investments without visiting a bank branch.
• **Social Media Networks**: **Social media** consists of interactive computer-mediated technologies that facilitate the creation and sharing of information, ideas, and interests.
• **Digital Entertainment**: The Internet streams high-definition movies, music, and interactive video games through services like YouTube, Spotify, and online gaming platforms.
• **Accessing News and Media**: Digital news portals provide instant global updates, replacing traditional printed newspapers with multimedia articles and live video feeds.
• **Remote Work and Jobs**: The Internet enables telecommuting, allowing professionals to work remotely from home offices for companies located across the globe.
• **Global Connectivity Impact**: The Internet acts as a great equalizer, bridging geographical divides and fostering cross-cultural understanding among global student populations.

• **Cyber Safety Importance**: **Cyber safety** refers to the safe and responsible use of information and communication technology to protect oneself and others online.
• **Personal Information Protection**: Users must never share sensitive personal details online, including full home addresses, phone numbers, passwords, or school names.
• **Strong Password Creation**: A **strong password** combines uppercase letters, lowercase letters, numbers, and special symbols, making it difficult for automated programs to guess.
• **Password Security Rules**: Passwords should be kept secret, changed periodically, and never reused across multiple different websites or online accounts.
• **Two-Factor Authentication (2FA)**: **2FA** provides an extra layer of security by requiring two distinct forms of identification before granting access to an account.
• **Logging Out Safely**: Users must always sign out or log out of their personal accounts when using shared computers in school labs, libraries, or cybercafes.
• **Digital Footprint**: A **digital footprint** is the trail of data left behind by users on the internet, including browsing history, posted comments, and shared photos.
• **Permanence of Online Data**: Information posted online can be copied, shared, and archived permanently, meaning hasty or inappropriate posts can haunt a person for years.
• **Cyberbullying Definition**: **Cyberbullying** involves using digital technologies, social media, mobile phones, or chat apps to harass, threaten, embarrass, or target another person.
• **Responding to Cyberbullying**: Victims of cyberbullying should never retaliate; instead, they must save evidence (screenshots), block the bully, and report the behavior immediately.
• **Reporting Authorities**: In school settings, students must report cyberbullying incidents to teachers, parents, school counselors, or designated cybercrime authorities.
• **Plagiarism in Digital Media**: **Plagiarism** is the act of taking someone else's work, ideas, or words and passing them off as one's own without proper attribution.
• **Copyright Law Basics**: **Copyright** is a legal right that grants the creator of an original work exclusive rights to its use and distribution, preventing unauthorized copying.
• **Creative Commons Licensing**: **Creative Commons** licenses provide a flexible way for digital creators to share their work publicly while retaining specific copyright permissions.
• **Respecting Intellectual Property**: Students must always cite their online sources, paraphrase information correctly, and respect digital creators' intellectual property rights.
• **Academic Integrity Online**: Conducting honest academic research means avoiding copy-pasting entire articles for school projects and striving for original synthesis.

• **Malware Definition**: **Malware** (Malicious Software) is any software intentionally designed to cause damage to a computer, server, client, or computer network.
• **Computer Virus**: A **computer virus** is a type of malicious code or program written to alter the way a system operates and replicate itself by inserting its own code.
• **Virus Spread Mechanism**: Viruses typically spread through infected USB flash drives, malicious email attachments, or unauthorized software downloads from unsafe websites.
• **Trojan Horse Malware**: A **Trojan horse** is malware that disguises itself as legitimate, useful software (like a game or utility) to trick users into installing it.
• **Ransomware Threat**: **Ransomware** is a devastating type of malware that encrypts a victim's files, demanding a financial ransom payment to restore system access.
• **Spyware Definition**: **Spyware** is software that secretly gathers information about a person or organization without their knowledge, often tracking browsing habits and keystrokes.
• **Adware Behavior**: **Adware** automatically displays unwanted advertisements on computer screens or web browsers, often slowing down system performance significantly.
• **Antivirus Software**: **Antivirus software** is a computer program used to prevent, detect, and remove malware infections on individual computers and network systems.
• **Antivirus Scanning Mechanisms**: Antivirus tools perform system scans, check file signatures against known malware databases, and monitor system behavior in real time.
• **Software Updates Importance**: Keeping operating systems and applications updated patches security vulnerabilities that hackers could otherwise exploit.
• **Firewall Protection**: A **firewall** is a network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules.
• **Hardware vs Software Firewalls**: Firewalls can be implemented as dedicated hardware devices protecting an entire local network or as software programs running on individual PCs.
• **Safe Downloading Practices**: Students should only download files and applications from official, trusted websites and scan all downloaded files with antivirus software.
• **Avoiding Pirated Software**: Pirated software often comes bundled with hidden malware, trojans, or spyware that compromises system security and steals personal data.
• **Popup Blocker Utility**: Web browsers include **popup blockers** to prevent unwanted advertisement windows from opening automatically during web surfing sessions.
• **Data Backup Protocols**: Regularly backing up essential school files to external hard drives or secure cloud storage prevents catastrophic data loss from malware attacks.

• **Netiquette Definition**: **Netiquette** (Network Etiquette) is a set of social rules and codes of polite behavior for communicating and interacting on the Internet.
• **Tone in Written Communication**: Because text messages and emails lack vocal inflection or facial expressions, users must choose words carefully to avoid sounding rude or harsh.
• **Avoid All-Capital Letters**: Typing entire messages in **ALL CAPITAL LETTERS** is considered the internet equivalent of shouting at someone and should be strictly avoided.
• **Polite Language Standards**: Always use polite words like "please," "thank you," and "excuse me" when interacting in online forums, chat rooms, or email threads.
• **Respecting Diverse Opinions**: The Internet connects people from diverse cultural, religious, and national backgrounds; respectful dialogue and tolerance are mandatory.
• **Spam Prevention Rules**: **Spam** refers to irrelevant, unsolicited, or bulk messages sent over the internet, typically to a large number of users for advertising or malicious purposes.
• **Chain Letters and Hoaxes**: Users must never forward chain letters, unverified rumors, or alarming fake news stories that clutter networks and spread panic.
• **Verifying Online Information**: Before believing or sharing any online article, students must practice **fact-checking** by cross-referencing multiple reputable news sources.
• **Fake News Identification**: **Fake news** consists of deliberate misinformation or hoaxes spread via viral social media posts to manipulate public opinion or generate clicks.
• **Source Evaluation Criteria**: To test source credibility, check the author's credentials, publication date, domain extensions (`.edu`, `.gov`), and presence of editorial oversight.
• **Online Privacy Settings**: Social media and app accounts should have strict **privacy settings** enabled so that personal profiles are visible only to approved friends and family.
• **Meeting Online Strangers**: Students must never agree to meet in person anyone they have befriended exclusively through online chats, gaming servers, or social media.
• **Involving Parents or Teachers**: If an online interaction feels uncomfortable, suspicious, or threatening, students must immediately inform a parent, guardian, or teacher.
• **Screen Time Balance**: While the Internet is a powerful learning tool, students must maintain a healthy balance between online activities and offline physical play.
• **Ergonomics While Browsing**: Good posture, proper screen distance, and regular eye breaks prevent physical strain during long study sessions on computers.
• **Conserving Network Bandwidth**: Avoid downloading unnecessarily massive files on shared school networks during peak hours to ensure fair access for all classmates.

• **Internet Terminology Glossary - Access Provider**: **ISP** (Internet Service Provider) is the company supplying telecommunication connectivity to homes and institutions.
• **Internet Terminology Glossary - Blog**: A **blog** (weblog) is a regularly updated website or web page run by an individual or small group, written in an informal style.
• **Internet Terminology Glossary - Cache**: A **cache** is a hardware or software component that stores data temporarily so future requests for that data can be served faster.
• **Internet Terminology Glossary - Cookie**: A **cookie** is a small text file stored on a user's computer by a web browser to remember user preferences and session data.
• **Internet Terminology Glossary - Download**: **Downloading** is the process of copying data from a remote web server to a local storage device over a network.
• **Internet Terminology Glossary - Upload**: **Uploading** is the process of transmitting local data from a device to a remote server or cloud storage repository.
• **Internet Terminology Glossary - FAQ**: **FAQ** stands for Frequently Asked Questions, a structured list of common inquiries and answers regarding a specific topic.
• **Internet Terminology Glossary - FTP**: **FTP** (File Transfer Protocol) is a standard network protocol used for transferring computer files between a client and server.
• **Internet Terminology Glossary - Homepage**: The **homepage** is the introductory or main web page of a website, serving as a starting point for navigation.
• **Internet Terminology Glossary - Hyperlink**: A **hyperlink** is a digital reference to data that the user can directly follow by clicking or tapping.
• **Internet Terminology Glossary - Podcast**: A **podcast** is a digital audio file made available on the internet for downloading to a computer or mobile device.
• **Internet Terminology Glossary - Protocol**: A **protocol** is a set of rules governing the format and transmission of data between electronic devices.
• **Internet Terminology Glossary - RSS**: **RSS** (Really Simple Syndication) is a web feed format used to publish frequently updated works in a standardized format.
• **Internet Terminology Glossary - Server**: A **server** is a dedicated computer that manages network resources and serves client requests across the Internet.
• **Internet Terminology Glossary - Wi-Fi Hotspot**: A **hotspot** is a physical location where people can access internet services, typically via Wi-Fi, through a wireless local area network.
• **Internet Terminology Glossary - World Wide Web**: The **WWW** is the system of interlinked hypertext documents accessed via the Internet using web browsers.
