• **Internet**: A global network of interconnected computers that communicate using standardized protocols to share information, resources, and services worldwide.
• **World Wide Web (WWW)**: A massive collection of interlinked documents and resources, identified by URLs, accessible via the Internet using a web browser.
• **Web Browser**: A software application used to access and view websites, such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari.
• **Uniform Resource Locator (URL)**: The unique address of a specific webpage or resource on the internet, typically starting with http:// or https://.
• **Hyperlink**: A clickable element (text or image) on a webpage that directs the user to another page or section within the same or a different website.
• **Search Engine**: A specialized web-based tool designed to search for information on the World Wide Web, such as Google, Bing, or DuckDuckGo.
• **ISP (Internet Service Provider)**: A company that provides individuals and organizations access to the internet and related services for a fee.
• **Modem**: A hardware device that connects a computer or router to the broadband network provided by the ISP.
• **Router**: A networking device that forwards data packets between computer networks, allowing multiple devices to share an internet connection.
• **Web Server**: A computer system that stores, processes, and delivers website content to users upon request.
• **IP Address**: A unique numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.
• **Domain Name**: A human-readable address used to identify a website, which replaces the complex numerical IP address (e.g., www.davps.edu.in).
• **HTTP (Hypertext Transfer Protocol)**: The foundation of data communication for the World Wide Web, defining how messages are formatted and transmitted.
• **HTTPS (Hypertext Transfer Protocol Secure)**: An extension of HTTP that uses encryption to provide secure communication over a computer network.
• **Connectivity**: The state of being connected to the internet, which is essential for accessing online resources and communication tools.

• **Search Query**: The specific word or phrase entered into a search engine to find relevant information or websites.
• **Keywords**: The most important words in a search query that help the search engine identify the most relevant results.
• **Search Engine Algorithm**: A complex set of rules and calculations used by search engines to rank and display the most relevant websites for a specific query.
• **Search Results Page (SERP)**: The page displayed by a search engine after a user submits a search query, containing a list of links and snippets.
• **Boolean Operators**: Special characters or words (like AND, OR, NOT) used to refine search queries and narrow down results.
• **Quotation Marks (" ")**: Used in search engines to find an exact phrase, ensuring the results contain the words in the specific order provided.
• **Minus Sign (-)**: Used to exclude specific words from a search, helping to filter out irrelevant results.
• **Asterisk (*)**: A wildcard character used to represent missing words or parts of words in a search query.
• **Image Search**: A feature of search engines that allows users to find visual content based on text descriptions or uploaded images.
• **Video Search**: A specialized search function that retrieves video content from platforms like YouTube or other media repositories.
• **News Search**: A filter that restricts search results to recent news articles and reports from reputable sources.
• **Maps Integration**: A feature that provides geographical locations, directions, and business information directly within search results.
• **Autocomplete**: A feature that suggests potential search queries as the user types, based on popular searches and previous history.
• **Search History**: A record of the queries a user has performed, which can be managed or cleared for privacy reasons.
• **Advanced Search**: A tool that allows users to filter results by language, region, last update, file type, and usage rights.

• **Cyber Safety**: The practice of protecting oneself and one's personal information while using the internet to prevent harm or exploitation.
• **Personal Information**: Sensitive data such as full name, home address, phone number, school name, or passwords that should never be shared online.
• **Cyberbullying**: The use of digital communication tools to harass, threaten, or humiliate an individual repeatedly.
• **Strong Password**: A complex combination of letters, numbers, and symbols that is difficult for others to guess or crack.
• **Password Hygiene**: The practice of keeping passwords secret, changing them regularly, and never using the same password for multiple accounts.
• **Two-Factor Authentication (2FA)**: A security process that requires two forms of identification to access an account, adding an extra layer of protection.
• **Privacy Settings**: Configuration options on social media and websites that control who can see your profile and interact with your content.
• **Phishing**: A fraudulent attempt to obtain sensitive information by disguising as a trustworthy entity in an electronic communication.
• **Malware**: Malicious software designed to infiltrate or damage a computer system without the owner's informed consent.
• **Virus**: A type of malicious software that replicates itself by modifying other computer programs and inserting its own code.
• **Spyware**: Software that secretly gathers information about a person or organization and transmits it to another entity.
• **Pop-up Ads**: Small windows that appear suddenly on a screen, often containing deceptive links or malicious software.
• **Clickbait**: Sensationalized headlines or images designed to entice users to click on a link, often leading to low-quality or harmful content.
• **Digital Footprint**: The trail of data left behind by a user's activities on the internet, which can be tracked and analyzed.
• **Reporting**: The act of notifying platform administrators or authorities when encountering inappropriate, harmful, or illegal content online.

• **Netiquette**: A combination of the words "Network" and "Etiquette," referring to the set of rules for acceptable online behavior.
• **Respectful Communication**: Treating others with kindness and courtesy in emails, chats, and social media interactions.
• **Cyber-Ethics**: The moral principles that govern the use of computers and the internet, focusing on honesty and integrity.
• **Copyright**: The legal right of the owner of intellectual property, meaning you cannot copy or distribute others' work without permission.
• **Plagiarism**: The act of presenting someone else's work or ideas as your own, which is a serious ethical violation.
• **Citing Sources**: Giving proper credit to the original author or creator when using information found on the internet.
• **Public Domain**: Creative materials that are not protected by intellectual property laws, allowing them to be used freely by anyone.
• **Creative Commons**: A set of licenses that allow creators to share their work with specific conditions, such as giving credit.
• **Online Gaming Safety**: Being cautious while playing games online, avoiding sharing personal details with strangers, and reporting toxic behavior.
• **Stranger Danger**: The risk of interacting with unknown individuals online who may have malicious intentions.
• **Safe Browsing**: Using tools and practices to ensure that the websites visited are secure and free from malicious content.
• **Browser Cache**: Temporary storage of web pages on your computer to speed up loading times, which should be cleared periodically for privacy.
• **Cookies**: Small text files stored on your computer by websites to track your preferences and browsing habits.
• **Incognito Mode**: A browser feature that prevents your browsing history and cookies from being saved on your device.
• **Parental Controls**: Software or settings that allow parents to restrict access to inappropriate content and monitor their child's online activity.

• **Reliability of Information**: The process of evaluating whether the content found on a website is accurate, trustworthy, and up-to-date.
• **Author Credibility**: Checking who wrote the article or created the website to determine if they are an expert in the field.
• **Fact-Checking**: Verifying information by comparing it against multiple reputable sources to ensure accuracy.
• **Bias**: A prejudice in favor of or against one thing, person, or group compared with another, which can influence online content.
• **Domain Extensions**: Suffixes at the end of a URL (like .edu, .gov, .org, .com) that provide clues about the nature of the website.
• **.edu (Education)**: A domain extension typically reserved for accredited educational institutions, often considered highly reliable.
• **.gov (Government)**: A domain extension used exclusively by government agencies, generally providing official and accurate information.
• **.org (Organization)**: A domain extension often used by non-profit organizations, though reliability can vary.
• **.com (Commercial)**: A domain extension used by businesses, which may prioritize marketing or sales over objective information.
• **Date of Publication**: Checking when a webpage was last updated to ensure the information is current and relevant.
• **Broken Links**: Links on a webpage that no longer lead to the intended destination, which may indicate an unmaintained site.
• **Grammar and Spelling**: Poor writing quality on a website can often be a sign of unreliable or unprofessional content.
• **Citations and References**: Reputable websites usually provide links or lists of sources to support their claims.
• **About Us Page**: A section of a website that explains the organization's mission, history, and purpose, helping to establish trust.
• **Critical Thinking**: The ability to analyze information objectively and make reasoned judgments about what you read online.

• **Email (Electronic Mail)**: A method of exchanging messages between people using electronic devices over the internet.
• **Email Address**: A unique identifier for an email account, consisting of a username and a domain name (e.g., user@provider.com).
• **Inbox**: The folder where incoming emails are received and stored.
• **Compose**: The action of creating a new email message to send to a recipient.
• **Subject Line**: A brief summary of the email's content, which helps the recipient understand the purpose of the message.
• **Attachment**: A file (document, image, or video) sent along with an email message.
• **Spam**: Unsolicited and often irrelevant or malicious emails sent in bulk to a large number of recipients.
• **Phishing Email**: A deceptive email designed to trick the recipient into revealing sensitive information like passwords or bank details.
• **Email Etiquette**: Using professional language, clear subject lines, and appropriate greetings when communicating via email.
• **CC (Carbon Copy)**: A field used to send a copy of an email to additional recipients who are not the primary addressee.
• **BCC (Blind Carbon Copy)**: A field used to send a copy of an email to recipients without revealing their addresses to other recipients.
• **Reply**: The function used to send a response directly to the sender of an email.
• **Reply All**: The function used to send a response to the sender and all other recipients included in the original email.
• **Forward**: The function used to send a received email to a new recipient.
• **Drafts**: A folder where unfinished email messages are saved before they are sent.

• **Cloud Computing**: The delivery of computing services—including servers, storage, databases, and software—over the internet.
• **Cloud Storage**: A service that allows users to save files online, making them accessible from any device with an internet connection.
• **Google Drive**: A popular cloud storage service that allows users to store, share, and collaborate on documents, spreadsheets, and presentations.
• **Collaboration**: Working together with others on a shared document in real-time using cloud-based tools.
• **File Sharing**: The practice of distributing or providing access to digital media, such as computer programs, multimedia, or documents.
• **Syncing**: The process of automatically updating files across multiple devices so that the most recent version is always available.
• **Accessibility**: The benefit of being able to access your data from anywhere in the world, provided you have an internet connection.
• **Data Backup**: Creating copies of important files to protect against data loss due to hardware failure, theft, or accidental deletion.
• **Security in the Cloud**: Using strong passwords and two-factor authentication to protect files stored on cloud platforms.
• **Shared Links**: A feature that allows you to provide others with access to a specific file or folder without giving them full account access.
• **Permissions**: Settings that control whether a person can only view a file, comment on it, or edit its content.
• **Version History**: A feature that allows users to view and restore previous versions of a document, which is useful for tracking changes.
• **Offline Access**: The ability to view or edit files without an active internet connection, with changes syncing once the connection is restored.
• **Cloud Security Risks**: Potential threats such as unauthorized access or data breaches, which require users to be vigilant.
• **Data Encryption**: The process of encoding information so that only authorized parties can access it, a key feature of cloud security.

• **Social Media**: Websites and applications that enable users to create and share content or to participate in social networking.
• **Social Networking**: The use of internet-based social media sites to stay connected with friends, family, and colleagues.
• **Profile**: A personal page on a social media platform that contains information about the user, such as name, photo, and interests.
• **Friend Request**: An invitation to connect with another user on a social media platform.
• **Follower**: A user who subscribes to see the content posted by another user or account.
• **Hashtag**: A word or phrase preceded by a hash sign (#), used to identify messages on a specific topic.
• **Privacy Risks**: The danger of oversharing personal information, which can be used by strangers or for identity theft.
• **Digital Reputation**: The impression or image of a person that is formed by their online activities and content.
• **Think Before You Post**: A golden rule of social media, reminding users that once something is online, it is difficult to remove completely.
• **Cyber-Harassment**: Sending offensive, rude, or insulting messages to others, which is a violation of social media terms of service.
• **Reporting Tools**: Features provided by social media platforms to flag inappropriate content or abusive users.
• **Blocking**: A feature that prevents a specific user from interacting with your profile or seeing your content.
• **Age Restrictions**: Most social media platforms have minimum age requirements to ensure the safety of younger users.
• **Time Management**: Balancing the time spent on social media with offline activities like studies, sports, and family time.
• **Authenticity**: Being true to oneself online and avoiding the creation of fake profiles or spreading misinformation.

• **Online Learning**: The use of internet-based platforms to access educational materials, attend virtual classes, and complete assignments.
• **LMS (Learning Management System)**: A software application for the administration, documentation, tracking, and delivery of educational courses.
• **Virtual Classroom**: An online learning environment that allows for live interaction between teachers and students.
• **Video Conferencing**: Technology that allows users in different locations to hold face-to-face meetings using audio and video.
• **Digital Citizenship**: The responsible, ethical, and safe use of technology and the internet.
• **Netiquette in Class**: Being punctual, keeping the microphone muted when not speaking, and using the chat box appropriately during online lessons.
• **E-books**: Electronic versions of books that can be read on computers, tablets, or e-readers.
• **Educational Websites**: Sites like Khan Academy, National Geographic Kids, or Britannica that provide reliable learning resources.
• **Interactive Learning**: Using online tools and games to make the learning process more engaging and effective.
• **Digital Literacy**: The ability to find, evaluate, and communicate information through various digital platforms.
• **Cyber-Safety Rules for Students**: Never share passwords, report suspicious activity, and always ask an adult before downloading files.
• **Screen Time**: The amount of time spent using a device, which should be monitored to maintain physical and mental health.
• **Ergonomics**: The practice of setting up your workspace to be comfortable and prevent strain while using a computer.
• **Posture**: Sitting correctly with back support and keeping the screen at eye level to avoid neck and back pain.
• **Eye Health**: Following the 20-20-20 rule (every 20 minutes, look at something 20 feet away for 20 seconds) to reduce eye strain.

• **Internet Ethics**: The set of moral principles that guide our behavior when we are online, ensuring we treat others with respect.
• **Cyber-Bullying Prevention**: Standing up against bullying by not participating, not forwarding hurtful messages, and reporting the behavior.
• **Responsible Sharing**: Only sharing information that is true, kind, and helpful to others.
• **Respecting Privacy**: Never sharing photos or personal details of others without their explicit permission.
• **Avoiding Piracy**: Respecting intellectual property by purchasing software or media legally and avoiding illegal downloads.
• **Reporting Inappropriate Content**: Using the "Report" button on websites to flag content that is violent, hateful, or illegal.
• **Staying Safe on Public Wi-Fi**: Avoiding accessing sensitive accounts (like banking) while connected to public, unsecured Wi-Fi networks.
• **VPN (Virtual Private Network)**: A service that creates a secure, encrypted connection to the internet, protecting your data on public networks.
• **Antivirus Software**: Programs designed to detect, prevent, and remove malicious software from your computer.
• **Firewall**: A network security system that monitors and controls incoming and outgoing network traffic based on security rules.
• **Software Updates**: Regularly updating your operating system and applications to patch security vulnerabilities.
• **Strong Password Policy**: Using a mix of uppercase, lowercase, numbers, and special characters, and changing them every few months.
• **Identity Theft**: The fraudulent practice of using another person's name and personal information to obtain credit or other benefits.
• **Safe Searching Habits**: Using kid-friendly search engines or enabling "SafeSearch" filters to avoid inappropriate content.
• **Conclusion**: The internet is a powerful tool for learning and communication, but it must be used with caution, responsibility, and constant awareness of safety protocols.
