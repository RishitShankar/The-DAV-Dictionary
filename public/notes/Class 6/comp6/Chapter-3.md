• **Chapter Title**: Chapter 3 - Word Processing and Formatting Tools, tailored specifically for Class 6 students under the DAV Public School Board curriculum.
• **Core Subject**: Hands On in Computer (Class 6), focusing on practical, applied digital literacy and foundational document creation skills.
• **Definition of Word Processing**: A word processor is a computer software application used for the production (including composition, editing, formatting, and possibly printing) of any sort of printable material.
• **Primary Objective**: To enable students to create professional-looking documents efficiently by manipulating text, adjusting layouts, and applying visual enhancements.
• **Industry Standard Software**: Microsoft Word is introduced as the benchmark word processing application, featuring a rich graphical user interface (GUI) designed for ease of use.
• **The Application Window**: Upon launching Microsoft Word, students encounter the primary workspace known as the Document Window, where text is typed and edited.
• **Title Bar**: Located at the very top of the window, it displays the name of the currently active document alongside the program name.
• **Quick Access Toolbar**: Situated in the top-left corner, it houses frequently used commands such as Save, Undo, and Redo for immediate single-click access.
• **The Ribbon**: A panel situated near the top of the window that organizes program features into a series of tabs, reducing clutter and improving workflow efficiency.
• **Tabs and Groups**: The Ribbon is divided into multiple Tabs (such as Home, Insert, Page Layout) which are further subdivided into logical Groups of related commands.
• **File Tab**: Clicking the File tab opens Backstage View, a central repository for managing document files (New, Open, Save, Print, Share, and Close).
• **The Insertion Point**: A blinking vertical line on the workspace that indicates where the next typed character or inserted object will appear.
• **Working Area**: The blank, white digital canvas that mimics a sheet of paper, ready to receive user input via the physical keyboard.
• **Scroll Bars**: Vertical and horizontal bars located at the edges of the window that allow users to navigate through documents that exceed the visible screen area.
• **Status Bar**: Located at the bottom of the window, it provides real-time information such as page count, word count, and the active view mode.

• **Text Entry Fundamentals**: Typing text in a word processor requires clicking the insertion point and using the keyboard; words automatically wrap to the next line.
• **Word Wrap Feature**: An automatic function of word processors where text automatically moves to the next line when the right margin is reached, eliminating the need to press Enter manually.
• **Paragraph Break**: Pressing the 'Enter' key explicitly ends the current paragraph and starts a new one, creating a hard return.
• **Selection Techniques**: Text must be selected (highlighted) before any formatting or editing command can be applied to it.
• **Selecting a Single Word**: Accomplished by double-clicking directly on top of the target word using the left mouse button.
• **Selecting an Entire Line**: Achieved by clicking in the left margin area directly adjacent to the desired line of text.
• **Selecting a Paragraph**: Performed by triple-clicking anywhere inside the paragraph or clicking four times rapidly in the left margin.
• **Selecting the Entire Document**: Executed either by dragging across the entire text or using the universal keyboard shortcut Ctrl + A.
• **Deletion Mechanics**: The Backspace key deletes characters to the left of the insertion point, while the Delete key removes characters to the right.
• **Editing Basics**: Modifying existing text without retyping the whole document, relying on insert and overwrite modes to update content.
• **Undo Command**: An essential safety feature (Ctrl + Z) that reverses the very last action performed in the document.
• **Redo Command**: Reinstates an action that was just undone using Ctrl + Y, restoring the document state forward.
• **Cut Operation**: Removes selected text from its original location and places it temporarily into the computer's memory called the Clipboard.
• **Copy Operation**: Duplicates the selected text, leaving the original intact while placing a copy onto the Clipboard.
• **Paste Operation**: Inserts the contents of the Clipboard into the document at the current location of the insertion point.

• **Formatting Definition**: Formatting refers to the process of changing the appearance, layout, and overall visual presentation of a document to make it attractive and readable.
• **Character Formatting**: The practice of altering the appearance of individual letters, numbers, and symbols within a document.
• **Font Family**: A complete set of characters, numbers, and symbols sharing a common weight, width, and style (e.g., Arial, Times New Roman, Calibri).
• **Font Size**: Measured in points (pt), determining how tall the characters appear on the page; standard body text is usually set to 11 or 12 pt.
• **Point Measurement**: One point is approximately 1/72 of an inch, providing a precise metric for typography sizing.
• **Bold Formatting**: Applied using the shortcut Ctrl + B, making the selected text thicker and darker to draw immediate reader attention.
• **Italic Formatting**: Applied using Ctrl + I, slanting the selected text to the right, often used for book titles, foreign words, or emphasis.
• **Underline Formatting**: Applied using Ctrl + U, drawing a horizontal line directly beneath the selected characters for added emphasis.
• **Strikethrough Effect**: Draws a horizontal line directly through the center of the selected text, indicating deleted or obsolete information.
• **Subscript Feature**: Lowers the selected text slightly below the normal baseline, frequently used in scientific formulas like $\text{H}_2\text{O}$.
• **Superscript Feature**: Raises the selected text slightly above the baseline, commonly used for mathematical exponents like $\text{x}^2$ or ordinal indicators (1st).
• **Text Highlight Color**: Simulates the effect of a fluorescent highlighter pen, adding a colored background behind selected text to mark important passages.
• **Font Color Tool**: Changes the pigment of the text characters from default black to any custom or standard color from the color palette.
• **Change Case Tool**: Allows users to quickly modify text capitalization without retyping, featuring options like Sentence case, lowercase, UPPERCASE, Capitalize Each Word, and tONGLE cASE.
• **Clear All Formatting**: Instantly removes all custom styling applied to selected text, reverting it back to the default style template.
---PAGE-BREAK---
• **Paragraph Formatting Definition**: The process of controlling the layout, alignment, spacing, and indentation of entire blocks of text rather than individual characters.
• **Alignment Basics**: Determines how text is positioned horizontally between the left and right margins of the document page.
• **Left Alignment**: The default setting (Ctrl + L) where text is aligned flush against the left margin, leaving the right edge ragged.
• **Right Alignment**: Positions text flush against the right margin (Ctrl + R), commonly used for dates, headers, or signatures.
• **Center Alignment**: Places text equidistant from both margins (Ctrl + E), ideal for document titles, headings, and cover pages.
• **Justify Alignment**: Aligns text evenly against both the left and right margins simultaneously (Ctrl + J), creating clean, professional-looking blocks of text.
• **Line Spacing**: The vertical distance between individual lines of text within a single paragraph, adjustable to values like 1.0, 1.15, 1.5, or 2.0.
• **Paragraph Spacing**: Controls the amount of vertical white space inserted before and after paragraphs, preventing the need to press Enter multiple times.
• **Indentation Definition**: The practice of increasing or decreasing the distance between the paragraph text and the left or right document margins.
• **Left Indent**: Moves the entire left edge of a paragraph inward from the margin.
• **Right Indent**: Moves the right edge of a paragraph inward from the margin.
• **First Line Indent**: Specifically indents only the very first line of a paragraph, standard for traditional book and essay formatting.
• **Hanging Indent**: Indents all lines in a paragraph *except* the first line, frequently used in bibliographies, reference lists, and glossaries.
• **Bullets and Numbering**: Used to create structured lists; bullet points for items where order does not matter, and numbers for sequential steps.
• **Multilevel Lists**: Advanced lists that combine numbers, letters, and bullets in a hierarchical tree structure to outline complex documents.
---PAGE-BREAK---
• **Borders and Shading**: Visual tools used to draw the reader's eye to specific paragraphs, sections, or entire pages by framing them or adding background colors.
• **Paragraph Borders**: Adds visible lines (top, bottom, left, right, or box) around selected paragraphs to separate them from the rest of the body text.
• **Shading Options**: Fills the background area behind selected text or paragraphs with a solid color or subtle pattern to create callout boxes.
• **Format Painter**: A powerful time-saving tool that copies formatting from one part of a document and applies it instantly to another.
• **Using Format Painter**: Selecting formatted text, clicking the paintbrush icon on the Home tab, and dragging over target text to duplicate the exact style.
• **Styles Gallery**: Pre-set combinations of font styles, colors, and sizes that can be applied to headings and body text with a single click.
• **Heading Styles (Heading 1, Heading 2)**: Standardized style templates that establish document hierarchy and are essential for auto-generating tables of contents.
• **Find Command**: Allows users to quickly locate every instance of a specific word or phrase within a large document using the navigation pane (Ctrl + F).
• **Replace Command**: Works alongside Find (Ctrl + H) to automatically substitute targeted words or phrases with new text throughout the entire document.
• **Spelling and Grammar Check**: An automated diagnostic feature that scans the document for lexical errors, flagging misspelled words with red squiggly lines.
• **Grammar Error Indicators**: Uses green or blue wavy underlines to mark potential grammatical mistakes, incorrect punctuation, or awkward phrasing.
• **Context Menu Corrections**: Right-clicking a flagged word opens a drop-down menu containing accurate spelling suggestions and grammar recommendations.
• **Adding to Dictionary**: Allows users to add custom words (like proper nouns or technical terms) to the software's internal dictionary so they are no longer flagged as errors.
• **Thesaurus Tool**: Provides a built-in repository of synonyms and antonyms, helping students enhance their vocabulary and write more descriptively.
• **Word Count Tool**: Tracks exact document metrics including total words, characters (with and without spaces), paragraphs, and lines in real-time.

• **Page Layout Fundamentals**: Managing the overall canvas dimensions, orientation, and margins to prepare a digital document for physical printing.
• **Page Margins**: The blank white spaces that border the top, bottom, left, and right edges of a printed page, ensuring text does not run off the paper.
• **Default Margins**: Standard Microsoft Word documents typically utilize "Normal" margins, set at 1 inch on all four sides.
• **Custom Margins**: Allows users to manually adjust margin sizes to accommodate specific printing requirements, binding offsets, or academic report guidelines.
• **Page Orientation**: Refers to the physical direction in which a document is displayed and printed.
• **Portrait Orientation**: The default vertical layout where the page is taller than it is wide, standard for letters, essays, and reports.
• **Landscape Orientation**: The horizontal layout where the page is wider than it is tall, ideal for wide tables, charts, and certificates.
• **Paper Size Settings**: Dictates the physical dimensions of the output paper stock, with Letter (8.5 x 11 inches) and A4 (8.27 x 11.69 inches) being most common.
• **Page Breaks (Manual)**: Forces the text following the insertion point to immediately move to the top of the next page, regardless of current page fullness (Ctrl + Enter).
• **Section Breaks**: Invisible markers that divide a document into sections, allowing different formatting properties (like varying margins or page numbers) within a single file.
• **Headers and Footers**: Specialized reserve areas located in the top and bottom margins of every page in a document.
• **Header Content**: Text or graphics that appear automatically at the top of every page, commonly containing document titles, chapter names, or author details.
• **Footer Content**: Information displayed at the bottom of every page, frequently utilized for page numbering, confidentiality notices, or publication dates.
• **Page Numbering**: Automated dynamic fields that insert correct, sequential page numbers across multi-page documents without manual typing.
• **Different First Page**: A useful setting that hides headers and footers on the cover page while displaying them on all subsequent pages.

• **Working with Graphics**: Enhancing textual documents with visual elements such as pictures, clip art, shapes, and icons to boost engagement.
• **Inserting Pictures**: The ability to import digital image files (JPEG, PNG, GIF) stored locally on the computer into the Word document via the Insert tab.
• **Online Pictures**: Access to web-based image repositories that allow users to search for and insert graphics directly from the internet.
• **Shapes Tool**: A collection of vector-based geometric shapes, callouts, arrows, and flowchart symbols that can be drawn directly onto the page.
• **SmartArt Graphics**: Pre-designed visual diagrams and organizational structures (such as process loops, hierarchies, and Venn diagrams) used to present complex information.
• **WordArt Feature**: A specialized text-styling tool that transforms standard text into artistic, stylized graphics featuring gradients, shadows, and 3D rotations.
• **Image Resizing**: The process of modifying an image's physical dimensions using sizing handles located at the corners and edges of a selected graphic.
• **Maintaining Aspect Ratio**: Holding the Shift key while dragging a corner handle ensures an image scales proportionally without distortion.
• **Image Rotation**: Using the green rotation handle at the top of a selected graphic to spin the image freely to any desired angle.
• **Picture Styles**: Pre-set frames, borders, and shadow effects that can be applied to images instantly from the Picture Tools Format tab.
• **Text Wrapping around Images**: Controls how surrounding body text flows past inserted graphics (e.g., In Line with Text, Square, Tight, Through, Top and Bottom).
• **Behind Text / In Front of Text**: Advanced text wrapping modes that allow graphics to act as watermarks or overlay directly on top of written content.
• **Positioning Graphics**: Placing images at precise locations on the page (top-left, center, bottom-right) relative to margins or paragraphs.
• **Cropping Images**: Trimming away unwanted outer portions of an image to focus attention on a specific subject area within the graphic.
• **Grouping Objects**: Combining multiple shapes or pictures into a single cohesive unit so they can be moved and resized together.

• **Table Creation Fundamentals**: Tables are structured grids composed of intersecting horizontal rows and vertical columns used to organize data clearly.
• **Definition of Cells**: The individual rectangular boxes formed by the intersection of a row and a column, serving as the fundamental building block of tables.
• **Rows and Columns**: Horizontal sequences of cells are called rows, while vertical sequences of cells are called columns.
• **Inserting a Table**: Accomplished via the Insert tab by using the grid selector, specifying exact row and column dimensions, or using the "Insert Table" dialog box.
• **Navigating a Table**: Using the Tab key to move forward from cell to cell, and Shift + Tab to move backward through the table grid.
• **Selecting Table Elements**: Specific techniques allow users to select an individual cell, a single row, an entire column, or the whole table simultaneously.
• **Adding Rows and Columns**: Contextual Table Tools allow users to instantly insert new rows above/below and new columns to the left/right of existing data.
• **Deleting Table Data**: Removing content versus deleting structural elements; backspace clears text, while delete commands remove entire rows or columns.
• **Merging Cells**: Combining two or more adjacent cells within the same row or column into a single, larger unified cell.
• **Splitting Cells**: Breaking a single table cell back down into multiple smaller rows and columns to accommodate more detailed data entry.
• **Table Alignment**: Positioning the entire table horizontally across the page (Left, Center, or Right) relative to the document margins.
• **Cell Margins and Padding**: Adjusting the internal spacing between text and the borders of table cells to improve readability.
• **Table Design Styles**: Applying pre-formatted color schemes, borders, and alternating shaded rows (zebra striping) to enhance visual appeal.
• **Borders and Shading in Tables**: Customizing individual gridlines with specific line weights, styles, and colors, or filling specific cells with background colors.
• **Text Direction in Tables**: Rotating text vertically within table cells, commonly used for compact table headers in complex financial or statistical reports.

• **Document Views**: Different ways to display a document on the screen depending on the specific task being performed (writing, editing, or reading).
• **Print Layout View**: The default and most common view, showing how the document will look when physically printed on paper, complete with margins and headers.
• **Read Mode View**: Optimizes the screen for comfortable reading by hiding the editing ribbons and maximizing text display area.
• **Web Layout View**: Displays the document as it would appear as a webpage in an internet browser, removing page break boundaries.
• **Outline View**: Shows document text in hierarchical outline form, making it easy to collapse and expand major headings and body sections.
• **Draft View**: A streamlined view that hides headers, footers, and background graphics, focusing entirely on fast text entry and rapid editing.
• **Zoom Controls**: Located on the status bar, the zoom slider allows users to magnify or reduce the document view size from 10% to 500% without altering font sizes.
• **Printing Documents**: The final output phase where digital word processor files are converted into physical paper copies.
• **Print Preview**: A crucial pre-print check window that displays exact page layout, margins, and page breaks before sending jobs to the printer.
• **Printer Selection**: Choosing the specific physical printer device connected locally or via a network in the Print settings menu.
• **Print Range Options**: Allowing users to print the entire document, only the current page, or a custom specified page range (e.g., pages 3-7).
• **Copies Configuration**: Setting the exact number of duplicate sets to be printed in a single run.
• **Collation Setting**: Ensures that multi-page documents print in complete sequential sets (1,2,3... 1,2,3) rather than grouped by page number.
• **Keyboard Shortcuts Summary**: Memorizing essential shortcuts (Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+S, Ctrl+P) to drastically accelerate workflow efficiency.
• **File Saving Best Practices**: Regularly saving work using descriptive file names and organized folder structures to prevent data loss.

• **Digital Citizenship in Word Processing**: Practicing ethical creation, respecting copyright laws, and properly attributing sources when incorporating external text or images.
• **Originality and Creativity**: Encouraging students to use formatting tools to express their unique ideas while maintaining professional academic standards.
• **Clarity Over Clutter**: A cardinal rule of document design stating that excessive fonts, colors, and graphics detract from readability and look unprofessional.
• **Consistency in Typography**: Using a maximum of two complementary font families per document to maintain visual harmony and clean design structure.
• **White Space Utilization**: Embracing blank space around paragraphs, images, and margins to prevent cognitive overload and guide the reader's eye naturally.
• **Alignment Discipline**: Avoiding mixed alignments within the same paragraph block to maintain a clean, organized visual structure.
• **Proper Use of Enter Key**: Never using the Enter key multiple times to force page breaks or create spacing; relying on paragraph spacing settings and manual page breaks instead.
• **Proofreading Habit**: Always reviewing documents using the Spelling and Grammar check tool alongside manual reading before final submission or printing.
• **File Backup Protocols**: Maintaining secondary copies of important school projects on cloud storage or external flash drives to safeguard against hardware failure.
• **Accessibility Considerations**: Designing documents with high contrast, legible font sizes, and clear headings to ensure readability for individuals with visual impairments.
• **Interactive Collaboration**: Modern word processors allow multiple users to co-author and edit documents simultaneously over cloud networks in real-time.
• **Tracking Changes**: A collaborative feature that records every deletion, insertion, and formatting change made by reviewers for editorial oversight.
• **Commenting Feature**: Adding digital sticky notes to specific sections of text to leave feedback, ask questions, or suggest revisions without altering main content.
• **Exporting to PDF**: Converting editable word processor documents into Portable Document Format (PDF) files to lock in formatting and ensure universal compatibility across devices.
• **Chapter Summary Mastery**: Achieving total competency in word processing, character/paragraph formatting, layout design, and document output tools as mandated by the DAV curriculum.
