• **Touch Typing**: A method of typing that uses all fingers without looking at the keyboard, relying on muscle memory to locate keys.
• **Ergonomics**: The practice of arranging the workspace to ensure comfort and efficiency while using a computer.
• **Posture**: Sitting straight with feet flat on the floor and elbows at a 90-degree angle is essential for effective touch typing.
• **Home Row Keys**: The middle row of the keyboard (A, S, D, F, G, H, J, K, L, ;) where fingers rest when not typing.
• **Guide Keys**: The keys 'F' and 'J' have small raised bumps to help fingers find the home row without looking.
• **Left Hand Placement**: The fingers of the left hand rest on A, S, D, and F respectively.
• **Right Hand Placement**: The fingers of the right hand rest on J, K, L, and ; respectively.
• **Thumb Function**: Both thumbs are reserved exclusively for the Space Bar.
• **Muscle Memory**: The process by which the brain learns to perform movements automatically through repetitive practice.
• **Accuracy**: The ability to type without making errors, which is more important than speed for beginners.
• **Speed**: Measured in Words Per Minute (WPM), this improves naturally as accuracy increases.
• **Text Editor**: A software program used for creating, editing, and saving plain text files.
• **Notepad**: A basic text editor included in the Windows operating system, ideal for practicing typing.
• **Cursor**: The blinking vertical line on the screen that indicates where the next typed character will appear.
• **Insertion Point**: Another term for the cursor, marking the exact location for text entry.
• **Keyboard Layout**: The standard arrangement of keys known as QWERTY, named after the first six letters on the top row.
• **Input Device**: The keyboard is the primary input device used to send instructions and text to the computer.

• **Opening Notepad**: To start, click the 'Start' button, type 'Notepad' in the search bar, and press Enter.
• **Interface**: The Notepad window consists of a Title Bar, Menu Bar, and the main Text Area.
• **Title Bar**: Displays the name of the file and the name of the software (Notepad).
• **Menu Bar**: Contains options like File, Edit, Format, View, and Help to manage the document.
• **Text Area**: The large white space where the user types and edits text.
• **Typing Basics**: Pressing a key sends a signal to the computer to display the corresponding character on the screen.
• **Capitalization**: To type a capital letter, hold down the 'Shift' key while pressing the desired letter key.
• **Caps Lock**: A toggle key that, when activated, makes all typed letters uppercase until pressed again.
• **Backspace Key**: Used to delete the character immediately to the left of the cursor.
• **Delete Key**: Used to remove the character immediately to the right of the cursor.
• **Space Bar**: The longest key on the keyboard, used to insert a space between words.
• **Enter Key**: Used to move the cursor to the beginning of the next line (creating a new paragraph).
• **Tab Key**: Used to move the cursor forward by several spaces at once, often for indentation.
• **Arrow Keys**: Used to navigate the cursor up, down, left, or right within the text without deleting anything.
• **Shift Key**: Used in combination with other keys to type symbols located on the top half of number keys.
• **Control Key (Ctrl)**: Used in combination with other keys to perform shortcuts like saving or selecting text.
• **Escape Key (Esc)**: Often used to cancel or close a current operation or menu.

---PAGE-BREAK---

• **Selecting Text**: Highlighting text is necessary to perform actions like copying, cutting, or deleting large chunks of data.
• **Mouse Selection**: Click and drag the mouse pointer across the text to highlight it.
• **Keyboard Selection**: Hold the 'Shift' key and use the arrow keys to highlight text character by character.
• **Select All**: Pressing 'Ctrl + A' highlights every character currently present in the text document.
• **Copying Text**: The process of duplicating selected text to the clipboard without removing it from its original location.
• **Copy Shortcut**: Use 'Ctrl + C' to copy the highlighted text.
• **Cutting Text**: The process of removing selected text from its original location and placing it on the clipboard.
• **Cut Shortcut**: Use 'Ctrl + X' to move the text.
• **Pasting Text**: The process of inserting the text stored on the clipboard into a new location.
• **Paste Shortcut**: Use 'Ctrl + V' to place the copied or cut text at the cursor position.
• **Clipboard**: A temporary storage area in the computer's memory that holds copied or cut data.
• **Undo Function**: Reverses the last action performed, such as accidental deletion or typing.
• **Undo Shortcut**: Use 'Ctrl + Z' to revert the most recent change.
• **Redo Function**: Reverses the effect of the Undo command, restoring the action that was just undone.
• **Saving Files**: Storing the typed text permanently on the computer's hard drive.
• **Save Command**: Found under the 'File' menu, or triggered by 'Ctrl + S'.
• **File Extension**: Notepad files are saved with the '.txt' extension, indicating a plain text format.

• **Format Menu**: Allows the user to change how the text appears on the screen without changing the actual content.
• **Word Wrap**: A feature that automatically moves text to the next line when it reaches the right edge of the window.
• **Font Settings**: Allows the user to change the typeface, style (bold/italic), and size of the text.
• **Typeface**: The design of the letters, such as Arial, Times New Roman, or Calibri.
• **Font Size**: Measured in points; larger numbers result in larger text on the screen.
• **Font Style**: Options like 'Regular', 'Bold', 'Italic', or 'Bold Italic' to emphasize specific words.
• **Status Bar**: Located at the bottom of the Notepad window, it shows the current line and column number of the cursor.
• **Zoom Feature**: Allows the user to magnify or reduce the view of the text for easier reading.
• **Find Command**: Used to search for a specific word or phrase within a long document.
• **Replace Command**: Used to search for a word and automatically swap it with a different word throughout the document.
• **Go To Command**: Allows the user to jump directly to a specific line number in the text.
• **Date and Time**: The 'F5' key or the 'Edit' menu can insert the current system date and time into the document.
• **Print Command**: Sends the text document to a connected printer to produce a physical copy on paper.
• **Page Setup**: Configures settings like paper size, margins, and orientation (portrait or landscape) before printing.
• **Exit Notepad**: Closing the application via the 'File' menu or the 'X' button in the top right corner.
• **Prompt to Save**: If changes are made to a file, Notepad will ask if you want to save them before closing.

• **Typing Rhythm**: Maintaining a steady pace while typing helps in developing consistent muscle memory.
• **Finger Stretching**: Avoid over-stretching fingers; keep them relaxed and close to the home row keys.
• **Wrist Position**: Keep wrists straight and slightly elevated, not resting heavily on the desk surface.
• **Eye Focus**: Train yourself to look at the screen rather than the keyboard to master touch typing.
• **Error Correction**: Do not panic when making a mistake; use the Backspace key calmly and continue typing.
• **Practice Consistency**: Short, daily practice sessions are more effective than one long, infrequent session.
• **Keyboard Familiarity**: Spend time identifying the location of special characters like @, #, $, %, and &.
• **Function Keys**: The 'F1' through 'F12' keys at the top of the keyboard perform specific tasks depending on the software.
• **Numeric Keypad**: The set of number keys on the right side of the keyboard, useful for fast data entry.
• **Num Lock**: A key that toggles the numeric keypad between number entry and directional navigation.
• **Special Keys**: Keys like 'Home', 'End', 'Page Up', and 'Page Down' help in navigating long documents quickly.
• **Home Key**: Moves the cursor to the beginning of the current line.
• **End Key**: Moves the cursor to the end of the current line.
• **Page Up**: Scrolls the view up by one screen length.
• **Page Down**: Scrolls the view down by one screen length.
• **Insert Key**: Toggles between 'Insert' mode (adding text) and 'Overwrite' mode (replacing existing text).

• **Typing Challenges**: Beginners often struggle with the 'P', 'Q', 'Z', and 'X' keys as they are further from the home row.
• **Finger Mapping**: Each finger is responsible for a specific vertical column of keys on the keyboard.
• **Left Pinky**: Responsible for Q, A, Z, and the Shift/Ctrl/Tab keys.
• **Left Ring Finger**: Responsible for W, S, and X.
• **Left Middle Finger**: Responsible for E, D, and C.
• **Left Index Finger**: Responsible for R, F, V, T, G, and B.
• **Right Index Finger**: Responsible for Y, H, N, U, J, and M.
• **Right Middle Finger**: Responsible for I, K, and the comma key.
• **Right Ring Finger**: Responsible for O, L, and the period key.
• **Right Pinky**: Responsible for P, ;, /, and the Enter/Backspace keys.
• **Rhythm Training**: Use metronomes or typing software to maintain a steady, even keystroke rhythm.
• **Visualizing the Keyboard**: Mental practice—visualizing the keyboard layout—can improve physical typing speed.

• **Correct Lighting**: Ensure the room is well-lit to reduce eye strain while reading the screen.
• **Screen Distance**: Keep the monitor at an arm's length away to maintain healthy posture.
