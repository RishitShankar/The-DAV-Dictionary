### 🔬 GRAMMATICAL FORMULAS (व्याकरण-सूत्राणि)

#### 1. KARAN KARAKA & TRITIYA VIBHAKTI (करण कारक एवं तृतीया विभक्ति)
* 📜 **Paninian Sutra**: `[BLUE]` **"साधकतमं करणम्"** (1.4.42) — *The most effective instrument in accomplishing an action is called Karan (Instrument).*
* 📜 **Application Sutra**: `[BLUE]` **"कर्तृकरणयोस्तृतीया"** (2.3.18) — *In unexpressed agent (Anukta Karta) and instrument (Karan), Tritiya Vibhakti is applied.*
* 🧮 **Grammatical Equation**:
  $$\text{Dhatu (Verb)} + \text{Instrumental Means (साधनम्)} \implies \text{Tritiya Vibhakti (तृतीया)}$$
  * *Example*: $\text{कार्यम्} + \text{क्रोध} (\text{करणम्}) + \text{न सिध्यति} \implies \text{क्रोधेन कार्यं न सिध्यति}$

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    TRITIYA VIBHAKTI EXTENSION RULES                     │
├─────────────────────────────────────────────────────────────────────────┤
│ Rule A: Sahayoge Tritiya (सहेतौ तृतीया / सहयोगे तृतीया)                  │
│ Words: सह (Saha), साकम् (Sakam), सार्धम् (Sardham), समम् (Samam)        │
│ Equation: [Noun] + सह ──► Noun takes Tritiya Vibhakti                    │
│ Example: रामः मित्रेण सह गच्छति। (Ram goes with his friend)              │
│                                                                         │
│ Rule B: Yenanga-Vikarah (येनाङ्गविकारः)                                 │
│ Equation: [Defective Body Part] ──► Takes Tritiya Vibhakti               │
│ Example: सः पादेन खञ्जः अस्ति। (He is lame by foot)                     │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 2. KRT PRATYAYA FORMULAS (कृत्-प्रत्यय-समीकरणानि)

##### A. Ktva Pratyaya (क्त्वा प्रत्ययान्तः)
* **Function**: Used for an earlier action performed by the same subject (*Samanakartrikayoḥ purvakale*).
* **Formula**: $\text{Dhatu} + \text{क्त्वा (त्वा)}$ $\implies$ **Avyaya (Indeclinable)**
* **Equations**:
  * $\text{पठ्} + \text{क्त्वा} = \text{पठित्वा}$ (*Having read*)
  * $\text{कृ} + \text{क्त्वा} = \text{कृत्वा}$ (*Having done*)
  * $\text{क्रुध्} + \text{क्त्वा} = \text{क्रुध्वा / क्रोधावेशं कृत्वा}$

##### B. Lyap Pratyaya (ल्यप् प्रत्ययान्तः)
* **Function**: Applied instead of *Ktva* when the verb root has a prefix (*Upasarga*).
* **Formula**: $\text{Upasarga} + \text{Dhatu} + \text{ल्यप् (य)}$ $\implies$ **Avyaya**
* **Equations**:
  * $\text{सम्} + \text{भू} + \text{ल्यप्} = \text{संभूय}$ (*Having become*)
  * $\text{वि} + \text{चिन्त्} + \text{ल्यप्} = \text{विचित्य}$ (*Having thought*)
  * $\text{आ} + \text{गम्} + \text{ल्यप्} = \text{आगत्य}$ (*Having come*)

##### C. Tumun Pratyaya (तुमुन् प्रत्ययान्तः)
* **Function**: Denotes purpose or intention (*Nimittartha*).
* **Formula**: $\text{Dhatu} + \text{तुमुन् (तुम)}$ $\implies$ **Avyaya**
* **Equations**:
  * $\text{कर्तुम्} = \text{कृ} + \text{तुमुन्}$ (*In order to do*)
  * $\text{शासितुम्} = \text{शास्} + \text{तुमुन्}$ (*In order to rule/instruct*)

---

#### 3. SANDHI EQUATION SYSTEM (सन्धि-समीकरण-प्रणाली)
* **Dirgha Svara Sandhi**: $a/ā + a/ā = \bar{a}$ $\implies$ $\text{कार्य} + \text{अकार्यम्} = \text{कार्याकार्यम्}$
* **Guna Svara Sandhi**: $a/ā + i/ī = e$ $\implies$ $\text{न} + \text{इति} = \text{नेति}$
* **Visarga Uttva Sandhi**: $a + \text{ः} + a \implies o + \text{ऽ}$ $\implies$ $\text{क्रोधः} + \text{अपि} = \text{क्रोधोऽपि}$
* **Visarga Sattva Sandhi**: $\text{ः} + t/th \implies s$ $\implies$ $\text{तस्य} + \text{तः} = \text{तस्यतः}$

### 📖 PRECISION GRAMMATICAL DEFINITIONS

#### 1. करण कारकम् (Karan Karakam)
* **Definition**: `[BLUE]` *क्रियासिद्धौ यत् सर्वाधिकं साहाय्यं करोति, तत् कारकं 'करणम्' इति उच्यते।* (The entity that renders maximum assistance in the accomplishment of an action is defined as the Instrument/Karan Karaka.)
* **Primary Vibhakti**: Tritiya Vibhakti (तृतीया विभक्ति).

#### 2. अव्ययपदम् (Avyayapadam)
* **Definition**: `[GREEN]` *सदृशं त्रिषु लिङ्गेषु सर्वासु च विभक्तिषु। वचनेषु च सर्वेषु यन्न व्येति तदव्ययम्॥* (That which remains invariant across all three genders, all grammatical cases, and all numbers is called an Avyaya/Indeclinable.)
* **Key Avyayas in Chapter 8**: **न, अपि, एव, सह, सर्वथा, सहसा, वृथा, यदा, तदा, कथम्**.

#### 3. क्त्वा-प्रत्ययः (Ktva Pratyaya)
* **Definition**: When one subject performs two actions sequentially, the suffix *Ktva* is attached to the root of the earlier action to signify completion (*Having done...*).

#### 4. ल्यप्-प्रत्ययः (Lyap Pratyaya)
* **Definition**: Substitution for *Ktva* when a preposition (*Upasarga*) precedes the verb root. The terminal sound left is **"य"**.
