• **Computer Input Devices**: The keyboard and the mouse are the two most important input devices used to give instructions to a computer.
• **Role of Input Devices**: These devices allow the user to communicate with the computer by sending data or commands.
• **The Keyboard**: A keyboard is a flat, rectangular board that contains many small buttons called keys.
• **Typing Function**: The primary purpose of a keyboard is to type letters, numbers, and symbols into the computer.
• **Key Arrangement**: The keys on a keyboard are arranged in a specific order, similar to a typewriter, to make typing easier.
• **Alphabet Keys**: These keys are marked with letters from A to Z and are used for typing words and sentences.
• **Number Keys**: These keys are marked with digits from 0 to 9 and are used for typing numerical data.
• **Space Bar**: This is the longest key on the keyboard, used to insert a blank space between words.
• **Enter Key**: This key is used to move the cursor to the next line or to give a command to the computer.
• **Backspace Key**: This key acts like an eraser, removing characters typed to the left of the cursor.
• **Delete Key**: This key is used to remove characters or objects to the right of the cursor.
• **Arrow Keys**: These are four keys (Up, Down, Left, Right) used to move the cursor in different directions on the screen.
• **Function Keys**: These are keys labeled F1 through F12, which perform specific tasks depending on the software being used.
• **Shift Key**: This key is used in combination with other keys to type capital letters or special symbols found on the top half of a key.
• **Caps Lock Key**: This key is used to type all letters in uppercase (capital) mode without holding down the Shift key.
• **Control (Ctrl) and Alt Keys**: These are modifier keys used in combination with other keys to perform shortcut commands.
• **Escape (Esc) Key**: This key is used to cancel a current operation or exit from a program or menu.
• **Tab Key**: This key is used to move the cursor several spaces forward at once, often used for indentation.

• **The Computer Mouse**: A mouse is a small, handheld pointing device that helps in selecting and moving items on the computer screen.
• **Physical Structure**: A standard mouse usually has two buttons (left and right) and a scroll wheel in the center.
• **Mouse Pad**: A mouse pad is a flat surface on which the mouse is placed to ensure smooth movement and better tracking.
• **Cursor/Pointer**: When you move the mouse on the mouse pad, a small arrow on the screen, known as the pointer or cursor, moves in the same direction.
• **Left-Click**: Pressing the left button once is called a single click, which is used to select an item on the screen.
• **Double-Click**: Pressing the left button twice quickly is called a double-click, which is used to open a file or a program.
• **Right-Click**: Pressing the right button once opens a menu of options related to the item you have clicked.
• **Dragging**: This action involves holding down the left mouse button and moving the mouse to move an object from one place to another on the screen.
• **Dropping**: This is the action of releasing the left mouse button after dragging an object to its new location.
• **Scroll Wheel**: The wheel located between the left and right buttons is used to move up and down through a document or a webpage.
• **Optical Mouse**: This is a modern type of mouse that uses a light sensor instead of a rubber ball to track movement.
• **Wireless Mouse**: A mouse that does not require a wire to connect to the computer; it uses radio signals or Bluetooth technology.
• **Mouse Grip**: It is important to hold the mouse correctly with your palm resting on it and your index finger on the left button.
• **Pointing**: The act of moving the mouse so that the pointer rests on a specific icon or menu item.
• **Selecting**: Highlighting an icon or text by clicking on it once so the computer knows you want to perform an action on it.
• **Context Menu**: The list of commands that appears when you perform a right-click on an object.
• **Scrolling**: The act of rotating the scroll wheel to view content that is not currently visible on the screen.
• **Mouse Maintenance**: Keeping the mouse and mouse pad clean ensures that the pointer moves smoothly without jumping.

• **Keyboard Layout**: Most keyboards follow the QWERTY layout, named after the first six letters on the top row of alphabet keys.
• **Typing Posture**: Sitting straight and keeping your fingers lightly on the keys helps in typing faster and avoiding fatigue.
• **Home Row**: The middle row of alphabet keys (A, S, D, F, G, H, J, K, L) is called the home row, where fingers should rest.
• **Numeric Keypad**: A separate set of number keys located on the right side of many keyboards, designed for quick data entry.
• **Special Symbols**: Keys like @, #, $, %, and & are accessed by pressing the Shift key along with the corresponding number key.
• **Cursor Control**: The cursor is a blinking vertical line on the screen that shows where the next character you type will appear.
• **Text Entry**: When you press an alphabet key, the corresponding letter appears on the screen at the cursor's position.
• **Word Formation**: By pressing multiple alphabet keys in sequence, you can form words, and by adding spaces, you form sentences.
• **Keyboard Shortcuts**: Combinations of keys like Ctrl + C (Copy) and Ctrl + V (Paste) allow for faster interaction with the computer.
• **Num Lock Key**: A key that toggles the numeric keypad on and off; when off, the keys may act as arrow keys.
• **Scroll Lock Key**: A key that changes the behavior of the arrow keys in some programs, though it is rarely used today.
• **Print Screen Key**: A key used to capture an image of the current screen, which can then be pasted into a document.
• **Pause/Break Key**: A key used to temporarily halt the execution of a program or a scrolling process.
• **Insert Key**: A key that toggles between 'Insert' mode (adding text) and 'Overwrite' mode (replacing text).
• **Home Key**: A key that moves the cursor to the beginning of the current line.
• **End Key**: A key that moves the cursor to the end of the current line.
• **Page Up/Down Keys**: Keys used to scroll through a document one page at a time.
• **Keyboard Care**: Avoid eating or drinking near the keyboard to prevent crumbs or liquids from damaging the internal circuits.

• **Mouse Mechanics**: The optical sensor on the bottom of the mouse captures images of the surface to detect movement.
• **Surface Sensitivity**: An optical mouse works best on opaque, non-reflective surfaces; glass or highly reflective surfaces may cause tracking issues.
• **Mouse Speed**: The sensitivity of the mouse, or how fast the pointer moves relative to the physical movement of the mouse, can be adjusted in settings.
• **Clicking Sound**: The mechanical switch inside the mouse buttons produces a distinct 'click' sound when pressed.
• **Left-Handed Usage**: Computer settings allow users to swap the functions of the left and right buttons to accommodate left-handed users.
• **Drag-and-Drop Mechanism**: This is a fundamental skill for organizing files, folders, and icons on the computer desktop.
• **Selecting Multiple Items**: By holding the Ctrl key on the keyboard and clicking multiple items with the mouse, you can select more than one object at a time.
• **Hovering**: Moving the mouse pointer over an object without clicking it, often causing a small tooltip or description to appear.
• **Double-Click Timing**: The speed at which you must click the left button for it to be recognized as a double-click can be adjusted in the operating system.
• **Mouse Connectivity**: Wired mice connect via USB ports, while wireless mice use a small USB receiver or direct Bluetooth pairing.
• **Battery Life**: Wireless mice require batteries or recharging, and the battery status should be monitored to prevent sudden disconnection.
• **Ergonomic Mouse**: A mouse designed to fit the natural shape of the hand, reducing strain during long periods of use.
• **Trackball Mouse**: A variation where the ball is on top and is rotated by the thumb or fingers, keeping the base stationary.
• **Touchpad**: A flat, touch-sensitive surface found on laptops that replaces the traditional mouse.
• **Gestures**: Modern touchpads support multi-finger gestures, such as pinching to zoom or swiping to switch between applications.
• **Clicking on Touchpads**: Tapping the surface once acts as a left-click, while tapping with two fingers often acts as a right-click.
• **Mouse vs. Keyboard**: While the keyboard is for entering text, the mouse is for navigating and interacting with graphical elements.
• **Input Synergy**: Most computer tasks require the coordinated use of both the keyboard and the mouse.

• **Mouse Precision**: High-end gaming mice offer adjustable weights and DPI settings for maximum control.
• **Mouse Troubleshooting**: If the mouse stops working, checking the connection, replacing batteries, or restarting the computer are the first steps.
• **Mouse Versatility**: The mouse is the primary tool for interacting with the Graphical User Interface (GUI) of modern operating systems.

• **Keyboard Layout Logic**: The QWERTY layout was designed to prevent the mechanical arms of typewriters from jamming, a legacy that continues in modern keyboards.
• **The 'Home Row' Importance**: Placing fingers on the home row allows for the shortest distance to reach any other key on the keyboard.
• **Shift Key Functionality**: It is a 'modifier' key, meaning it has no function on its own but changes the output of other keys.
• **Caps Lock Indicator**: Most keyboards have a small LED light that turns on when Caps Lock is active, preventing accidental typing in uppercase.
• **Num Lock Indicator**: Similar to Caps Lock, this light indicates whether the numeric keypad is in 'number' mode or 'navigation' mode.
• **The 'Escape' Key Origin**: Originally used to 'escape' from a program or a specific state, it remains a standard way to cancel operations.
• **The 'Enter' Key Variations**: On some keyboards, the Enter key is large and L-shaped, while on others, it is a smaller, rectangular key.
• **The 'Windows' Key**: A special key that opens the Start menu in Windows, providing quick access to system functions.
• **The 'Menu' Key**: Often found next to the right Ctrl key, it performs the same function as a right-click on the mouse.
• **Keyboard Shortcuts for Accessibility**: Shortcuts like 'Sticky Keys' allow users to perform key combinations one at a time, aiding those with physical limitations.
• **Mouse Click Sensitivity**: The 'click' is a tactile confirmation that the computer has received the user's input.
• **Mouse Pointer Customization**: Users can change the size, color, and shape of the mouse pointer in the system settings for better visibility.
• **Mouse 'Double-Click' Logic**: The time interval between clicks is short to distinguish between two single clicks and one double-click.
• **The 'Right-Click' Philosophy**: It provides 'contextual' information, meaning the options change based on what you are currently clicking.
• **Mouse Pad Importance**: Using a mouse on a rough or uneven surface can cause the pointer to skip or move inaccurately.
• **Wireless Mouse Latency**: Modern wireless technology has reduced latency to the point where it is indistinguishable from wired mice for most users.
• **Keyboard 'Ghosting'**: A phenomenon where some keyboards fail to register certain key combinations; high-end keyboards are designed to prevent this.
• **Input Device Longevity**: With proper care, a high-quality keyboard and mouse can last for many years of daily use.
